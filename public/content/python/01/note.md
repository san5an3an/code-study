# 01. 프로그래밍 언어의 기본 개념 및 파이썬 소개

## 이 강의에서 배우는 것

- 프로그램과 프로그래밍 언어가 무엇인지, 컴퓨터가 왜 "번역"을 거쳐야만 프로그램을 실행할 수 있는지
- 프로그래밍 언어가 1세대(기계어)부터 5세대(초고급 언어)까지 어떻게 발전해 왔는지
- 프로그래밍 언어의 두 종류: **컴파일 언어**와 **인터프리터 언어**의 차이
- 파이썬의 특징, 파이썬으로 할 수 있는 일과 하기 어려운 일, 라이브러리, 인기
- 앞으로 이 강좌에서 배울 내용과 공부하는 방법

> 이번 강의는 개념 소개 강의라서 강사님이 코드를 실행하지 않아요("오늘은 별다른 실습 예제 없이 끝날 텐데요"). 아래 `code/` 폴더의 예제는 개념을 손으로 확인해 볼 수 있게 따로 만든 **강의 밖 실습**이에요. 파이썬 설치는 다음 강의(02강)에서 해요. 설치를 마친 뒤에 돌려 보세요.

강사님은 "개발자는 한 번에 적게는 2~3개, 많게는 7~8개 언어를 쓰지만, 기본 개념은 전부 같아서 하나만 제대로 공부하면 다른 언어도 쉽게 이해할 수 있다"고 해요. 그래서 첫 시간에 프로그래밍 언어 전체 그림과 그 안에서 파이썬이 어디쯤 있는지를 먼저 본다고 해요.

## 1. 프로그램과 프로그래밍 언어

### 우리는 프로그램에 둘러싸여 있어요

컴퓨터, 스마트폰, TV뿐 아니라 거리의 전광판, 엘리베이터, 버스 도착 알림판, 지하철 발권기, 패스트푸드점 키오스크까지 전부 IT 기기예요. 이 기기들은 모두 **프로그램**으로 움직여요. 강사님 말로는 "프로그램이 없는 IT 기기는 아무 동작도 못 하는 기계 덩어리"예요.

### 프로그램

슬라이드에 적힌 국립국어원의 정의예요.

> 어떤 문제를 해결하기 위하여 그 처리 방법과 순서를 기술하여 컴퓨터에 주어지는 일련의 명령문 집합체

쉽게 말해 "컴퓨터에게 할 일을 순서대로 적어 준 명령 모음"이에요. 비유하면 요리 레시피예요. 레시피에 적힌 순서대로만 요리사(컴퓨터)가 움직여요.

### 프로그래밍 언어

> 사람과 컴퓨터 사이의 의사소통이 가능하게 하는 인공적인 언어. 사람이 컴퓨터에게 일방적으로 전달하는 명령문 형태

- 프로그램을 만들려면 프로그래밍 언어를 써야 해요.
- 강사님은 "컴퓨터한테 전달하고 싶은 내용을 **서술한다**는 느낌으로 접근하라"고 해요.
- 대화가 아니라 **일방적인 명령**이에요. 우리가 컴퓨터한테 지시를 받지는 않으니까요.
- 언어마다 실력을 가장 잘 발휘하는 분야가 따로 있어서, **목적과 용도에 맞는 언어**를 골라 써야 해요.

## 2. 프로그래밍 언어의 발전 (1세대 ~ 5세대)

컴퓨터는 **2진수(0과 1)** 만 이해해요. 컴퓨터가 이해하는 2진수의 모음을 **기계어**라고 해요. 강사님이 "중요합니다, 이 단어요"라고 짚은 단어예요.

| 세대 | 이름 | 한 줄 설명 |
|---|---|---|
| 1세대 | 기계어 | 컴퓨터가 이해할 수 있는 2진수의 모음 |
| 2세대 | 어셈블리어 | 기계어 명령을 사람 말과 비슷한 알파벳 기호로 바꾼 언어 |
| 3세대 | 고급 언어 | 사람이 이해할 수 있는 수준의 언어. 절차지향. 예: C |
| 4세대 | 객체지향 언어 | 오늘날 쓰는 대부분의 언어. 사람의 사고방식에 더 가까움. **파이썬이 여기 속함** |
| 5세대 | 초고급 언어 | 인공지능 원리를 쓰는 시스템을 위해 제안된 개념 |

### 1세대: 기계어

- 컴퓨터의 **중앙처리장치(CPU)** 는 기계어만 해석할 수 있어요. 그래서 **모든 프로그래밍 언어는 결국 기계어로 바뀌어야만 실행돼요.**
- 최초의 컴퓨터(애니악 등)는 **천공카드**로 기계어를 직접 넣었어요. OMR 카드처럼 생긴 종이에 구멍이 **뚫린 곳은 1, 안 뚫린 곳은 0**으로 2진수를 나타냈어요. (강사님이 처음에 반대로 말했다가 바로 고쳐 말해요.)
- 사람이 다루기엔 매우 어려웠어요.

### 2세대: 어셈블리어

- 기계어를 `MOV EAX,1`, `INC EAX`처럼 **알파벳 기호(심벌)** 로 바꾼 형태예요. 영어로 2GL(Second Generation Language)이라고 해요.
- 기계어보다는 읽기 쉽지만 여전히 어렵고, 값을 **16진수**로 많이 써서 더 어려워요. (16진수는 0~9 다음에 A~F까지 써서 세는 수예요.)
- 3세대 언어가 나온 뒤로는 거의 안 써요. 강사님도 "어셈블리는 실제로 본 적이 없다"고 해요.

### 3세대: 고급 언어

- 드디어 **사람이 이해할 수 있는 수준**이 된 언어예요. 수학식에 기반해서 이전보다 읽기 쉽고(가독성이 높고) 다루기 간단해요. 다만 강사님 말대로 "상대적으로 간단하다는 게 쉽다는 건 아니에요."
- 사람에게 가까워진 만큼 **컴퓨터는 직접 이해하지 못해요.** 그래서 고급 언어로 짠 프로그램은 **반드시 기계어로 변환하거나 해석해야** 실행돼요.

슬라이드의 그림을 글로 옮기면 이래요.

```
컴퓨터  <->  기계어 01000001  <->  어셈블리어 mov ax, a  <->  고급 언어 C = a + b  <->  사람
```

- 3세대 언어의 특징은 **절차지향**이에요. 코드가 위에서부터 순서대로 실행되고 프로그램 전체가 유기적으로 연결돼요.
- 구조가 컴퓨터의 처리 구조와 비슷해서 **실행 속도가 매우 빨라요.** 대표 언어는 **C**예요. 강사님 말로 C를 설명할 때 늘 나오는 첫마디가 "C로 만든 프로그램은 빠르다"예요.

### 4세대: 객체지향 언어

- 오늘날 쓰는 대부분의 언어예요. 슬라이드 예: C++, Visual Basic, Java, ASP, PHP, C#, Swift, JavaScript, **Python**
- 사람의 언어와 사고방식에 더 가까워서 **자료의 추상화**가 가능한 객체지향 언어라고 해요. 추상화는 강사님 말로 아주 중요하지만 지금은 생소할 테니 "조급해하지 말고 천천히 알아가면 된다"고 해요. 객체지향은 강좌 중후반에 배워요.
- 이전 세대보다 **쉽고 생산성이 높아서** 4세대 언어가 나온 뒤 개발자가 빠르게 늘었어요.
- 상업용 비즈니스 프로그램 개발에 특화돼 있어요. 데이터 구조를 정의하고 보고서 명세를 저장할 수 있어서 데이터베이스 질의나 GUI 프로그래밍에 많이 써요.

> **참고(강의 밖 내용)**: "몇 세대 언어"라는 나눔은 책마다 조금씩 달라요. 다른 책에서는 4세대 언어(4GL)를 SQL처럼 "무엇을 원하는지만 적으면 되는 언어"로 설명하기도 해요. 또 파이썬은 객체지향만 되는 언어가 아니라, 3세대처럼 위에서 아래로 순서대로 짜는 절차지향 방식도 그대로 쓸 수 있어요. 앞으로 한동안은 그 방식으로 배워요.

### 5세대: 초고급 언어

- 인공지능 분야의 원리를 사용하는 시스템을 위해 **제안된 개념**이에요. 아직 완벽하게 구현되지는 않았어요.
- 프로그래머가 제약 조건이나 **요구사항**을 적어 주면 컴퓨터가 스스로 추론해서 문제를 해결하는 방식이에요.
- 강사님이 비슷한 예로 든 것은 **GitHub Copilot(깃허브 코파일럿)** 이에요. VS Code(비주얼 스튜디오 코드)에 붙이는 확장 기능인데, 코드를 몇 글자 치면 주변 코드를 분석해서 인공지능이 알맞은 코드를 제안해 줘요.
- 강사님 생각: Copilot이 나왔을 때 "개발자의 시대는 끝났다"는 말까지 나왔지만, 막상 써 보니 제안이 늘 정확하지는 않았어요. 그래서 앞으로의 프로그래머는 **인공지능이 제시한 코드를 검증하고 알맞은 자리에 배치하는 역할**을 하게 될 거라고 해요.

> **참고(강의 밖 내용)**: 이 강의는 2023년 무렵에 만들어졌어요. 그 뒤로 코드를 짜 주는 인공지능 도구가 훨씬 많아지고 좋아졌어요. 그래도 "만들어 준 코드가 맞는지 사람이 읽고 판단해야 한다"는 강사님 말은 여전히 맞아요. 그 판단을 하려면 결국 기초 문법을 알아야 해요.

### 예제 (code/machine_code_numbers.py)

슬라이드의 기계어 예시 `01000001`이 어떤 수인지 파이썬으로 확인해 봐요. (강의 밖 실습)

```python
print(int("01000001", 2))   # 2진수 01000001 을 10진수로
print(bin(65))              # 10진수 65 를 2진수로
print(hex(65))              # 10진수 65 를 16진수로
print(chr(65))              # 65 번 글자
```

실행 결과:

```
65
0b1000001
0x41
A
```

- `0b`는 "2진수예요", `0x`는 "16진수예요"라는 표시예요.
- 2진수 `01000001` = 10진수 `65` = 16진수 `41`이고, 컴퓨터 안에서 65는 영문자 `A`의 번호이기도 해요. 같은 값을 사람이 보기 편한 모양으로 바꿔 적을 뿐이에요.

## 3. 프로그래밍 언어의 종류: 컴파일 언어와 인터프리터 언어

강사님이 "구별하는 게 굉장히 중요하고 **개발자 기술 면접에서도 자주 나오는 주제**"라고 강조해요.

### 먼저 알아야 할 단어

| 단어 | 뜻 |
|---|---|
| 소스 코드 | 사람이 읽을 수 있는 프로그래밍 언어로 적은 **텍스트 파일**(글자만 저장된 문서). 윈도우 메모장으로도 쓸 수 있어요 |
| 컴파일 | 소스 코드를 컴퓨터가 실행할 수 있는 **기계어로 변환하는 과정** |
| 컴파일러 | 컴파일을 해 주는 소프트웨어. 언어마다 따로 설치해요 |

소스 코드는 기계어가 아니라서 그대로는 실행이 안 돼요. 그래서 바꿔 주는 과정이 필요해요.

### 컴파일 언어

```
소스 코드  ->  컴파일러  ->(기계어)->  실행 파일(.exe) 저장  ->  컴퓨터를 통한 실행
               (최초 1회만)                  (그 뒤로는 실행 파일만 바로 실행)
```

1. 개발자가 소스 코드를 써요.
2. 컴파일러가 기계어로 바꿔서 **파일로 저장**해요. 이 파일을 **실행 파일**, 또는 기계어로 이뤄졌다고 해서 **바이너리 파일**이라고 해요.
3. 컴파일은 **최초 1회만** 해요. 그다음부터는 저장된 실행 파일을 더블클릭해서 바로 실행해요.
4. 실행할 때 변환 과정이 없으니 **속도가 빠를 수 있어요.** 예: C

### 인터프리터 언어 (= 스크립트 언어)

- **인터프리터**: 소스 코드를 컴파일 과정 없이 바로 실행하는 프로그램이나 환경이에요.
- **인터프리터 언어**: 인터프리터 환경에서 동작하도록 만든 언어예요. 다른 말로 **스크립트 언어**예요.

```
소스 코드  ->  인터프리터(매번 해석 과정을 거침)  ->  컴퓨터를 통한 실행
```

- 동작 과정은 더 간단해 보이지만, 실행할 때마다 **매번** 해석을 거쳐야 해요.
- 그래서 컴파일 언어보다 실행 속도가 **다소 느려요.**

강사님의 비유: MP3 파일은 음악 재생 프로그램이, zip 압축 파일은 압축 해제 프로그램이, 한글(hwp) 문서는 한글 워드 프로세서가 있어야 열 수 있죠. 인터프리터 언어의 소스 코드도 **그 내용을 해석해 줄 전용 프로그램(인터프리터)** 이 있어야 실행돼요. 파이썬을 설치한다는 건 이 파이썬 인터프리터를 설치하는 거예요.

> **강의와 다른 점**: 슬라이드 그림은 인터프리터가 소스 코드를 바로 **기계어**로 바꾼다고 그렸는데, 우리가 설치할 파이썬(CPython)은 정확히는 소스 코드를 먼저 **바이트코드**라는 중간 코드로 바꾸고, 그 바이트코드를 파이썬 가상 머신이 한 줄씩 실행해요. 기계어 파일(실행 파일)을 따로 만들지 않고 매번 파이썬이 대신 실행해 준다는 점은 강의 설명과 같아요. 파이썬 3.14에서 `dis` 모듈로 바이트코드를 직접 확인했어요.
> ```
> $ python3 -c "import dis; dis.dis('print(1 + 2)')"
>   0           RESUME                   0
>
>   1           LOAD_NAME                0 (print)
>               PUSH_NULL
>               LOAD_SMALL_INT           3
>               CALL                     1
>               RETURN_VALUE
> ```
> 기계어(0과 1)가 아니라 파이썬 전용 명령 목록이 나와요. 지금 이 내용을 이해할 필요는 없어요. "파이썬도 속으로는 한 번 바꾼 다음 실행한다" 정도만 알아 두세요.

## 4. 파이썬 소개

### 파이썬은 어떤 언어

- **4세대**로 구분되는 **인터프리터 언어**예요.
- **1991년 귀도 반 로섬(Guido van Rossum)** 이 만들었어요.
- 슬라이드 문구: **"Life is too short, You need Python."** (인생은 짧다. 그래서 당신은 파이썬이 필요하다.) 강사님 풀이로는 "그만큼 배우기 쉽고 빠르다"는 뜻이에요.

> **강의와 다른 점**: 강의에서는 귀도 반 로섬이 파이썬을 만들면서 이 말을 했다고 했지만, 이 말은 귀도가 아니라 프로그래밍 책 작가 **브루스 에켈(Bruce Eckel)** 의 말로 알려져 있어요(원래 문구는 "Life is short (You need Python)"에 가까워요). 우리나라에서는 파이썬 입문서 소개 문구로 널리 퍼졌어요. 파이썬 안에 직접 들어 있는 "파이썬의 철학"은 아래 `import this` 예제로 볼 수 있어요.

### 파이썬의 특징 (슬라이드 정리)

- 프로그래밍 언어 중 가장 쉽고 간결한 문법 → 처음 배우는 사람에게 알맞아요
- 무료지만 강력한 기능 → 강사님 말로 "못하는 게 없어요"
- 빠른 개발 속도 → 배우기 쉬우니 만드는 속도도 빨라요
- 인터프리터 언어
- 객체지향 프로그래밍 (4세대)
- 실행 시간에 실시간으로 자료형 검사 → **변수 선언이 없어요.** 강사님은 이 특징이 초보자의 진입 장벽을 크게 낮춰 준다고 해요.

"변수 선언이 없다"는 말은, 자바나 C처럼 `int x;`로 "x는 정수를 담는 변수예요"라고 미리 적어 두지 않아도 된다는 뜻이에요. 값을 넣는 순간 변수가 생기고, 그 값의 종류(자료형)는 실행할 때 파이썬이 알아서 정해요.

### 예제 (code/no_variable_declaration.py)

강의 밖 실습이에요. `type()`은 그 값의 자료형을 알려 주는 함수예요. 변수와 자료형은 뒤 강의에서 자세히 배워요.

```python
x = 10
print(x, type(x))

x = "파이썬"
print(x, type(x))
```

실행 결과:

```
10 <class 'int'>
파이썬 <class 'str'>
```

- 처음엔 정수(`int`)였던 `x`가 글자를 넣자 문자열(`str`)로 바뀌었어요. 미리 선언하지 않았으니 바꾸는 것도 자유로워요.
- 대신 자료형이 안 맞는 계산은 **실행하는 순간** 에러로 알려 줘요. 예: `print("나이: " + 20)` → `TypeError: can only concatenate str (not "int") to str`

### 파이썬으로 할 수 있는 일

| 분야 | 설명 |
|---|---|
| 운영체제 시스템 유틸리티 | 윈도우의 계산기, 메모장, 그림판 같은 기본 프로그램 |
| GUI 프로그래밍 | GUI는 Graphical User Interface, 창과 버튼으로 쓰는 화면. 다음 단원에서 자세히 설명해요 |
| C/C++과의 결합 | 인터프리터라 느린 부분을 빠른 C나 C++과 묶어 보완. 강사님 말로 "여기까지 다루면 하이레벨" |
| 웹 프로그래밍 | 장고(Django), 플라스크(Flask) 프레임워크 |
| 수치 연산 프로그래밍 | C로 만든 모듈 **NumPy(넘파이, Numeric Python)**. 대학 연구소에서 많이 써요 |
| 데이터베이스 프로그래밍 | |
| 데이터 분석, 사물 인터넷, 인공지능 | |

### 파이썬으로 할 수 없는 일 (강의 기준)

- **모바일 프로그래밍**: 강사님 말로는 모바일은 전용 언어가 있어서 그것만 써야 해요.
- **시스템과 밀접한 영역**: 대단히 빠른 속도가 필요하거나 하드웨어를 직접 제어하는 일

> **강의와 다른 점**: "모바일 프로그래밍은 못한다"는 지금은 조금 달라요. 파이썬 3.13부터 **iOS와 안드로이드가 공식 지원 대상**에 들어갔어요(PEP 730, PEP 738). 파이썬 3.14에서 `platform.ios_ver`, `platform.android_ver` 함수가 들어 있는 것도 확인했어요. 다만 실제 앱 회사들은 여전히 iOS는 Swift, 안드로이드는 Kotlin을 주로 써요. "파이썬은 모바일 앱의 주력 언어가 아니다" 정도로 이해하면 맞아요.

### 방대한 라이브러리

- **라이브러리**는 강사님 말로 쉽게 **"확장팩"** 이에요. 파이썬에 필요한 기능을 추가로 붙이면 파이썬이 더 많은 일을 할 수 있어요.
- 예: **pandas(판다스)** 는 데이터 분석, **matplotlib(맷플롯립)** 은 그래프 그리기. 슬라이드에는 NumPy, SciPy, scikit-learn, Jupyter 등도 보여요.
- 셀 수 없이 많은 라이브러리가 **전부 무료**예요. 개발자가 하나하나 다 만들 필요 없이 있는 라이브러리를 가져다 쓰면 돼서 원하는 결과를 쉽고 빠르게 만들 수 있어요.

슬라이드는 **TIOBE 지수**(tiobe.com/tiobe-index, 프로그래밍 언어 인기 순위를 매달 발표하는 사이트)의 **2023년 1월** 순위예요.

## 자주 하는 실수

### 1) "파이썬 코드는 컴퓨터가 바로 알아듣는다"고 생각함

CPU는 기계어만 이해해요. 파이썬 소스 코드는 **파이썬 인터프리터**가 있어야 실행돼요. 파이썬을 설치하지 않은 컴퓨터에서 `.py` 파일을 더블클릭해도 실행되지 않는 이유예요. (MP3를 들으려면 재생 프로그램이 필요한 것과 같아요.)

### 2) 컴파일 언어와 인터프리터 언어를 거꾸로 외움

| | 컴파일 언어 | 인터프리터 언어 |
|---|---|---|
| 변환 시점 | 실행 전에 **한 번** | 실행할 때마다 **매번** |
| 결과물 | 실행 파일(바이너리) 저장 | 따로 실행 파일을 만들지 않음 |
| 속도 | 빠른 편 | 다소 느린 편 |
| 예 | C | 파이썬 |

"한 번 통째로 번역해서 번역본을 남기면 컴파일, 실행할 때마다 옆에서 해석해 주면 인터프리터"로 기억하세요.

### 3) "고급 언어 = 어려운 언어"로 오해함

여기서 "고급"은 "수준이 높다(어렵다)"가 아니라 "**사람 쪽에 가깝다**"는 뜻이에요. 반대로 기계어처럼 컴퓨터 쪽에 가까운 언어를 저급 언어라고 해요. 고급 언어일수록 사람이 읽기 쉬워요.

### 4) 슬라이드 순위나 "할 수 없는 일"을 영원한 사실로 외움

인기 순위(2023년 1월)와 "모바일은 못 한다" 같은 내용은 시간이 지나면 바뀌어요. 위의 "강의와 다른 점"을 같이 보세요.

## 용어 정리

| 용어 | 쉬운 뜻 |
|---|---|
| 프로그램 | 문제를 해결하려고 처리 방법과 순서를 적어 컴퓨터에 주는 명령 모음 |
| 프로그래밍 언어 | 사람이 컴퓨터에게 명령을 전달하려고 만든 인공 언어 |
| CPU(중앙처리장치) | 컴퓨터의 두뇌. 기계어만 해석할 수 있음 |
| 2진수 | 0과 1 두 숫자만으로 수를 나타내는 방법 |
| 16진수 | 0~9와 A~F, 열여섯 글자로 수를 나타내는 방법 |
| 기계어 | 컴퓨터가 바로 이해하는 2진수의 모음. 1세대 언어 |
| 천공카드 | 구멍을 뚫어 0과 1을 나타낸 종이 카드. 최초의 컴퓨터에 기계어를 넣던 도구 |
| 어셈블리어 | 기계어를 알파벳 기호로 바꾼 2세대 언어 |
| 고급 언어 | 사람이 이해할 수 있는 수준의 언어. 3세대부터 |
| 절차지향 | 코드가 위에서부터 순서대로 실행되는 방식. 3세대의 특징 |
| 객체지향 | 사람의 사고방식에 더 가깝게 자료를 묶어 표현하는 방식. 4세대의 특징 |
| 추상화 | 복잡한 것에서 핵심만 뽑아 단순하게 나타내는 것 |
| 초고급 언어 | 요구사항만 주면 컴퓨터가 스스로 해결하도록 제안된 5세대 개념 |
| 소스 코드 | 사람이 읽을 수 있는 언어로 적은 프로그램 텍스트 파일 |
| 컴파일 / 컴파일러 | 소스 코드를 기계어로 바꾸는 과정 / 그 일을 하는 프로그램 |
| 실행 파일(바이너리 파일) | 컴파일로 만든 기계어 파일. 더블클릭해서 바로 실행 |
| 인터프리터 | 소스 코드를 실행 파일 없이 바로 해석해서 실행해 주는 프로그램 |
| 인터프리터 언어(스크립트 언어) | 인터프리터 환경에서 실행되도록 만든 언어. 파이썬이 여기 속함 |
| 바이트코드 | 파이썬이 소스 코드를 실행하기 전에 바꿔 두는 중간 코드 |
| 변수 선언 | 변수를 쓰기 전에 이름과 자료형을 미리 적어 두는 것. 파이썬은 하지 않음 |
| 자료형 | 값의 종류. 예: 정수(int), 문자열(str) |
| 라이브러리 | 파이썬에 기능을 더해 주는 확장팩. 예: NumPy, pandas, matplotlib |
| 프레임워크 | 프로그램의 뼈대를 미리 갖춰 둔 큰 도구 모음. 예: Django, Flask |
| GUI | Graphical User Interface. 창, 버튼처럼 그림으로 된 화면 |
| TIOBE 지수 | 프로그래밍 언어 인기 순위를 매달 발표하는 지표 |
| 알고리즘 | 문제를 해결하는 단계적 절차. 쉽게 말해 공식 |
| 자료구조 | 많은 데이터를 규칙에 맞게 나열하고 다루는 방법 |
