# 14. 리스트 활용

## 이 강의에서 배우는 것

- 리스트의 인덱싱과 슬라이싱: 문자열과 같은 규칙으로 원소 하나, 또는 구간을 꺼내는 법
- 슬라이싱 구간에 리스트를 대입해서 원소를 교체, 확장, 축소, 삭제하는 법
- 리스트와 함께 쓰는 내장 함수 `len()`, `sorted()`
- 리스트 객체의 메서드: `count`, `index`, `append`, `insert`, `extend`, `pop`, `reverse`, `sort`, 그리고 삭제 키워드 `del`
- 문자열과 리스트를 오가는 `split()`, `join()`
- 리스트의 사촌인 튜플: 소괄호로 만드는 읽기 전용 자료형

> 복습: 지난 13강에서 여러 값을 한 변수에 담는 리스트를 배웠어요. 이번엔 그 리스트를 실제로 써먹는 방법들을 배워요. 강사님 말대로 리스트도 문자열과 특성이 비슷해서, 09강에서 배운 인덱싱과 슬라이싱 규칙이 그대로 적용돼요.

## 1. 리스트의 인덱싱

**인덱싱**은 인덱스 번호로 리스트의 **원소 하나**에 접근하는 거예요. 문자열과 똑같이 번호는 **0부터** 시작해요.

- 원소를 출력하거나, 다른 변수에 복사하거나, 특정 원소의 값을 바꾸는 것 모두 인덱싱이에요.
- 인덱싱의 결과는 리스트가 아니라 **원소 값 하나**예요.
- **마이너스 인덱스**도 돼요. 뒤에서부터 `-1`, `-2`, ... 로 세요.

```
mylist =  [ 10,  20,  30,  40,  50 ]
인덱스       0    1    2    3    4
마이너스    -5   -4   -3   -2   -1
```

### 예제 (code/list_indexing.py)

```python
mylist = [10, 20, 30, 40, 50]
print(mylist)

print(mylist[1])     # 1번째 원소 (0부터 세요)
print(mylist[-1])    # -1번째 원소 (맨 뒤)

grade = [92, 83, 96]
eng = grade[1]       # 1번째 원소를 다른 변수에 복사
print(eng)
grade[2] = 88        # 2번째 원소의 값을 변경
print(grade)
```

실행 결과:

```
[10, 20, 30, 40, 50]
20
50
83
[92, 83, 88]
```

강사님은 인덱싱은 지난 시간에 본 거라 "크게 특별히 어려운 거 없다"고 하고 넘어가요.

## 2. 리스트의 슬라이싱

**슬라이싱**은 연속된 자료에서 **구간**을 정해 잘라내는 거예요. `리스트[시작:끝]`으로 쓰고, 규칙은 문자열 슬라이싱과 같아요.

- **시작 위치는 포함, 끝 위치는 포함 안 돼요.** 끝 위치의 바로 왼쪽 원소까지만 잘라요.
- 시작을 비우면 처음부터, 끝을 비우면 마지막까지예요. `[:]`는 전체예요.
- **슬라이싱의 결과는 항상 새 리스트예요.** 강사님이 "중요 포인트로 기억하라"고 짚은 부분이에요.

### 예제 (code/list_slicing.py)

```python
mylist = [60, 70, 80, 90, 100]

print(mylist[1:3])    # 1번째부터 3번째 전까지
print(mylist[:3])     # 처음부터 3번째 전까지
print(mylist[3:])     # 3번째부터 끝까지
print(mylist[:])      # 모든 원소
print(mylist[1:-2])   # 1번째부터 -2번째 전까지

part = mylist[1:3]
print(type(part))
```

실행 결과:

```
[70, 80]
[60, 70, 80]
[90, 100]
[60, 70, 80, 90, 100]
[70, 80]
<class 'list'>
```

### 플러스와 마이너스를 섞어 쓸 때

`mylist[1:-2]`는 1번째(70)부터 -2번째(90) **전**까지라서 `[70, 80]`이에요. 강사님도 "잘 쓰는 표현은 아니다"라고 했어요. 마이너스를 써도 규칙은 같아요. **끝 위치 원소의 왼쪽까지만** 잘라요.

> **강의와 다른 점**: 강의에서는 `mylist[1:-2]`를 "1번째부터 뒤에서 2번째 **다음까지**"라고 설명하고 화면 주석에도 그렇게 적었어요. 하지만 -2번째인 90은 결과에 없어요(`[70, 80]`, 3.14에서 실행해 확인). "다음까지"보다는 화면 주석 셋째 줄처럼 "끝 위치 인덱스의 왼쪽 원소까지"로 기억하는 게 덜 헷갈려요.

## 3. 슬라이싱으로 교체, 확장, 축소, 삭제하기

슬라이싱으로 정한 구간에 `=`로 **리스트를 대입**하면 그 구간이 통째로 바뀌어요. 넣는 리스트의 길이에 따라 결과가 달라져요.

`data = [100, 200, 300, 400, 500]`에서 `data[1:4]`는 200, 300, 400 세 개예요.

| 넣는 리스트 | 이름 | 결과 |
|---|---|---|
| 같은 길이(3개) `[2, 3, 4]` | 교체 | `[100, 2, 3, 4, 500]` |
| 더 긴 길이(6개) `[2, 3, 4, 5, 6, 7]` | 확장 | `[100, 2, 3, 4, 5, 6, 7, 500]` |
| 더 짧은 길이(1개) `[2]` | 축소 | `[100, 2, 500]` |
| 빈 리스트 `[]` | 삭제 | `[100, 500]` |

### 예제 (code/list_slice_assign.py)

```python
data = [100, 200, 300, 400, 500]
data[1:4] = [2, 3, 4]            # 교체
print(data)

data = [100, 200, 300, 400, 500]
data[1:4] = [2, 3, 4, 5, 6, 7]   # 확장
print(data)

data = [100, 200, 300, 400, 500]
data[1:4] = [2]                  # 축소
print(data)

data = [100, 200, 300, 400, 500]
data[1:4] = []                   # 삭제
print(data)
```

실행 결과:

```
[100, 2, 3, 4, 500]
[100, 2, 3, 4, 5, 6, 7, 500]
[100, 2, 500]
[100, 500]
```

빈 리스트를 넣으면 "구간을 대체할 게 없으니" 그 자리가 비고 뒤에 있던 원소가 앞으로 당겨져서, 결국 **삭제 효과**가 나요.

> **강의와 다른 점**: 슬라이드에는 원래 있던 원소가 "삽입되는 리스트의 길이만큼" 뒤로 밀려나거나 앞으로 당겨진다고 적혀 있어요. 실제로는 **구간 길이와 넣는 리스트 길이의 차이만큼** 움직여요. 확장 예에서 500은 인덱스 4에서 7로 3칸(6 - 3) 밀렸고, 축소 예에서는 4에서 2로 2칸(3 - 1) 당겨졌어요(`data.index(500)`으로 3.14에서 확인).

## 4. 리스트와 함께 쓰는 내장 함수: len, sorted

강사님 말대로 이 부분부터는 "함수를 부르면 결과가 이렇게 된다"를 확인하는 내용이라 코드 위주로 봐요.

### len(): 길이 조회

`len(리스트)`는 원소 개수, 즉 **길이**를 돌려줘요. 문자열에서도 썼던 함수고, 강사님이 "굉장히 많이 쓰는 기능"이라고 강조해요.

> **강의와 다른 점**: 강의에서는 `len`이 "파라미터로 전달되는 것의 형태가 무엇이든 간에 일단 뭐라도 카운트해 준다"고 했는데, 숫자처럼 길이가 없는 값은 셀 수 없어요. `len(5)`는 에러예요(3.14에서 확인).
> ```
> TypeError: object of type 'int' has no len()
> ```
> 문자열, 리스트, 튜플처럼 여러 개가 모인 값에만 써요.

### sorted(): 정렬된 복사본 만들기

- `sorted(리스트)`: 작은 것부터 큰 것 순서(**순차 정렬, 오름차순**)로 정렬해요.
- `sorted(리스트, reverse=True)`: 큰 것부터(**역순 정렬, 내림차순**) 정렬해요.
- **원본은 그대로**이고, 정렬된 **복사본**을 새로 돌려줘요. 그래서 결과를 `asc`, `desc` 같은 변수에 받아요.

### 예제 (code/list_builtin_functions.py)

```python
mylist = [1, 2, 3]
print(len(mylist))

mylist = [4, 2, 5, 3, 1]
print(mylist)

asc = sorted(mylist)                  # 오름차순 복사본
print(asc)

desc = sorted(mylist, reverse=True)   # 내림차순 복사본
print(desc)

print(mylist)                         # 원본은 그대로
```

실행 결과:

```
3
[4, 2, 5, 3, 1]
[1, 2, 3, 4, 5]
[5, 4, 3, 2, 1]
[4, 2, 5, 3, 1]
```

강사님: 정렬도 "엄청나게 많이 쓰는 기능"이라 결과를 잘 확인해 두라고 해요.

## 5. 리스트 메서드 (1) 개수 세기와 위치 찾기: count, index

리스트도 파이썬의 **객체**라서 안에 여러 **메서드**(객체가 가진 함수)가 들어 있어요. `리스트.메서드()`처럼 점을 찍고 불러요.

- `리스트.count(값)`: 그 값이 **몇 번** 들어 있는지 세요.
- `리스트.index(값)`: 그 값이 **처음 나오는 위치**(인덱스)를 찾아요.

### 예제 (code/list_count_index.py)

```python
mylist = [1, 2, 3, 2, 4, 2]
c = mylist.count(2)     # 2가 몇 번 나오나
print(c)

mylist = [1, 2, 3, 10, 1, 2, 3, 10]
x = mylist.index(10)    # 10이 처음 나오는 위치
print(x)

if 5 in mylist:
    print(mylist.index(5))
else:
    print("5는 리스트에 없어요")
```

실행 결과:

```
3
3
5는 리스트에 없어요
```

10은 두 번 나오지만 `index`는 **가장 처음** 나온 자리(인덱스 3)만 알려 줘요.

### 없는 값을 찾으면 에러

강사님이 직접 실행해서 보여 준 부분이에요. 12강에서 배운 문자열의 `find()`는 못 찾으면 `-1`을 돌려줬지만, 리스트의 `index()`는 **에러가 나요.**

```python
y = mylist.index(5)
```

> **강의와 다른 점**: 강의 화면(Python 3.11.1)의 에러 문구는 `ValueError: 5 is not in list`인데, 3.14에서 실행하면 문구가 이렇게 나와요.
> ```
> ValueError: list.index(x): x not in list
> ```
> 에러 종류(ValueError)와 뜻("리스트에 없다")은 같아요.

> **참고(강의 밖 내용)**: 에러를 피하고 싶으면 위 예제처럼 `값 in 리스트`로 먼저 들어 있는지 확인한 뒤 `index`를 부르면 돼요. `in`은 들어 있으면 `True`, 없으면 `False`예요.

## 6. 리스트 메서드 (2) 원소 추가: append, insert, extend

강사님: 원소 추가는 "진짜 많이 사용"하는 기능이에요. 세 메서드 모두 **원본이 직접 바뀌어요.**

| 메서드 | 하는 일 |
|---|---|
| `append(값)` | 맨 뒤에 원소 하나 추가 |
| `insert(위치, 값)` | 그 위치에 넣고, 원래 있던 원소는 뒤로 한 칸씩 밀림 |
| `extend(리스트)` | 다른 리스트의 원소들을 하나씩 맨 뒤에 덧붙임(리스트 결합) |

### append에 리스트를 넣으면 통째로 원소 하나

`mylist.append([5, 6])`을 하면 5와 6이 따로 들어가는 게 아니라 `[5, 6]` 리스트가 **원소 하나**로 들어가요(리스트 안의 리스트, 2차 리스트). 5와 6을 하나씩 넣고 싶으면 강사님 말대로 `append`를 두 번 쓰거나, 아래의 `extend`를 써요.

### insert로 맨 앞, 맨 뒤에 넣기

- 맨 앞: `insert(0, 값)`
- 맨 뒤: `insert(len(리스트), 값)` → `append`와 같은 효과

강사님은 처음에 "맨 마지막 인덱스"인 `len(mylist) - 1`을 넣어 봤는데, 그러면 원래 마지막에 있던 3이 뒤로 밀려서 `[1, 2, 10, 3]`이 됐어요. `- 1`을 빼고 `len(mylist)`를 넣어야 맨 뒤에 붙어요. `insert`는 "그 자리에 있던 원소 **앞**에 끼워 넣는다"고 생각하면 쉬워요.

### extend는 + 와 결과가 같아요

`mylist.extend(addon)`은 `mylist + addon`과 결과가 같아요. 차이는 `extend`는 **원본 `mylist`를 바꾸고**, `+`는 새 리스트를 만든다는 점이에요.

### 예제 (code/list_add_items.py)

```python
mylist = [1, 2, 3]
mylist.append(4)
print(mylist)

mylist = [1, 2, 3]
mylist.append([5, 6])
print(mylist)

mylist = [1, 2, 3]
mylist.insert(1, 10)
print(mylist)

mylist = [1, 2, 3]
mylist.insert(0, 10)
print(mylist)

mylist = [1, 2, 3]
mylist.insert(len(mylist) - 1, 10)
print(mylist)

mylist = [1, 2, 3]
last_index = len(mylist)
mylist.insert(last_index, 10)
print(mylist)

mylist = [1, 2, 3]
addon = [10, 9, 8, 7]
mylist.extend(addon)
print(mylist)

print([1, 2, 3] + addon)
```

실행 결과:

```
[1, 2, 3, 4]
[1, 2, 3, [5, 6]]
[1, 10, 2, 3]
[10, 1, 2, 3]
[1, 2, 10, 3]
[1, 2, 3, 10]
[1, 2, 3, 10, 9, 8, 7]
[1, 2, 3, 10, 9, 8, 7]
```

> **강의와 다른 점**: 강의 화면의 "맨 앞에 삽입" 셀은 주석에 "0번째 위치에 **100**을 삽입"이라고 적혀 있지만 코드는 `mylist.insert(0, 10)`이라 실제 결과는 `[10, 1, 2, 3]`이에요. 주석과 코드가 어긋난 거라, 위 예제는 코드 기준(10)으로 맞췄어요.

> 강의 화면 변수 이름은 `lastIndex`였는데, 파이썬은 보통 변수 이름을 `last_index`처럼 소문자와 밑줄(snake_case)로 써서 예제는 그렇게 바꿨어요. 결과는 같아요.

## 7. 원소 삭제와 추출: del, pop

### del: 단순 삭제

`del 리스트[위치]`로 그 위치의 원소를 지워요.

> **강의와 다른 점**: 강의에서는 `del`을 "내장 함수"라고 하고 `del(mylist[1])`처럼 괄호를 써서 보여 줬어요. 하지만 `del`은 함수가 아니라 `if`, `for` 같은 파이썬 **키워드(예약어)** 예요(`keyword.kwlist`에 `'del'`이 들어 있고, `print(del)`은 SyntaxError, 3.14에서 확인). 괄호를 써도 되는 건 괄호가 그냥 묶음 표시로 읽히기 때문이고, 보통은 `del mylist[1]`처럼 괄호 없이 써요. 결과는 둘 다 `[1, 3]`이에요.

> **참고(강의 밖 내용)**: 3번에서 본 슬라이싱 삭제와도 연결돼요. `del data[1:4]`처럼 구간을 주면 `data[1:4] = []`와 똑같이 `[100, 500]`이 돼요.

### pop: 꺼내고 지우기

`리스트.pop()`은 **맨 마지막 원소를 꺼내서 돌려주고**, 원본에서는 지워요. 꺼낸 값을 변수(`k`)에 받아 쓸 수 있다는 점이 `del`과 달라요.

강사님은 추출에 "맨 마지막 거를 꺼내는 방법과 맨 앞에 거를 꺼내는 방법 두 가지가 있다"고 했는데, 실습에서는 맨 마지막을 꺼내는 `pop()`만 보여 줬어요.

> **참고(강의 밖 내용)**: 맨 앞을 꺼내려면 `pop(0)`처럼 위치를 넣어요. 위치를 주면 그 자리의 원소를 꺼내요. 빈 리스트에서 `pop()`을 하면 `IndexError: pop from empty list` 에러가 나요.

### 예제 (code/list_remove_items.py)

```python
mylist = [1, 2, 3]
del mylist[1]
print(mylist)

mylist = [1, 2, 3]
k = mylist.pop()     # 맨 마지막 원소를 꺼내요
print(k)
print(mylist)

mylist = [1, 2, 3]
first = mylist.pop(0)   # 맨 앞 원소를 꺼내요 (강의 밖 내용)
print(first)
print(mylist)
```

## 8. 리스트 재배치: reverse, sort

- `리스트.reverse()`: 지금 순서를 **거꾸로 뒤집어요.** 크기 순으로 정렬하는 게 아니에요. `[1, 7, 5, 3, 9]` → `[9, 3, 5, 7, 1]`
- `리스트.sort()`: 오름차순(순차 정렬)으로 정렬해요.
- `리스트.sort(reverse=True)`: 내림차순(역순 정렬)으로 정렬해요.

**내장 함수 `sorted()`와의 차이**가 중요해요. 강사님이 짚은 부분이에요.

| | `sorted(리스트)` | `리스트.sort()` |
|---|---|---|
| 종류 | 내장 함수 | 리스트 메서드 |
| 원본 | 그대로 | **원본이 바뀜** |
| 돌려주는 값 | 정렬된 복사본 | `None`(아무것도 없음) |

> **강의와 다른 점**: 강의에서는 `sort` 메서드가 "객체 자체가 반환된다"고 했는데, 정확히는 **원본 리스트 자체가 정렬되고**, 돌려주는 값은 `None`이에요(`print(mylist.sort())`가 `None`, 3.14에서 확인). 그래서 `result = mylist.sort()`처럼 받아 쓰면 안 되고, 정렬 뒤에 `mylist`를 그대로 쓰면 돼요.

### 예제 (code/list_reorder.py)

```python
mylist = [1, 7, 5, 3, 9]
mylist.reverse()
print(mylist)

mylist = [2, 5, 1, 4, 3]
mylist.sort()
print(mylist)

mylist = [2, 5, 1, 4, 3]
mylist.sort(reverse=True)
print(mylist)

mylist = [2, 5, 1, 4, 3]
result = mylist.sort()
print(result)
```

실행 결과:

```
[9, 3, 5, 7, 1]
[1, 2, 3, 4, 5]
[5, 4, 3, 2, 1]
None
```

## 9. 문자열과 리스트 오가기: split, join

두 개 다 사실 **문자열의 메서드**예요. 결과가 리스트이거나 리스트를 다루기 때문에 강사님이 여기서 소개했어요.

### split: 문자열 → 리스트

`문자열.split(기준 글자)`는 기준 글자로 문자열을 잘라서 **리스트**로 돌려줘요. `"Hello,Python,World,Good".split(",")` → `['Hello', 'Python', 'World', 'Good']`

### join: 리스트 → 문자열

`split`의 반대예요. `연결할문자열.join(리스트)`처럼 **연결할 기호를 앞에** 쓰고, 리스트를 괄호 안에 넣어요. 앞의 문자열이 리스트 원소 **사이사이에 끼어들어**(join에 참여해서) 완전히 이어진 **문자열 하나**를 돌려줘요.

- `"/"`면 `Hello/Python/World/Good`
- `""`(빈 문자열, 따옴표를 열자마자 닫은 것)면 기호 없이 `HelloPythonWorldGood`
- `" "`(띄어쓰기 하나)면 `Hello Python World Good`
- 강사님 말대로 꼭 슬래시일 필요 없어요. `$`, `~` 무엇이든 돼요.

### 예제 (code/split_join.py)

```python
text = "Hello,Python,World,Good"
mylist = text.split(",")
print(mylist)

slash = "/"
mylist = ['Hello', 'Python', 'World', 'Good']
text = slash.join(mylist)
print(text)

space = ""
text = space.join(mylist)
print(text)

space2 = " "
text = space2.join(mylist)
print(text)

print("$".join(mylist))
print("~".join(mylist))
```

실행 결과:

```
['Hello', 'Python', 'World', 'Good']
Hello/Python/World/Good
HelloPythonWorldGood
Hello Python World Good
Hello$Python$World$Good
Hello~Python~World~Good
```

> **참고(강의 밖 내용)**: `join`에 넣는 리스트의 원소는 **전부 문자열**이어야 해요. 숫자가 섞이면 에러가 나요(3.14에서 확인).
> ```python
> "/".join(['a', 1])   # TypeError: sequence item 1: expected str instance, int found
> ```

## 10. 튜플

**튜플**은 리스트와 거의 똑같은 자료구조인데, 두 가지가 달라요.

| | 리스트 | 튜플 |
|---|---|---|
| 만드는 괄호 | 대괄호 `[1, 2, 3]` | **소괄호** `(1, 2, 3)` |
| 원소 값 바꾸기 | 됨 | **안 됨(읽기 전용)** |

- 숫자, 문자열 모두 원소가 될 수 있고, 자료형을 **섞어서** 만들 수도 있어요.
- 인덱싱, 슬라이싱 규칙이 그대로 적용돼요. 슬라이싱 결과는 새 튜플이에요.
- 한 번 만들면 원소를 바꿀 수 없어서 **읽기 전용**이라고 불러요. 값을 바꾸려 하면 에러가 나요.

```python
stud1[0] = "철호"
```

```
TypeError: 'tuple' object does not support item assignment
```

"튜플 객체는 원소에 값을 대입하는 걸 지원하지 않는다"는 뜻이에요.

강사님은 리스트가 할 수 있는 일이 큰 상자라면 튜플은 그 안의 작은 상자라고 그림으로 설명했어요. 튜플로 할 수 있는 건 리스트로 다 할 수 있지만 반대는 안 되는 경우가 많아서, 강사님은 개인적으로 "평소에 튜플을 전혀 사용하지 않는다"고 해요. 그래도 알아는 둬야 해서 간단히 정리했고, 중요도가 높지 않아 학습 정리에도 넣지 않았다고 해요.

> **참고(강의 밖 내용)**: 슬라이드에는 튜플의 메서드도 "모두 동일하다(값의 변경이 발생하는 함수는 제외)"고 적혀 있어요. 실제로 튜플이 가진 일반 메서드는 `count`와 `index` 두 개뿐이에요(3.14에서 `dir(())`로 확인). `append`, `sort` 같은 건 없어서 `AttributeError`가 나요. `len()`, `sorted()` 같은 내장 함수는 튜플에도 쓸 수 있어요(`sorted`는 결과를 리스트로 돌려줘요).

### 예제 (code/tuple_basics.py)

```python
grade = (98, 82, 73, 64, 100)
print(grade)

names = ("철수", "영희", "나영", "민식", "호영")
print(names)

stud1 = ("철수", 98)      # 자료형을 섞어도 돼요
print(stud1)

print(stud1[0])
print(stud1[1])

print(grade[1:3])         # 슬라이싱도 돼요
```

실행 결과:

```
(98, 82, 73, 64, 100)
('철수', '영희', '나영', '민식', '호영')
('철수', 98)
철수
98
(82, 73)
```

> **참고(강의 밖 내용)**: 강의 노트북 오른쪽 위에 보이는 실행 버전은 Python 3.11.1이에요. 이 노트의 예제는 Python 3.14에서 다시 실행했고, 위에 따로 적은 `index` 에러 문구 말고는 결과가 화면과 같아요.

## 자주 하는 실수

### 1) 슬라이싱 끝 위치까지 포함된다고 생각함

```python
mylist = [60, 70, 80, 90, 100]
print(mylist[1:3])    # [70, 80]  (3번째인 90은 안 들어가요)
```

### 2) 없는 값을 index로 찾음

```python
mylist = [1, 2, 3]
mylist.index(5)       # ValueError (문자열 find처럼 -1이 나오지 않아요)
if 5 in mylist:       # 먼저 있는지 확인해요
    print(mylist.index(5))
```

### 3) 두 원소를 넣으려고 리스트를 append 함

```python
mylist = [1, 2, 3]
mylist.append([5, 6])   # [1, 2, 3, [5, 6]]  (통째로 원소 하나)
mylist = [1, 2, 3]
mylist.extend([5, 6])   # [1, 2, 3, 5, 6]
```

### 4) insert로 맨 뒤에 넣으려고 len - 1 을 씀

```python
mylist = [1, 2, 3]
mylist.insert(len(mylist) - 1, 10)   # [1, 2, 10, 3]  (마지막 원소 앞)
mylist = [1, 2, 3]
mylist.insert(len(mylist), 10)       # [1, 2, 3, 10]  (append와 같음)
```

### 5) sort의 결과를 변수에 받음

```python
mylist = [2, 5, 1]
result = mylist.sort()
print(result)            # None
print(sorted([2, 5, 1])) # [1, 2, 5]  (결과를 받아 쓰려면 sorted)
```

### 6) reverse를 내림차순 정렬로 착각함

```python
mylist = [1, 7, 5, 3, 9]
mylist.reverse()             # [9, 3, 5, 7, 1]  (순서만 뒤집혀요)
mylist.sort(reverse=True)    # [9, 7, 5, 3, 1]  (큰 것부터 정렬)
```

### 7) join 앞뒤를 바꿔 씀

```python
mylist = ['Hello', 'Python']
"/".join(mylist)    # 'Hello/Python'  (연결 기호가 앞, 리스트가 괄호 안)
# mylist.join("/")  # AttributeError: 리스트에는 join 메서드가 없어요
```

### 8) 튜플 원소를 바꾸려 함

## 용어 정리

| 용어 | 쉬운 뜻 |
|---|---|
| 원소 | 리스트 안에 들어 있는 값 하나하나 |
| 인덱싱 | 인덱스 번호로 원소 하나에 접근하는 것 |
| 슬라이싱 | `[시작:끝]`으로 구간을 잘라 새 리스트를 만드는 것 |
| 마이너스 인덱스 | 뒤에서부터 -1, -2, ... 로 세는 번호 |
| 내장 함수 | 파이썬에 처음부터 들어 있어서 바로 쓰는 함수. 예: `len()`, `sorted()` |
| 메서드 | 객체가 가진 함수. `리스트.append()`처럼 점을 찍고 불러요 |
| 오름차순(순차 정렬) | 작은 것부터 큰 것 순서로 정렬 |
| 내림차순(역순 정렬) | 큰 것부터 작은 것 순서로 정렬 |
| 복사본 | 원본은 그대로 두고 새로 만든 같은 내용의 값 |
| 2차 리스트 | 리스트 안에 리스트가 원소로 들어간 것 |
| 키워드(예약어) | 파이썬이 문법용으로 정해 둔 단어. `del`, `if`, `for` 등 |
| 빈 문자열 | 따옴표를 열자마자 닫은 `""`. 글자가 하나도 없는 문자열 |
| 튜플(tuple) | 소괄호로 만드는, 원소를 바꿀 수 없는(읽기 전용) 리스트 |
| ValueError | 값 에러. 예: 리스트에 없는 값을 `index()`로 찾을 때 |
| TypeError | 자료형 에러. 예: 튜플 원소에 값을 대입할 때 |
