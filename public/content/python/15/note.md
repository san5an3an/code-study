# 15. 딕셔너리

## 이 강의에서 배우는 것

- 딕셔너리가 무엇인지: 이름(key)과 값(value)이 쌍을 이루는 자료구조
- 딕셔너리 만들기, 이름으로 값 꺼내기, 값 바꾸기, `del`로 지우기
- 딕셔너리를 쓸 때 규칙: 없는 키를 꺼내면 에러, 없는 키에 넣으면 추가, 키가 겹치면 마지막 것만 남음
- 딕셔너리 안에 리스트나 딕셔너리를 넣어 정보를 계층으로 표현하기
- 헷갈리기 쉬운 두 구조: 딕셔너리를 원소로 갖는 리스트, 리스트를 원소로 갖는 딕셔너리
- 내장함수 `len()`과 딕셔너리 메서드 `get()`, `keys()`, `values()`, `items()`

> 복습: 지난 강의들에서 문자열, 리스트, 튜플처럼 값을 줄지어 담는 자료형(강의에서는 "연속성 자료형"이라고 불러요)을 배웠어요. 오늘은 그 마지막으로 딕셔너리를 배워요. 강사님은 데이터 분석을 할 생각이 있는 사람은 특히 더 신경 써서 공부하라고 강조해요. 나중에 배우는 데이터 분석의 기본 단위인 **데이터 프레임(DataFrame)** 을 만드는 원료로 딕셔너리가 쓰이기 때문이에요.

## 1. 딕셔너리란

**딕셔너리(dictionary)** 는 우리말로 "사전"이에요. 사전에서 단어를 찾으면 뜻이 나오듯, 딕셔너리는 **이름**을 대면 그 이름에 붙은 **값**이 나와요.

### 기본 형식

- **중괄호(`{ }`)** 를 써요.
- 리스트나 튜플처럼 **쉼표(`,`)** 로 값을 구별해요.
- 리스트와 튜플은 값만 나열하지만, 딕셔너리는 **`이름: 값`** 형태로 나열해요. 이게 가장 핵심이에요.

```python
{ "이름": "값", "이름": "값", ..., "이름": "값" }
```

- 이 이름을 **키(key)**, 값을 **밸류(value)** 라고 불러요. 그래서 보통 딕셔너리를 "key와 value의 쌍으로 구성된 자료구조"라고 설명해요.
- 강사님은 수업에서 편하게 "이름과 값"이라고 부르지만, 다른 책으로 공부할 때는 key와 value라는 말로 바꿔서 알아들어야 한다고 해요.
- 값이 문자열이면 당연히 따옴표가 있어야 하고, 숫자 같은 다른 값은 따옴표가 필요 없어요(강사님 필기: "문자열 → 따옴표, 그 외 → X").

> **강의와 다른 점**: 강의에서는 "이름(key)은 항상 따옴표로 감싸야 한다"고 했는데, 꼭 그렇지는 않아요. 숫자나 튜플도 키가 될 수 있어요. 다만 리스트처럼 내용이 바뀔 수 있는 값은 키가 될 수 없어요(python3 3.14로 확인).
> ```python
> d = {1: "one", (1, 2): "tuple"}
> print(d[1])        # one
> # {[1, 2]: "x"}    # TypeError: cannot use 'list' as a dict key (unhashable type: 'list')
> ```
> 처음 배울 때는 강의처럼 문자열 키를 쓰는 게 가장 흔하고 읽기도 쉬워요.

### 값에 리스트 넣기

값에는 지금까지 배운 모든 자료형(정수, 실수, 문자열, 논리값)이 들어갈 수 있고, 리스트와 튜플도 들어갈 수 있어요. 강사님 말로는 튜플은 거의 안 쓰니까 사실상 리스트예요.

```python
{ "이름": [값0, 값1, 값2] }
```

이렇게 하면 **하나의 key에 여러 개의 value를 지정하는 효과**가 나요.

## 2. 딕셔너리 만들기와 원소 다루기

### 만들기

```python
mydic = {"name": "철수", "phone": "010-1234-5678", "birth": "0115"}
```

### 특정 원소에 접근하기

딕셔너리의 원소에 접근할 때는 **이름**을 써요. 그리고 이름을 **대괄호(`[ ]`)** 로 감싸요. 리스트가 번호(인덱스)로 꺼냈다면, 딕셔너리는 이름으로 꺼내는 거예요.

```python
print(mydic["name"])   # 철수
```

꺼낸 값을 다른 변수에 복사할 수도 있어요.

```python
phone = mydic["phone"]
```

### 값 바꾸기

이름을 써서 새 값을 넣으면 값이 바뀌어요.

```python
mydic["name"] = "호영"
```

### 지우기

리스트에서 봤던 `del`을 딕셔너리에도 그대로 쓸 수 있어요.

```python
del mydic["birth"]   # key가 birth인 데이터를 지워요
```

> **강의와 다른 점**: 강의에서는 `del`을 "함수"라고 불렀고 화면에도 `del (mydic["birth"])`처럼 괄호를 썼어요. 실제로 `del`은 함수가 아니라 파이썬의 **예약어(키워드)** 예요. `keyword.iskeyword("del")`이 `True`로 나와요(python3로 확인). 괄호를 써도 동작은 하지만 필요 없어서 보통 `del mydic["birth"]`처럼 써요.

### 예제 (code/dict_basics.py)

```python
mydic = {"name": "철수", "phone": "010-1234-5678", "birth": "0115"}
print(mydic)

print(mydic["name"])

phone = mydic["phone"]
print(phone)

mydic["name"] = "호영"
print(mydic)

del mydic["birth"]
print(mydic)
```

실행 결과:

```
{'name': '철수', 'phone': '010-1234-5678', 'birth': '0115'}
철수
010-1234-5678
{'name': '호영', 'phone': '010-1234-5678', 'birth': '0115'}
{'name': '호영', 'phone': '010-1234-5678'}
```

출력할 때 파이썬은 따옴표를 홑따옴표(`'`)로 바꿔서 보여 줘요. 쌍따옴표로 만들었어도 같은 값이에요.

> **참고(강의 밖 내용)**: 강의는 주피터 노트북이라 셀 마지막 줄에 `mydic`만 써도 내용이 보였어요. `.py` 파일로 실행할 때는 `print(mydic)`처럼 꼭 `print`를 써야 보여요.

## 3. 딕셔너리를 쓸 때 지켜야 할 규칙

> **강의와 다른 점**: 실습 노트북의 제목이 "리스트 사용 제약"으로 적혀 있는데, 내용은 **딕셔너리** 사용 제약이에요. 제목만 잘못 적힌 거예요.

### 1) 없는 키의 값을 꺼내면 에러

```python
print(mydic["weight"])
```

```
KeyError: 'weight'
```

"weight라는 키가 없다"는 뜻이에요. 강사님 말대로 메시지가 굉장히 직관적이죠.

### 2) 없는 키에 값을 넣으면 그 즉시 추가(확장)

꺼내는 건 에러지만, **넣는 건** 에러가 아니에요. 그 자리에서 새 항목이 생겨요.

```python
mydic["height"] = 175
```

### 3) 키가 중복되면 하나만 남음

같은 키를 여러 번 적으면 하나를 뺀 나머지는 무시돼요. **가장 마지막에 적은 항목이 앞의 것을 덮어써요.** 그래서 딕셔너리는 중복을 허용하지 않는데, 이때 중복의 기준은 **키**예요(값이 같은 건 상관없어요).

### 예제 (code/dict_rules.py)

```python
mydic = {"name": "호영", "phone": "010-1234-5678"}

# print(mydic["weight"])   # KeyError: 'weight'

mydic["height"] = 175
print(mydic)

data = {"msg": "hello", "msg": "world", "msg": "python"}
print(data["msg"])
print(data)
```

실행 결과:

```
{'name': '호영', 'phone': '010-1234-5678', 'height': 175}
python
{'msg': 'python'}
```

`msg`를 세 번 넣었는데 마지막 `python` 하나만 남았어요. 에러도 나지 않아서 실수로 키를 겹쳐 쓰면 모르고 지나가기 쉬워요.

> **참고(강의 밖 내용)**: 덮어쓸 때 값은 마지막 것으로 바뀌지만 자리는 처음 나온 자리 그대로예요. `{"a": 1, "b": 2, "a": 3}`을 출력하면 `{'a': 3, 'b': 2}`가 나와요(python3로 확인).

## 4. 정보의 계층적 표현 (딕셔너리 안에 딕셔너리, 리스트)

딕셔너리의 값에는 **모든 형태의 데이터**를 넣을 수 있어요. 정수, 실수, 문자열, 논리값, 리스트, 그리고 **딕셔너리**까지요. 값에 또 딕셔너리를 넣으면 데이터의 **계층 구조**가 만들어져요. 2차원 리스트랑 비슷하게 보면 돼요.

강사님 비유로는 **폴더 안에 또 다른 폴더를 넣고, 그 안에 파일을 넣는 구조**예요.

### 따로 만든 딕셔너리를 값으로 넣기 (슬라이드 예)

```python
addressData = {"addr1": "서울특별시 ...", "addr2": "123-4"}
bodyData = {"height": 175, "weight": 80}
student = {"address": addressData, "body": bodyData}
```

`student`의 `address` 안에 딕셔너리가, `body` 안에 또 딕셔너리가 들어간 구조예요.

### 처음부터 한 번에 계층화하기

보통은 변수를 따로 만들어 넣지 않고, 2차원 리스트를 정의할 때처럼 **처음부터 한 번에** 계층으로 적어요. 줄바꿈과 띄어쓰기를 잘 넣어서 보기 좋은 코드를 만들면 돼요.

```python
student = {
    "address": {
        "addr1": "서울특별시 ...",
        "addr2": "123-4"
    },
    "body": {
        "height": 175,
        "weight": 80
    }
}
```

강사님 팁: VS Code에서 줄 번호와 코드 사이에 마우스를 올리면 아래 방향 화살표(`v`)가 보여요. 누르면 그 블록이 접혀요. 몇 번 접었다 폈다 하면 코드의 계층 구조를 파악하기 쉬워요.

### 계층화된 값에 접근하기

**바깥부터 한 단계씩 차근차근** 들어가면 돼요. 들어간 곳이 리스트면 리스트 규칙(번호), 딕셔너리면 딕셔너리 규칙(이름)을 따라요.

```python
member["addr"][0]          # member의 addr → 리스트니까 0번째
member["grade"]["korean"]  # member의 grade → 딕셔너리니까 korean
```

### 예제 (code/dict_nested.py)

```python
addressData = {"addr1": "서울특별시 ...", "addr2": "123-4"}
bodyData = {"height": 175, "weight": 80}
student = {"address": addressData, "body": bodyData}
print(student)

addr = ["서울", "서초구", "강남대로"]
grade = {"korean": 98, "math": 77, "english": 82}
member = {
    "userid": "python",   # 문자열 데이터
    "age": 20,            # 정수형 데이터
    "addr": addr,         # 리스트 데이터
    "grade": grade        # 딕셔너리 데이터
}
print(member)

print(member["addr"][0])
print(member["grade"]["korean"])

mydic = {
    "total": 1962,
    "city": ["서울", "대전", "광주"],
    "population": [987, 654, 321],
    "date": {"yy": 2023, "mm": 9, "dd": 10}
}
print(mydic)
print(mydic["city"][0])
print(mydic["population"][0])
print(mydic["date"]["yy"])
```

실행 결과:

```
{'address': {'addr1': '서울특별시 ...', 'addr2': '123-4'}, 'body': {'height': 175, 'weight': 80}}
{'userid': 'python', 'age': 20, 'addr': ['서울', '서초구', '강남대로'], 'grade': {'korean': 98, 'math': 77, 'english': 82}}
서울
98
{'total': 1962, 'city': ['서울', '대전', '광주'], 'population': [987, 654, 321], 'date': {'yy': 2023, 'mm': 9, 'dd': 10}}
서울
987
2023
```

강의에서는 처음에 `'yy': 2018`로 만들었다가, 촬영 시점에 맞춰 `2023`으로 고쳐 다시 실행했어요. 예제는 고친 값으로 적었어요.

> **참고(강의 밖 내용)**: 강의 화면(주피터)에서는 긴 딕셔너리가 키마다 줄을 나눠 보였는데, `print()`로 출력하면 한 줄로 쭉 이어서 나와요. 내용은 똑같아요.

## 5. 딕셔너리를 원소로 갖는 리스트 (목록 구조)

강사님이 "최종 목적지"라고 부른 구조예요. 리스트 안에 딕셔너리가 여러 개 들어 있고, 그 딕셔너리들은 **모두 같은 구조, 즉 키가 모두 같아요.**

```python
{ "이름": [ {...}, {...}, {...} ] }
```

슬라이드의 리뷰 목록 예:

```python
review = {
    "items": [
        {"email": "user1@python.com", "comment": "Good~!!"},
        {"email": "user2@python.com", "comment": "Nice~!!"},
        {"email": "user3@python.com", "comment": "Not Bad"}
    ]
}
```

이렇게 같은 구조의 딕셔너리가 리스트 안에 들어 있으면 **목록형 데이터**가 돼요. 강사님 말로는 인터넷에서 보는 게시글 목록, 리뷰 목록, 댓글 목록, 상품 목록, 장바구니 목록이 실제로 전부 이런 구조로 만들어져요. 화면 메모에는 "표 자료형"이라고도 적혀 있어요. 딕셔너리 하나가 표의 한 줄(행), 키가 표의 칸 이름(열)인 셈이에요.

### 바깥 괄호부터 보기

강사님이 강조한 부분: 이 구조는 헷갈려요. **가장 바깥 괄호 모양**을 먼저 보세요. 바깥이 대괄호(`[ ]`)면 그냥 리스트예요. 그다음 쉼표로 원소가 어떻게 나뉘는지 보면 0번째, 1번째, 2번째 원소가 각각 딕셔너리예요. 그래서 꺼낼 때는 **번호로 딕셔너리를 먼저 꺼내고, 그다음 이름으로 값을 꺼내요.**

```python
grade[0]["name"]   # 0번째 딕셔너리의 name
```

### 예제 (code/list_of_dicts.py)

```python
review = {
    "items": [
        {"email": "user1@python.com", "comment": "Good~!!"},
        {"email": "user2@python.com", "comment": "Nice~!!"},
        {"email": "user3@python.com", "comment": "Not Bad"}
    ]
}
print(review)

grade = [
    {"name": "철수", "kor": 95, "eng": 88},
    {"name": "영희", "kor": 92, "eng": 90},
    {"name": "철민", "kor": 88, "eng": 76}
]
print(type(grade))

print("0번째 원소", grade[0])
print("1번째 원소", grade[1])
print("2번째 원소", grade[2])

tpl = "{0}의 국어점수:{1}, 영어점수: {2}"
print(tpl.format(grade[0]["name"], grade[0]["kor"], grade[0]["eng"]))
print(tpl.format(grade[1]["name"], grade[1]["kor"], grade[1]["eng"]))
print(tpl.format(grade[2]["name"], grade[2]["kor"], grade[2]["eng"]))
```

실행 결과:

```
{'items': [{'email': 'user1@python.com', 'comment': 'Good~!!'}, {'email': 'user2@python.com', 'comment': 'Nice~!!'}, {'email': 'user3@python.com', 'comment': 'Not Bad'}]}
<class 'list'>
0번째 원소 {'name': '철수', 'kor': 95, 'eng': 88}
1번째 원소 {'name': '영희', 'kor': 92, 'eng': 90}
2번째 원소 {'name': '철민', 'kor': 88, 'eng': 76}
철수의 국어점수:95, 영어점수: 88
영희의 국어점수:92, 영어점수: 90
철민의 국어점수:88, 영어점수: 76
```

- `type(grade)`가 `<class 'list'>`로 나와서 전체가 리스트인 걸 확인할 수 있어요.
- `print("0번째 원소", grade[0])`처럼 쉼표로 여러 값을 넘기면 사이에 공백 하나를 넣어서 출력해요(08강에서 배운 내용). 문자열과 딕셔너리처럼 자료형이 달라도 쉼표로는 같이 출력돼요.
- 마지막은 11강에서 배운 `format()`으로 보기 좋게 정리한 거예요.

## 6. 리스트를 원소로 갖는 딕셔너리

5번과 반대 구조예요. 바깥이 **중괄호**라서 전체는 딕셔너리이고, 각 값이 리스트예요. 강사님은 이 두 경우를 **잘 나눠서** 기억하라고 해요.

| 구조 | 바깥 괄호 | 꺼내는 순서 | 예 |
|---|---|---|---|
| 딕셔너리를 원소로 갖는 리스트 | `[ ]` | 번호 → 이름 | `grade[1]["kor"]` |
| 리스트를 원소로 갖는 딕셔너리 | `{ }` | 이름 → 번호 | `student["age"][1]` |

### 예제 (code/dict_of_lists.py)

```python
student = {
    "name": ["철수", "민수", "호영", "수민"],
    "age": [16, 17, 19, 18],
    "height": [172.4, 168.2, 170.5, 165.8]
}
print(student)

print(student["name"][1], student["age"][1], student["height"][1])
```

실행 결과:

```
{'name': ['철수', '민수', '호영', '수민'], 'age': [16, 17, 19, 18], 'height': [172.4, 168.2, 170.5, 165.8]}
민수 17 168.2
```

민수는 각 리스트에서 두 번째지만, 번호는 0부터 세니까 **1번째**예요. 강의에서도 처음에 0을 넣었다가 1로 고쳤어요.

## 7. 딕셔너리 관련 내장함수: len()

`len()`은 문자열, 리스트, 튜플에서 계속 봤던 내장함수예요. 딕셔너리에도 쓸 수 있고, **이름: 값 한 쌍을 원소 하나**로 세요.

### 예제 (code/dict_len.py)

```python
point = {"korean": 98, "math": 77, "english": 82}
print(len(point))
```

실행 결과:

```
3
```

강사님이 꼭 기억하라고 한 부분: `len()`은 문자열, 리스트, 튜플, 딕셔너리에 다 쓸 수 있고, 나중에 데이터 분석을 하면서 만나는 다른 자료형(파이썬 기본 제공이 아닌 것)에서도 여전히 쓸 수 있어요.

> **강의와 다른 점**: 강의 학습 정리에 "딕셔너리는 연속성 자료형이다"라고 나와요. 넣은 순서대로 보관하고 `len()`도 쓸 수 있는 건 맞지만, 문자열, 리스트, 튜플과 달리 **번호(인덱스)로 꺼낼 수는 없어요.** `{"a": 1}[0]`은 0번째 원소가 아니라 이름이 `0`인 키를 찾아서 `KeyError: 0`이 나요. 파이썬의 분류로도 딕셔너리는 순서대로 번호가 붙는 자료형(시퀀스)이 아니에요. `isinstance({}, collections.abc.Sequence)`가 `False`, 리스트와 문자열은 `True`로 나와요(python3로 확인). 딕셔너리는 꼭 **이름으로** 꺼낸다고 기억하세요.

## 8. 딕셔너리 메서드: get()

`get()`은 키를 넣으면 그 키의 값을 돌려주는 메서드예요. `dic.get("name")`은 `dic["name"]`과 같은 결과예요.

차이는 **없는 키**에 접근할 때 나와요.

| 쓰는 법 | 키가 있을 때 | 키가 없을 때 |
|---|---|---|
| `dic["gender"]` | 그 값 | `KeyError` 에러 |
| `dic.get("gender")` | 그 값 | 에러 없이 `None` |
| `dic.get("gender", "남자")` | 그 값 | 대신 `"남자"` |

- `None`은 "아무것도 없다(존재하지 않는다)"를 뜻하는 특별한 값이에요.
- 키가 없을 때 대신 쓰이는 값을 **기본값**이라고 해요. 강사님 말로는 `get()`이 더 좋은 점이 바로 이 기본값을 함께 정할 수 있다는 거예요.

### 예제 (code/dict_get.py)

```python
dic = {"name": "철수", "phone": "010-1234-5678", "birth": "0115"}

print(dic.get("name"))

# print(dic["gender"])   # KeyError: 'gender'

print(dic.get("gender"))
print(dic.get("gender", "남자"))
```

실행 결과:

```
철수
None
남자
```

> **참고(강의 밖 내용)**: `get()`으로 기본값을 받아도 딕셔너리에 그 키가 추가되지는 않아요. `m = {"a": 1}`에서 `m.get("z", 0)`은 `0`을 돌려주지만 `m`은 그대로 `{'a': 1}`이에요. 또 키가 있는지만 알고 싶으면 `"a" in m`처럼 `in`을 쓰면 `True`/`False`가 나와요. `in`은 값이 아니라 **키**를 찾아요(둘 다 python3로 확인).

## 9. 딕셔너리 메서드: keys(), values(), items()

| 메서드 | 돌려주는 것 | 출력 모양 |
|---|---|---|
| `keys()` | 키만 모은 것 | `dict_keys([...])` |
| `values()` | 값만 모은 것 | `dict_values([...])` |
| `items()` | (키, 값) 튜플 쌍을 모은 것 | `dict_items([(..., ...), ...])` |

이 메서드들이 돌려주는 `dict_keys` 같은 것은 리스트가 아니라 따로 있는 객체예요. 그래서 **`list()` 내장함수로 리스트로 바꿔서** 써요. `list()`는 넘겨받은 것을 리스트로 바꿔 주는 함수예요.

```python
keys = dic.keys()        # 1단계: 키만 모은 dict_keys
key_list = list(keys)    # 2단계: 리스트로 바꾸기
```

두 번 호출해야 하니까 보통은 **한 줄로 한꺼번에** 써요.

```python
keyList = list(dic.keys())
```

강사님 말: 지금은 언제 쓰는지 감이 안 오겠지만 뒤에서 굉장히 많이 쓰이니까 꼭 기억하세요.

> **강의와 다른 점**: 강의에서는 `dict_keys` 객체는 "직접적으로 쓸 수 없다"고 했어요. 번호로 꺼내는 건(`keys[0]`) 실제로 `TypeError: 'dict_keys' object is not subscriptable`이 나서 안 되지만, `len(keys)`나 `"name" in keys`처럼 쓰는 건 돼요(python3로 확인). 번호로 꺼내거나 리스트 기능을 쓰고 싶을 때 `list()`로 바꾸는 거예요.

### 예제 (code/dict_keys_values_items.py)

```python
dic = {"name": "철수", "phone": "010-1234-5678", "birth": "0115"}

keys = dic.keys()
print(keys)
key_list = list(keys)
print(key_list)
keyList = list(dic.keys())
print(keyList)

values = dic.values()
print(values)
value_list = list(values)
print(value_list)
valueList = list(dic.values())
print(valueList)

items = dic.items()
print(items)
lists = list(items)
print(lists)
print(list(dic.items()))

point = {"korean": 98, "math": 77, "english": 82}
print(list(point.keys()))
print(list(point.values()))
```

실행 결과:

```
dict_keys(['name', 'phone', 'birth'])
['name', 'phone', 'birth']
['name', 'phone', 'birth']
dict_values(['철수', '010-1234-5678', '0115'])
['철수', '010-1234-5678', '0115']
['철수', '010-1234-5678', '0115']
dict_items([('name', '철수'), ('phone', '010-1234-5678'), ('birth', '0115')])
[('name', '철수'), ('phone', '010-1234-5678'), ('birth', '0115')]
[('name', '철수'), ('phone', '010-1234-5678'), ('birth', '0115')]
['korean', 'math', 'english']
[98, 77, 82]
```

`items()`를 리스트로 바꾸면 리스트 안에 `('name', '철수')` 같은 **튜플**이 들어 있어요. 괄호가 소괄호인 걸 보면 알 수 있어요.

### 그래프 재료로 쓰기

강사님은 `point`를 예로 들어 설명해요. 이름만 뽑은 `['korean', 'math', 'english']`를 그래프의 **x축**, 값만 뽑은 `[98, 77, 82]`를 **y축**으로 잡으면 국어, 수학, 영어 막대 그래프가 돼요. 이렇게 딕셔너리 자체가 그래프를 그리기 위한 정보를 담고 있는 경우도 있어서, `keys()`와 `values()`를 잘 기억해 두면 좋아요.

## 자주 하는 실수

### 1) 없는 키를 대괄호로 꺼냄

```python
dic = {"name": "철수"}
print(dic["gender"])             # KeyError: 'gender'
print(dic.get("gender"))         # None
print(dic.get("gender", "없음"))  # 없음
```

### 2) 같은 키를 두 번 적음

```python
data = {"msg": "hello", "msg": "python"}
print(data)   # {'msg': 'python'}  에러 없이 앞의 값이 사라져요
```

### 3) 딕셔너리를 번호로 꺼냄

```python
point = {"korean": 98, "math": 77}
print(point[0])          # KeyError: 0
print(point["korean"])   # 98  이름으로 꺼내요
```

### 4) 구조를 헷갈려서 순서를 반대로 꺼냄

```python
grade = [{"name": "철수", "kor": 95}, {"name": "영희", "kor": 92}]
print(grade["kor"][1])   # TypeError: list indices must be integers or slices, not str
print(grade[1]["kor"])   # 92  바깥이 리스트니까 번호가 먼저예요
```

### 5) 변수 이름과 메서드 이름을 헷갈림 (강의 중 실제로 난 에러)

강의에서 `keys = dic.keys()`로 변수를 만든 뒤, 한 번에 쓰려다 `list(keys(dic))`라고 잘못 써서 에러가 났어요.

```python
keys = dic.keys()
keyList = list(keys(dic))    # TypeError: 'dict_keys' object is not callable
keyList = list(dic.keys())   # 메서드는 "딕셔너리.keys()" 모양으로 불러요
```

`keys`라는 변수(`dict_keys` 객체)를 함수처럼 부르려고 해서 "호출할 수 없다(not callable)"는 에러가 난 거예요.

### 6) keys() 결과를 바로 번호로 꺼냄

```python
keys = dic.keys()
print(keys[0])         # TypeError: 'dict_keys' object is not subscriptable
print(list(keys)[0])   # 리스트로 바꾼 다음 꺼내요
```

### 7) 리스트를 키로 씀

```python
d = {[1, 2]: "x"}   # TypeError: cannot use 'list' as a dict key (unhashable type: 'list')
```

## 용어 정리

| 용어 | 쉬운 뜻 |
|---|---|
| 딕셔너리(dict) | 이름(key)과 값(value)을 쌍으로 묶어 중괄호에 담은 자료형 |
| 키(key) | 값을 찾을 때 쓰는 이름. 한 딕셔너리 안에서 겹치지 않음 |
| 밸류(value) | 키에 붙어 있는 값. 어떤 자료형이든 들어갈 수 있음 |
| 계층 구조 | 딕셔너리나 리스트 안에 또 딕셔너리나 리스트가 들어간 구조. 폴더 안의 폴더 |
| 목록 구조 | 같은 키를 가진 딕셔너리들을 리스트에 모은 구조. 게시글 목록, 상품 목록 등 |
| del | 변수나 원소를 지우는 파이썬 예약어 |
| KeyError | 딕셔너리에 없는 키로 값을 꺼낼 때 나는 에러 |
| None | "아무것도 없음"을 뜻하는 특별한 값 |
| 기본값 | 원하는 값이 없을 때 대신 쓰이는 값. 예: `get("gender", "남자")`의 `"남자"` |
| `get()` | 키로 값을 꺼내되, 키가 없으면 에러 대신 None이나 기본값을 돌려주는 메서드 |
| `keys()` / `values()` / `items()` | 키만 / 값만 / (키, 값) 쌍을 모아서 돌려주는 메서드 |
| `list()` | 넘겨받은 것을 리스트로 바꿔 주는 내장함수 |
| 데이터 프레임 | 데이터 분석에서 쓰는 표 모양 데이터. 딕셔너리로 만들 수 있음(뒤에서 배움) |
