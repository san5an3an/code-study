# 10. 형식문자를 활용한 문자열 포메팅

## 이 강의에서 배우는 것

- 문자열 포메팅이 무엇인지: 틀을 먼저 잡아 두고 빈칸에 값을 넣어 문장을 완성하는 방법
- 형식문자 `%d`(정수), `%f`(실수), `%s`(문자열), 그리고 `%o`, `%x`, `%%`
- `%` 연산자로 형식문자에 값을 넣는 법, 값이 여러 개일 때 괄호와 콤마로 묶는 법
- 형식문자 사이에 숫자를 넣어 자릿수를 정하고 정렬하는 법(`%5d`, `%-5d`, `%05d`)
- 문자열의 자릿수와 정렬(`%10s`, `%-10s`)
- 실수의 소수점 자릿수와 정렬(`%0.3f`, `%10.3f`, `%-10.3f`, `%010.3f`)

> 복습: 08강에서 역슬래시(`\`)와 글자 하나를 합친 이스케이프 문자를 배웠어요. 강사님은 형식문자도 일종의 특수문자라고 소개해요. 다만 이스케이프 문자는 **자기 자신이 무언가를 출력**하는 역할(줄바꿈, 탭 등)이고, 형식문자는 **자기는 출력되지 않고 그 자리에 다른 값이 들어가게** 하는 역할이에요.

---

## 1. 문자열 포메팅이란

**포맷(format)** 은 사전에서 찾아보면 "체제, 형식"이라는 뜻이에요. 미디어 포맷, 영상 포맷, 파일 포맷이라고 할 때의 그 포맷이에요. 여기에 `ing`가 붙은 **포메팅(formatting)** 은 "형식을 갖추는 처리"예요.

파이썬에서 **문자열 포메팅**은 이런 방법이에요.

1. 값이 들어갈 자리(형식문자)를 포함한 문장의 틀을 미리 만들어 놓고
2. 그 자리에 변수 값을 넣어서
3. 완성된 문자열을 만들어요.

강사님이 판서로 든 예가 쉬워요. `△ 안녕`이라는 틀을 만들어 두고, `△`에 철수를 넣으면 `철수 안녕`, 민수를 넣으면 `민수 안녕`이 되는 거예요. 이게 포메팅이에요.

---

## 2. 형식문자의 종류

| 형식문자 | 뜻 |
|---|---|
| `%d` | 10진 정수 (decimal) |
| `%f` | 10진 실수, 소수점을 포함하는 값 (float) |
| `%s` | 문자열 (string) |
| `%o` | 8진 정수 |
| `%x` | 16진 정수 |
| `%%` | `%` 기호 자체 |

- 강사님 말로는 `%o`, `%x`는 잘 쓰지 않아요. 중요한 건 `%d`, `%f`, `%s` 세 개예요.
- 다른 프로그래밍 언어들도 똑같이 쓰는 표기라서 이번에 잘 기억해 두면 좋다고 강조해요.
- 이스케이프 문자가 **역슬래시 + 글자**였듯이, 형식문자는 **`%` + 글자**예요. 그래서 `%` 기호 자체를 출력하고 싶으면 이스케이프 문자의 `\\`처럼 **`%%` 두 개**를 써요.

### 예제 (code/other_format_chars.py)

```python
print("8진수: %o" % 8)
print("16진수: %x" % 255)

print("할인율은 %d%% 입니다." % 30)   # % 자체를 출력하려면 %%
print("할인율은 30% 입니다.")          # % 연산자를 안 쓰면 % 하나로 충분해요
```

실행 결과:

```
8진수: 10
16진수: ff
할인율은 30% 입니다.
할인율은 30% 입니다.
```

> **참고(강의 밖 내용)**: `%%`가 필요한 건 그 문자열에 `%` 연산자를 쓸 때뿐이에요. `print("할인율은 30% 입니다.")`처럼 `%` 연산자를 쓰지 않는 보통 문자열에서는 `%` 하나만 써도 그대로 출력돼요. 반대로 `%` 연산자를 쓰면서 `%`를 하나만 쓰면 뒤 글자와 합쳐 형식문자로 읽혀서 에러가 나요(`TypeError: not enough arguments for format string`).

---

## 3. 기본 사용 방법: `%` 연산자

형식문자를 포함한 문자열 뒤에 **`%` 연산자**를 쓰고, 그 뒤에 넣을 값을 적어요.

```python
str = "나는 %d세 입니다."   # 10진수를 치환할 수 있는 형식문자 %d 포함
result = str % 20          # str에 포함된 형식문자에 20이라는 값을 적용
print(result)              # 나는 20세 입니다.
```

강사님이 "개인적으로 이게 좀 헷갈렸었다"고 짚은 부분이 있어요. 문자열 **안**의 `%d`에 있는 `%`는 형식문자를 표현하는 기호고, 문자열 **밖**의 `%`는 **문장과 값을 연결하는 연산자**예요. 같은 `%` 모양이지만 역할이 달라요.

- 결과를 변수(`result`)에 담아서 출력해도 되고, `print` 안에서 바로 써도 돼요.
- 형식문자가 **두 개 이상**이면, 넣을 값들을 **소괄호 `( )`로 묶고 콤마로 구분**해요. 앞에서부터 **순서대로** 치환돼요.

```python
print("나는 %d개의 %s을 갖고 있다." % (10, "사과"))
# 10이 첫 번째 %d, "사과"가 두 번째 %s 자리에 들어가요
```

> **참고(강의 밖 내용)**: 슬라이드 예제는 변수 이름을 `str`로 썼는데, `str`은 08강 자주 하는 실수에서 본 문자열 변환 함수 `str()`의 이름이기도 해요. 변수 이름으로 쓰면 그 뒤로는 `str(20)` 같은 변환을 못 써요(`TypeError: 'str' object is not callable`). 실습 노트북처럼 `str1`, `str2`처럼 다른 이름을 쓰는 게 안전해요.

### 예제 (code/format_basics.py)

```python
str1 = "나는 %d원을 갖고 있다." % 10000
print(str1)

lang = "Python"
str2 = "Hello %s" % lang     # 넣을 값을 변수에 담아 넘겨도 돼요
print(str2)

print("나는 %s을 먹었다" % "점심")
print("나는 %d개의 %s을 갖고 있다." % (10, "사과"))

str3 = "%s 날짜는 %d년 %d월 %d일 입니다."   # 형식문자를 포함한 문장만 따로 변수로
msg1 = str3 % ("정모", 2023, 1, 1)
print(msg1)
msg2 = str3 % ("약속", 2023, 3, 5)
print(msg2)
```

실행 결과:

```
나는 10000원을 갖고 있다.
Hello Python
나는 점심을 먹었다
나는 10개의 사과을 갖고 있다.
정모 날짜는 2023년 1월 1일 입니다.
약속 날짜는 2023년 3월 5일 입니다.
```

실습에서 강사님은 처음에 2018년으로 적었다가 2023년으로 바꿔 다시 실행했어요. 같은 `str3`를 두 번 썼죠. 강사님 말대로 형식문자는 일종의 **템플릿(틀)** 역할을 해서, 구조를 한 번 잡아 두면 치환될 내용만 바꿔서 계속 재사용할 수 있어요.

`나는 10개의 사과을`처럼 조사가 어색한 건 파이썬이 조사를 알아서 바꿔 주지 않기 때문이에요. 틀에 적은 글자는 그대로 나와요.

## 4. 형식문자의 구성: `%` + 숫자 + 알파벳

형식문자는 값이 들어갈 자리를 잡아 주는 것뿐 아니라, **자릿수를 정하고 정렬**하는 기능도 있어요.

```
%  [숫자]  d / f / s
```

- `%` 기호로 시작해요.
- 맨 끝 알파벳이 **데이터 타입**이에요. 정수면 `d`, 실수면 `f`, 문자열이면 `s`.
- 그 사이에 **숫자**를 넣으면, 숫자 모양에 따라 전체 자릿수와 정렬 방향이 정해져요.

---

## 5. 정수의 자릿수 지정과 정렬

| 형식문자 예 | 뜻 |
|---|---|
| `%5d` | 전체를 5자리로 맞추고 **오른쪽 정렬**. 모자란 자리는 **공백** |
| `%-5d` | 전체를 5자리로 맞추고 **왼쪽 정렬**. 모자란 자리는 **공백** |
| `%05d` | 전체를 5자리로 맞추고 오른쪽 정렬. 모자란 자리는 **0** |

- 숫자가 플러스(그냥 숫자)면 오른쪽 정렬, 마이너스(`-`)가 붙으면 왼쪽 정렬이에요.
- 출력할 내용이 지정한 자릿수보다 **길면** 자르지 않고 그냥 다 출력돼요. 예를 들어 5자리로 지정했는데 7자리 숫자면 7자리가 다 나와요.
- 0을 채우는 건 **오른쪽 정렬만** 돼요. 강사님 설명으로는, 왼쪽 정렬로 `350` 뒤에 0을 채우면 `35000`이 되어 **값 자체가 바뀌어 버리니까** 지원하지 않는 거예요.
- 빈자리를 채우는 글자로 0 말고 다른 글자는 쓸 수 없어요.

슬라이드의 결과 화면에 그어진 밑줄은 자릿수를 보여 주려고 강사님이 파워포인트에 임의로 그린 거예요. 실제 출력에는 밑줄이 없어요. 실습에서는 대신 **대괄호 `[ ]`** 를 같이 출력해서 공백이 몇 칸인지 보이게 했어요. 이 대괄호는 형식문자가 아니라 그냥 출력한 글자예요.

### 예제 (code/int_width_align.py)

```python
print("[%10d]원을 입금했습니다." % 120000)    # 오른쪽 정렬, 빈자리는 공백
print("[%010d]원을 입금했습니다." % 120000)   # 오른쪽 정렬, 빈자리는 0
print("[%-10d]원을 입금했습니다." % 120000)   # 왼쪽 정렬, 빈자리는 공백
print("[%-010d]원을 입금했습니다." % 120000)  # 왼쪽 정렬에 0을 붙여 봐도 공백

print("판매금액은 %5d원 입니다." % 350)
print("판매금액은 %-5d원 입니다." % 350)
print("판매금액은 %05d원 입니다." % 350)

print("[%5d]" % 1234567)                       # 자릿수보다 길면 그냥 다 출력
```

실행 결과:

```
[    120000]원을 입금했습니다.
[0000120000]원을 입금했습니다.
[120000    ]원을 입금했습니다.
[120000    ]원을 입금했습니다.
판매금액은   350원 입니다.
판매금액은 350  원 입니다.
판매금액은 00350원 입니다.
[1234567]
```

`120000`은 6자리라서, 10자리로 맞추면 공백(또는 0)이 4개 붙어요. `350`은 3자리라서 5자리로 맞추면 2개가 붙어요.

강사님은 실습에서 왼쪽 정렬에 0을 넣어 보고 "적용이 안 된다"고 보여 줬어요. 위 네 번째 줄처럼 에러는 나지 않고, `-`가 이겨서 0은 무시되고 공백으로 채워져요.

## 6. 문자열의 자릿수 지정과 정렬

| 형식문자 예 | 뜻 |
|---|---|
| `%10s` | 문자열을 10자리로 맞추고 **오른쪽 정렬**. 모자란 자리는 공백 |
| `%-10s` | 문자열을 10자리로 맞추고 **왼쪽 정렬**. 모자란 자리는 공백 |
| `%010s` | 문자열에는 0 채우기가 지원되지 않아요 |

규칙은 정수와 같고, 문자열은 0으로 채우는 게 안 된다는 점만 달라요.

### 예제 (code/str_width_align.py)

```python
print("[%10s]에 살고 있습니다." % "대한민국")    # 오른쪽 정렬
print("[%-10s]에 살고 있습니다." % "대한민국")   # 왼쪽 정렬

print("Hello %10s." % "Python")
print("Hello %-10s." % "Python")

print("[%010s]" % "Python")                     # 0을 붙여도 공백으로 채워져요
```

실행 결과:

```
[      대한민국]에 살고 있습니다.
[대한민국      ]에 살고 있습니다.
Hello     Python.
Hello Python    .
[    Python]
```

- `Python`은 6글자라서 10자리로 맞추면 공백 4칸이 붙어요.
- `대한민국`은 4글자라서 공백 6칸이 붙어요.

> **참고(강의 밖 내용)**: `%010s`는 에러가 나지 않아요. 0은 무시되고 공백으로 채워져요(마지막 줄). 그리고 자릿수는 **글자 수**로 세요. 한글은 화면에서 영어보다 넓게 보이는 경우가 많아서, 한글과 영어가 섞이면 줄이 딱 맞아 보이지 않을 수 있어요.

## 7. 실수의 소수점 자릿수와 정렬

실수는 **전체 자릿수**와 **소수점 아래 자릿수**를 나눠서 생각해야 해요. 지정한 소수점 자릿수보다 값이 길면 **반올림**돼요.

| 형식문자 | 뜻 |
|---|---|
| `%0.3f` | 전체 자릿수 제한 없이 소수점 셋째 자리까지 출력 |
| `%10.3f` | 전체 글자 수를 10자리로, 소수점 아래는 셋째 자리까지. 모자란 자리는 공백, 오른쪽 정렬 |
| `%-10.3f` | `%10.3f`와 같은데 왼쪽 정렬 |
| `%010.3f` | `%10.3f`와 같은데 모자란 자리는 0 (오른쪽 정렬만 됨) |

- `.` 앞의 숫자가 **전체 글자 수**, `.` 뒤의 숫자가 **소수점 아래 자릿수**예요.
- 강사님이 특히 강조한 점: **소수점(`.`)도 한 자리를 차지해요.** `123.457`은 숫자 6개 + 소수점 1개 = 7자리라서, 10자리로 맞추면 공백이 3칸 붙어요.
- `%0.3f`의 0은 생략해서 `%.3f`로 써도 같아요. 강사님은 주로 0을 넣는 편이지만, 안 넣는 사람도 꽤 많다고 해요.

> **강의와 다른 점**: 강의에서는 `%0.3f`의 `0`을 "전체 자릿수(0이면 제한 없음)"라고 설명했어요. 결과는 맞지만 파이썬이 읽는 방식은 조금 달라요. `.` 앞에 붙은 맨 앞의 `0`은 자릿수가 아니라 **"빈자리를 0으로 채워라"는 표시**예요. 그래서 `%0.3f`는 "0으로 채우되 전체 자릿수는 안 정함" = `%.3f`와 결과가 같아요. 0 뒤에 숫자를 붙이면 차이가 보여요.
> ```python
> print("%07.3f" % 1.5)   # 001.500  (0으로 채워서 7자리)
> print("%.3f" % 1.5)     # 1.500
> ```
> (python3 3.14.7에서 실행해 확인했어요.)

### 예제 (code/float_precision_align.py)

```python
money = 123.456789
print("[%f]원 입니다." % money)       # 그냥 %f
print("[%0.3f]원 입니다." % money)    # 소수점 셋째 자리까지, 넷째 자리에서 반올림
print("[%.3f]원 입니다." % money)     # 0을 빼도 같아요

print("[%10.3f]원 입니다." % money)   # 전체 10글자, 오른쪽 정렬
print("[%-10.3f]원 입니다." % money)  # 전체 10글자, 왼쪽 정렬
print("[%010.3f]원 입니다." % money)  # 전체 10글자, 빈자리는 0

print("[%f]" % 1.5)
```

실행 결과:

```
[123.456789]원 입니다.
[123.457]원 입니다.
[123.457]원 입니다.
[   123.457]원 입니다.
[123.457   ]원 입니다.
[000123.457]원 입니다.
[1.500000]
```

> **강의와 다른 점**: 강의에서는 `%f`만 쓰면 값을 "곧이곧대로(그대로)" 출력한다고 했어요. 실습 값 `123.456789`가 마침 소수점 아래 6자리라서 그렇게 보인 거예요. `%f`는 **항상 소수점 아래 6자리**로 맞춰요. 짧으면 0을 채우고(`1.5` → `1.500000`), 길면 일곱째 자리에서 반올림해요. (python3 3.14.7에서 `"%f" % 1.5`를 실행해 확인했어요.)

> **강의와 다른 점**: 슬라이드(실수의 자릿수 지정 및 정렬) 예제에 두 군데 옮겨 적기 실수가 있어요.
> - `print("%0.3f" % 123.4567)` 옆 주석이 `# 10자리, 오른쪽 정렬`로 적혀 있는데, `%0.3f`는 전체 자릿수를 정하지 않아요. 결과도 공백 없이 `123.457`이에요.
> - `print("%010.3f" % 123.456750)`의 결과가 `판매금액은 000123.457원 입니다.`로 적혀 있는데, 코드에 "판매금액은"이라는 글자가 없으니 실제 결과는 `000123.457`이에요.
>
> (python3 3.14.7에서 두 코드를 그대로 실행해 확인했어요.)

> **참고(강의 밖 내용)**: 컴퓨터는 실수를 2진수로 저장해서 아주 조금 오차가 있어요. 그래서 끝자리가 딱 5인 값은 생각과 다르게 반올림될 때가 있어요. 예를 들어 `"%.2f" % 2.675`는 `2.68`이 아니라 `2.67`이에요. 처음엔 "반올림된다"로 기억하고, 이런 경우가 있다는 것만 알아 두세요.

## 8. 직접 타이핑하기

강사님은 영상 시간 때문에 실습 코드를 하나하나 다 타이핑하지 않았지만, 여러분은 **꼭 직접 타이핑해 보라**고 강조해요. 코딩은 대소문자를 가리고 이상한 약자도 많아서, 별것 아닌 오타 때문에 에러 나는 경우가 굉장히 많아요. 그 오타도 습관이라서, 올바른 습관을 들이려면 쉬워 보이는 코드도 직접 쳐 봐야 해요.

---

## 자주 하는 실수

### 1) 값 개수와 형식문자 개수가 안 맞음

```python
print("%d년 %d월" % (2023,))     # TypeError: not enough arguments for format string
print("%d년" % (2023, 1))        # TypeError: not all arguments converted during string formatting
print("%d년 %d월" % (2023, 1))   # 2023년 1월
```

형식문자 개수만큼 값을 넣어요. 순서대로 들어가니까 순서도 맞춰요.

### 2) 값이 여러 개인데 괄호로 안 묶음

```python
print("%d개의 %s" % 10, "사과")     # TypeError: not enough arguments for format string
print("%d개의 %s" % (10, "사과"))   # 10개의 사과
```

괄호가 없으면 `%` 뒤에 `10` 하나만 넘어가요. `"사과"`는 `print`에 넘기는 다른 값으로 읽혀요.

### 3) `%d` 자리에 문자열을 넣음

```python
print("%d원" % "10000")        # TypeError: %d format: a real number is required, not str
print("%d원" % int("10000"))   # 10000원
```

`input()`으로 받은 값은 문자열이라서 `%d`에 넣으려면 `int()`로 바꿔야 해요. `%s`는 숫자를 넣어도 글자로 바꿔서 넣어 줘요.

### 4) `%` 연산자를 쓰면서 `%` 기호를 하나만 씀

```python
print("할인율 %d% 입니다." % 30)    # TypeError: not enough arguments for format string
print("할인율 %d%% 입니다." % 30)   # 할인율 30% 입니다.
```

### 5) 왼쪽 정렬에 0 채우기를 기대함

```python
print("[%-05d]" % 350)   # [350  ]  에러는 안 나지만 0은 무시돼요
```

0 채우기는 오른쪽 정렬일 때만 돼요.

### 6) 실수의 전체 자릿수에서 소수점을 빼먹고 셈

```python
print("[%8.3f]" % 123.4567)   # [ 123.457]
```

`123.457`은 소수점까지 7자리라서 8자리로 맞추면 공백이 1칸이에요. 2칸이 아니에요.

## 용어 정리

| 용어 | 쉬운 뜻 |
|---|---|
| 포맷(format) | 형식. 미디어 포맷, 파일 포맷의 그 포맷 |
| 문자열 포메팅 | 틀을 먼저 만들어 두고 빈자리에 값을 넣어 문장을 완성하는 방법 |
| 형식문자 | `%` + 글자로 된 특수문자. 자기는 출력되지 않고 그 자리에 값이 들어감 |
| 치환 | 어떤 자리를 다른 값으로 바꿔 넣는 것 |
| `%` 연산자 | 형식문자를 포함한 문자열과 넣을 값을 연결하는 연산자 |
| 템플릿 | 구조를 미리 잡아 둔 틀. 내용만 바꿔 계속 재사용함 |
| 자릿수 | 출력할 전체 글자 칸 수 |
| 오른쪽 정렬 | 내용을 오른쪽 끝에 붙이고 남는 칸을 왼쪽에 둠 |
| 왼쪽 정렬 | 내용을 왼쪽 끝에 붙이고 남는 칸을 오른쪽에 둠 |
| 반올림 | 지정한 자리 바로 다음 숫자가 5 이상이면 올리고 아니면 버림 |
| 8진수, 16진수 | 8개, 16개 숫자로 수를 나타내는 방법. `%o`, `%x`로 출력 |
