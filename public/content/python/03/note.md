# 03. 파이썬 개발환경 구성(mac)

## 이 강의에서 배우는 것

- UI, GUI, CLI가 무엇이고, 맥에서 CLI 환경인 **터미널**을 어떻게 여는지
- 파일 확장자와 텍스트 파일이 무엇인지, 맥 Finder에서 확장자를 보이게 하는 설정
- 맥에서 파이썬 개발 환경을 꾸리는 순서: 설치 여부 확인 → 파이썬 내려받기 → 설치 → 주피터랩 설치 → VS Code 설치
- 맥에서는 `python`이 아니라 **`python3`**, `pip`이 아니라 **`pip3`** 를 쓴다는 것
- 맥에 원래 들어 있는 파이썬은 지우지 않고, 새 버전을 **추가로** 설치한다는 것

> 복습: 02강은 윈도우에서 개발 환경을 꾸리는 강의였어요. 강사님은 02강을 건너뛴 맥 사용자라도 02강의 1단원(UI, GUI, CLI 설명)은 먼저 보고 오라고 해요. 이 노트에도 핵심은 다시 정리해 뒀어요. 이번 강의는 코드를 짜는 강의가 아니라 **준비 강의**라서, 실습은 대부분 터미널 명령과 설치 화면이에요.

## 1. UI, GUI, CLI

**UI(User Interface, 사용자 인터페이스)** 는 사용자가 프로그램을 쓰려고 누르거나 입력하는 **환경 전체**를 말해요. UI는 크게 두 가지로 나뉘어요.

| 종류 | 풀어 쓰면 | 쉽게 말하면 | 예 |
|---|---|---|---|
| GUI | Graphic User Interface | 아이콘 같은 그림을 보면서 마우스나 터치로 쓰는 환경 | 바탕화면, 웹사이트, 스마트폰 앱 |
| CLI | Command Line Interface | 글자로 명령어를 입력하고, 글자로 결과를 보는 환경 | 윈도우의 명령 프롬프트, 맥의 터미널 |

강사님 비유로는, 옛날 영화에서 까만 화면에 글자만 쭉쭉 올라가는 그 화면이 CLI예요.

- 윈도우는 CLI 환경으로 **명령 프롬프트**(줄여서 CMD)를 줘요.
- 맥은 그 자리에 **터미널(Terminal)** 이라는 프로그램이 기본으로 들어 있어요.

## 2. 맥에서 터미널 열기

화면에 나온 순서예요.

1. 키보드 스페이스바 양옆에 있는 `⌘`(커맨드, 줄여서 Cmd) 키와 스페이스바를 같이 눌러요.
2. 화면 가운데에 **Spotlight 검색** 창이 떠요.
3. `terminal` 또는 한글로 `터미널`을 입력하고 엔터를 눌러요.
4. 명령어를 입력할 수 있는 창이 떠요. 강의 화면에서는 이렇게 보였어요.

```
Last login: Wed Jan 11 17:03:25 on ttys000
leekh@leekh-MacBookPro ~ %
```

`%` 뒤에 깜박이는 곳에 명령어를 입력하면 돼요. `leekh`는 강사님 컴퓨터의 사용자 이름이라 여러분 화면에는 여러분 이름이 나와요.

### 글자 크기 바꾸기

처음엔 글자가 아주 작게 보일 수 있어요.

| 단축키 | 동작 |
|---|---|
| `⌘` + `+` | 글자 크게(확대) |
| `⌘` + `-` | 글자 작게(축소) |

강사님 조언: 앞으로 터미널에 여러 명령어를 입력해서 파이썬 코딩에 필요한 일들을 하게 돼요. 수업에서는 그때그때 필요한 명령어만 알려 주지만, 터미널 명령어를 **표로 정리해서 모니터 옆에 붙여 두고** 필요할 때마다 보면 프로그래밍 공부에 큰 도움이 된다고 해요.

> **참고(강의 밖 내용)**: 강의에서는 "하얀 배경"이라고 했는데, 터미널 색은 맥의 화면 모드(라이트/다크)에 따라 까만 배경으로 보일 수도 있어요. 기능은 똑같아요.

## 3. 파일 확장자와 텍스트 파일

### 파일 확장자

**확장자**는 파일의 **종류**를 나타내는 짧은 영단어예요. 파일 이름 뒤에 **점(`.`)** 을 찍고 적어요. 확장자에 따라 파일을 더블클릭했을 때 **어떤 프로그램으로 열릴지**가 정해져요.

| 확장자 | 종류 |
|---|---|
| `.xlsx` | 엑셀 문서 |
| `.hwp` | 한글 문서 |
| `.ipynb` | 우리가 나중에 작성할 파이썬 소스 코드(주피터 노트북) |
| `.mp3` | 음악 |
| `.jpg` | 사진(이미지) |
| `.txt` | 텍스트 파일 |

강의 화면에 `*.mp3`, `*.jpg`처럼 앞에 **별표(`*`)** 가 붙은 표기가 나와요. 컴퓨터 이야기에서 별표는 **"전부(ALL)"** 라는 뜻이에요. 즉 "앞의 파일 이름은 무엇이든 상관없고, 확장자가 mp3인 파일"이라는 뜻이에요.

### 왜 확장자를 보이게 해야 하나

확장자는 아주 중요한 값이라서, 일반 사용자가 잘못 건드리면 파일이 엉뚱한 프로그램과 연결돼 안 열릴 수 있어요. 그래서 **윈도우와 맥은 기본으로 확장자를 숨겨요.** 그런데 프로그래밍을 하려면 확장자를 직접 다뤄야 하니까, **확장자가 보이도록 운영체제 설정을 바꿔야** 해요.

### 텍스트 파일

- 텍스트(문장)만 저장된 문서 파일이에요. 확장자는 `.txt`예요.
- 윈도우의 **메모장**, 맥의 **텍스트 편집기**로 열 수 있는 가장 단순한(원시적인) 파일이에요.
- **프로그램 소스 코드는 텍스트 파일을 만든 뒤, 확장자를 그 프로그래밍 언어에 맞게 바꾼 파일**이에요. 파이썬이면 `.py`(또는 주피터 노트북의 `.ipynb`)예요.

### 예제 (code/file_extension.py)

강의에서 코드를 짠 건 아니지만, "이름.확장자" 구조를 눈으로 확인하는 작은 예제예요. 문자열을 나누는 `rsplit`, 패턴을 검사하는 `fnmatch`는 뒤 강의에서 배우는 기능이니 지금은 결과만 보세요.

```python
files = ["성적표.xlsx", "보고서.hwp", "02강-파이썬.ipynb", "노래.mp3", "사진.jpg", "메모.txt", "hello.py"]

for name in files:
    stem, ext = name.rsplit(".", 1)    # 맨 뒤의 점을 기준으로 이름과 확장자를 나눠요
    print(name, "=> 이름:", stem, "/ 확장자:", ext)

source = "hello.txt"
print(source, "->", source.replace(".txt", ".py"))   # 텍스트 파일의 확장자만 .py로

from fnmatch import fnmatch
for name in files:
    if fnmatch(name, "*.mp3") or fnmatch(name, "*.jpg"):   # 별표는 "아무 이름이나"
        print("*.mp3 또는 *.jpg 에 해당해요:", name)
```

실행 결과:

```
성적표.xlsx => 이름: 성적표 / 확장자: xlsx
보고서.hwp => 이름: 보고서 / 확장자: hwp
02강-파이썬.ipynb => 이름: 02강-파이썬 / 확장자: ipynb
노래.mp3 => 이름: 노래 / 확장자: mp3
사진.jpg => 이름: 사진 / 확장자: jpg
메모.txt => 이름: 메모 / 확장자: txt
hello.py => 이름: hello / 확장자: py
hello.txt -> hello.py
*.mp3 또는 *.jpg 에 해당해요: 노래.mp3
*.mp3 또는 *.jpg 에 해당해요: 사진.jpg
```

## 4. 맥 Finder에서 확장자 보이게 하기

맥에서 폴더를 여는 프로그램이 **Finder(파인더)** 예요.

1. 아무 폴더나 열어 Finder를 앞에 띄워요.
2. 화면 맨 위 메뉴 막대에서 **Finder → 설정...** 을 눌러요(단축키 `⌘` + `,`).
3. **고급** 탭에서 **모든 파일 확장자 보기**를 체크해요.

강사님이 덤으로 알려 준 편한 설정도 있어요.

4. **일반** 탭의 **새로운 Finder 윈도우에서 보기**를 여러분 **사용자 이름 폴더**(강사님 화면에서는 `leekh`)로 바꿔요. 이 폴더를 **사용자 홈 폴더**라고 해요. 기본값은 "최근 항목"이라 맥북 안의 폴더를 찾아 들어가기가 불편해요.
5. 그 밖의 항목은 화면을 참고해서 필요한 것을 체크하면 돼요. 강의 화면의 고급 탭에는 "확장자를 변경하기 전에 경고 보기", "휴지통을 비우기 전에 경고 보기" 등이 체크돼 있었어요.

> **참고(강의 밖 내용)**: macOS 12(Monterey) 이전에는 이 메뉴 이름이 **Finder → 환경설정...** 이었어요. 강의 화면처럼 "설정..."으로 보이는 건 macOS 13(Ventura)부터예요. 위치는 같아요.

## 5. 맥에서 개발 환경을 꾸리는 순서

강의 화면의 "파이썬 개발 환경 구성 과정"이에요.

1. **터미널로 파이썬 설치 여부 확인**
2. **파이썬 다운로드** — 여기서 받는 "파이썬"이 바로 코드를 해석해서 실행해 주는 **인터프리터**예요.
3. **파이썬 설치**
4. **터미널로 JupyterLab(주피터랩) 설치** — 파이썬을 코딩하는 **코딩 도구**예요.
5. **Visual Studio Code(VS Code) 설치** — 전 세계에서 가장 많이 쓰는 **IDE**(코드 편집, 실행 등을 한곳에서 하는 개발 도구)예요.

주피터랩은 웹 브라우저 위에서 도는 프로그램이라 쓰기가 좀 불편해요. 그래서 VS Code를 깔면, VS Code가 주피터랩을 불러와서 **VS Code 안에 주피터가 옮겨 심어진(이식된)** 것처럼 쓸 수 있어요. 이렇게 하면 VS Code의 편한 기능과 합쳐서 코딩할 수 있어요.

> **참고(강의 밖 내용)**: 정확히는 VS Code가 주피터랩 프로그램 자체를 띄우는 건 아니에요. VS Code에 **Python 확장**과 **Jupyter 확장**을 깔면, VS Code가 설치된 파이썬(과 주피터 관련 패키지)을 이용해서 `.ipynb` 파일을 직접 열고 실행해요. 확장 설치는 보통 다음 강의들에서 다뤄요.

## 6. 파이썬 설치 여부 확인하기

터미널에 이렇게 입력해요. `--version`은 **빼기(하이픈) 두 개** + `version`이에요.

```
python3 --version
```

- 설치돼 있으면 버전이 나와요. 강의 슬라이드 예: `Python 3.7.0`
- 설치돼 있지 않으면 "명령어를 찾을 수 없다"는 에러가 나요.

```
zsh: command not found: python3
```

### 맥은 `python3`, 윈도우는 `python`

강사님이 크게 강조한 부분이에요.

| | 윈도우 | 맥 |
|---|---|---|
| 파이썬 실행 명령 | `python` | `python3` |
| 패키지 설치 명령 | `pip` | `pip3` |

맥에는 옛날 파이썬 2가 들어 있던 시절이 있어서, 그거랑 구별하려고 `python`은 버전 2, `python3`은 버전 3을 찾도록 돼 있다고 설명해요. 앞으로 수업에서는 윈도우 기준으로 `python`, `pip`이라고만 적을 테니, **맥 사용자는 항상 뒤에 숫자 3을 붙이라**고 해요.

### 파이썬 2와 3

- 파이썬 2에서 3으로 넘어오면서 코드 쓰는 법이 아주 많이 바뀌어서 거의 다른 언어라고 봐도 될 정도예요.
- 그래서 요즘은 전부 파이썬 3을 기준으로 하고, **파이썬 2는 지원이 끝났어요.**

### 버전 이야기

- 강의 기준(2023년 1월) 최신 버전은 **3.11**이고, 이전 버전보다 속도가 크게 빨라져서 3.11을 강력히 권해요.
- 강사님 설명: 오래된 맥에는 파이썬 2.7, M1 이후 맥에는 3.8이나 3.9가 기본으로 들어 있어요. 이건 **운영체제가 내부적으로 쓰는 것**이라 잘못 지우면 컴퓨터에 문제가 생길 수 있으니 **그대로 두고 새 버전을 추가로 설치**해요.

> **강의와 다른 점**: "맥에는 파이썬 2.7이 기본으로 들어 있다"는 건 이제 맞지 않아요. 애플은 **macOS 12.3부터 파이썬 2.7을 뺐어요.** 이 노트를 확인한 맥(macOS 27)에서도 `/usr/bin/python` 파일이 없고, `python --version`을 치면 강의 화면(17:50)처럼 `zsh: command not found: python`이 나와요. 그래서 요즘 맥에서 `python`은 "버전 2로 가는 명령"이 아니라 그냥 **없는 명령**이에요(설치 방법에 따라 `python`이 3을 가리키게 될 수도 있어요).

> **강의와 다른 점**: 최신 버전이 3.11이라는 건 2023년 1월 기준이에요. 이 노트는 **Python 3.14**(`python3 --version` → `Python 3.14.7`)로 확인했어요. 지금 설치한다면 python.org 첫 화면에 뜨는 최신 버전을 받으면 돼요. 강의 내용(설치 순서, 명령어)은 그대로 통해요.

> **참고(강의 밖 내용)**: 요즘 맥에서 `python3 --version`을 쳤을 때 나오는 3.9.x는 엄밀히는 운영체제 자체가 아니라 애플의 **Command Line Tools(개발자 도구)** 에 딸린 파이썬이에요. 이 노트를 확인한 맥에서도 `/usr/bin/python3 --version`이 `Python 3.9.6`이었어요(강의 화면과 같은 버전). 개발자 도구가 아직 없는 새 맥이라면, `python3`을 처음 칠 때 "개발자 도구를 설치하겠냐"는 창이 뜰 수 있어요. 어느 쪽이든 **지우지 말고 그대로 두라**는 강사님 조언은 똑같이 맞아요.

### 예제 (code/check_python_version.py)

터미널의 `python3 --version`처럼, 코드 안에서도 지금 돌고 있는 파이썬 버전을 확인할 수 있어요. `import sys`는 뒤에서 배우는 기능이에요.

```python
import sys

print("큰 번호(major):", sys.version_info.major)
print("3.11 이상인가요?", sys.version_info >= (3, 11))
print("파이썬 3 인가요?", sys.version_info.major == 3)
```

실행 결과(파이썬 3.14로 실행):

```
큰 번호(major): 3
3.11 이상인가요? True
파이썬 3 인가요? True
```

터미널에서 `python3 code/check_python_version.py`처럼 실행해요.

## 7. 실습: 파이썬 설치하기

### 1) 지금 버전 확인

`⌘` + 스페이스 → `터미널` → 엔터로 터미널을 열고 확인해요. 강사님 맥(M1)의 화면이에요.

```
leekh@leekh-MacBookPro ~ % python --version
zsh: command not found: python
leekh@leekh-MacBookPro ~ % python3 --version
Python 3.9.6
```

- `python`은 없는 명령이라 에러(파이썬 2점대가 깔려 있지 않다는 뜻)
- `python3`은 기본 버전 3.9.6
- 3.11보다 낮으니 최신 버전을 추가로 설치하기로 해요.

### 2) 내려받기

1. 터미널을 닫고 웹 브라우저를 열어요.
2. **python.org** 에 들어가요.
3. 가운데 메뉴의 **Downloads** 에 마우스를 올리면 **Download for macOS** 아래에 버튼이 나와요. 강의 화면에서는 `Python 3.11.1` 버튼이었고, 받은 파일은 `python-3.11.1-macos11.pkg`였어요.

### 3) 설치

1. 받은 파일을 다운로드 폴더에서 더블클릭해요.
2. "Python 설치" 창에서 **계속**을 눌러 진행해요. 강사님 말로는 윈도우에서는 "꼭 체크하라"는 항목이 있었는데, **맥은 그런 게 없어요.** 그냥 계속 누르면 돼요.
3. **사용권(라이선스)에 동의**하고 설치를 진행해요.
4. 맥 로그인 **비밀번호**를 한 번 입력해요.
5. "설치가 성공적으로 완료되었습니다"가 뜨면 창을 닫아요. 설치 프로그램을 휴지통으로 옮길지 물으면 **휴지통으로 이동**을 눌러도 돼요(설치 파일은 지워도 괜찮아요).

### 4) 새 버전 확인

1. 쓰던 터미널을 **완전히 종료**해요. 화면 아래 **Dock**의 터미널 아이콘에서 마우스 오른쪽 클릭 → **종료**.
2. 터미널을 다시 열고 확인해요.

```
leekh@leekh-MacBookPro ~ % python3 --version
Python 3.11.1
```

3.9.6에서 **3.11.1**로 바뀐 걸 볼 수 있어요. 터미널을 완전히 껐다 켜야 새로 깔린 파이썬을 찾아요.

## 8. 실습: 주피터랩 설치하기

패키지(추가 프로그램)는 **pip** 명령으로 설치해요. 맥이니까 `pip3`예요.

```
pip3 install jupyterlab
```

강의에서는 말로 "주피터 랩"이라고 띄어 읽지만, 화면에 입력한 건 띄어쓰기 없는 **`jupyterlab`** 이에요. 엔터를 누르면 이렇게 내려받기가 시작돼요.

```
Collecting jupyterlab
  Downloading jupyterlab-3.5.2-py3-none-any.whl (8.8 MB)
```

함께 깔리는 패키지가 아주 많아서 목록이 쭉 올라가요. 마지막에 `Successfully installed ... jupyterlab-3.5.2 ...` 같은 줄이 나오고 다시 `%` 입력 줄이 나오면 끝이에요. 그러면 터미널을 닫아요.

> **강의와 다른 점**: python.org 설치 파일로 깐 파이썬이라면 강의처럼 `pip3 install jupyterlab`이 바로 돼요. 그런데 **Homebrew(`brew install python`)로 깐 파이썬**에서는 이제 이 명령이 막혀요. 이 노트를 확인한 맥(Homebrew 파이썬 3.14)에서 실제로 쳐 보면 이렇게 나와요.
> ```
> error: externally-managed-environment
>
> × This environment is externally managed
> ```
> "이 파이썬은 Homebrew가 관리하니까 함부로 패키지를 넣지 말라"는 뜻이에요. 이럴 땐 에러 문구가 알려 주는 대로 **가상 환경**을 만들어서 그 안에 설치해요.
> ```
> python3 -m venv ~/venv-python
> source ~/venv-python/bin/activate
> python3 -m pip install jupyterlab
> ```
> 처음 배우는 단계라면 강의처럼 **python.org 설치 파일**을 쓰는 게 제일 덜 헷갈려요.

> **참고(강의 밖 내용)**: 강의 화면의 주피터랩은 3.5.2였는데, 지금 받으면 더 새 판(4점대 이상)이 깔려요. 화면 모양은 조금 달라도 쓰는 법은 같아요. 또 `pip3` 대신 `python3 -m pip`이라고 쓰면 "지금 쓰는 python3에 딸린 pip"이 확실히 실행돼서, 파이썬이 여러 개 깔린 맥에서 더 안전해요.

## 9. 실습: VS Code 설치하기

1. 브라우저에서 **code.visualstudio.com** 에 들어가요(검색이 번거로우면 주소를 직접 입력).
2. **Download Mac Universal** 버튼을 눌러요. 강의 화면에는 "Version 1.74 is now available!"이 떠 있었어요.
3. 맥에서는 **압축 파일**(`VSCode-darwin-universal.zip`, 약 210MB)로 받아져요. 더블클릭해서 압축을 풀어요.
4. 풀린 `Visual Studio Code.app`을 그 자리에서 쓰지 말고, Finder 왼쪽의 **응용 프로그램** 폴더로 **끌어다 넣어요.**
5. 창을 다 닫고 **Launchpad(런치패드)** 를 열면 Visual Studio Code 아이콘이 보여요. 클릭하면 실행돼요.

### Dock에 고정하기

자주 쓸 거라면 Dock에 있는 VS Code 아이콘을 마우스 오른쪽 클릭 → **옵션** → **Dock에 유지**를 눌러요. 그러면 프로그램을 종료해도 아이콘이 Dock에 남아서 바로바로 실행할 수 있어요.

> **참고(강의 밖 내용)**: 강의 화면의 VS Code는 1.74(2022년 말)라서 지금 받으면 훨씬 새 버전이에요. 시작 화면 모양은 달라도 설치 과정은 같아요. 또 Safari로 받으면 zip이 자동으로 풀려서 바로 `.app` 파일로 보일 수도 있어요(강의는 Chrome이라 zip 그대로였어요). 응용 프로그램 폴더로 옮기는 건 똑같이 해요.

강사님 말대로 여기까지 하면 맥 설치는 끝이에요. 다음 강의부터는 파이썬 코드를 직접 써서 실행하는데, **이제부터는 맥과 윈도우의 차이가 없어요**(명령어 뒤 숫자 3만 빼고요).

## 자주 하는 실수

### 1) 맥에서 `python`, `pip`이라고 침

```
% python --version
zsh: command not found: python
```

맥에서는 `python3 --version`, `pip3 install ...`처럼 숫자 3을 붙여요. 수업 자료가 `python`, `pip`이라고 써 있어도 맥에서는 3을 붙여서 쳐요.

### 2) `--version`의 빼기를 하나만 씀

```
% python3 -version
Unknown option: -e
```

이러면 버전이 안 나오고 "모르는 옵션"이라는 에러가 나요(빼기 하나 뒤의 글자를 한 글자씩 옵션으로 읽어서, 파이썬에 없는 `-e`에서 멈춰요). 빼기 **두 개**(`--version`)를 쓰거나, 짧게 대문자 `-V`를 써요(`python3 -V` → `Python 3.14.7`).

### 3) 새 파이썬을 깔고 터미널을 안 껐다 켬

설치 전에 열어 둔 터미널은 예전 파이썬을 찾을 수 있어요. Dock에서 터미널을 **완전히 종료**하고 다시 열어서 `python3 --version`으로 확인해요.

### 4) 맥에 원래 있던 파이썬을 지움

원래 들어 있는 3.9 같은 파이썬은 지우지 말아요. 새 버전은 **추가로** 설치하는 거예요.

### 5) `pip3 install jupyter lab`처럼 띄어 씀

패키지 이름은 띄어쓰기 없는 `jupyterlab`이에요. 띄어 쓰면 `jupyter`와 `lab`이라는 **서로 다른 패키지 두 개**를 설치하라는 뜻이 돼요.

### 6) 터미널 명령을 파이썬 코드 안에 씀

`python3 --version`, `pip3 install ...`은 **터미널에 치는 명령**이에요. 파이썬 파일(`.py`)이나 `>>>` 뒤에 쓰면 에러가 나요. 실제로 해 보면 `pip3 install jupyterlab`은 `SyntaxError: invalid syntax`, `python3 --version`은 `NameError: name 'python3' is not defined`가 나요.

### 7) VS Code를 다운로드 폴더에서 그대로 실행

압축 푼 `.app`은 **응용 프로그램** 폴더로 옮긴 뒤에 써요. 그래야 Launchpad에도 보여요.
