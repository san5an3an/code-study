# 06. 함수와 객체의 이해

## 이 강의에서 배우는 것

- 수학의 함수 `f(x) = 2x + 1`에서 출발해 프로그램의 함수가 무엇인지(입력, 출력, 재사용)
- `def`로 함수를 정의하고, 파라미터와 `return`으로 값을 주고받는 흐름
- `print()`는 명령어가 아니라 **함수**이고, 파이썬에 미리 들어 있는 **내장 함수**라는 것
- 파이썬 공식 매뉴얼(API 도큐멘테이션)에서 내장 함수 찾아보기
- `type()`으로 데이터 타입 확인하기, 파이썬은 값을 대입할 때 타입이 정해진다는 것
- `input()`으로 받은 값은 무조건 문자열이고, `int()`, `float()`로 숫자로 바꾼다는 것
- 객체란 무엇인지, `객체.변수`와 `객체.함수()`를 읽는 법

> 복습: 지난 강의에서 변수를 배웠어요. 이번엔 지금까지 "명령어"라고 불러 온 `print`가 사실은 함수라는 걸 알고, 앞으로 계속 만나게 될 함수와 객체라는 두 용어를 처음 정리해요. 강사님 말로는 함수를 정의하는 코딩 규칙을 지금 외울 필요는 없고, **큰 맥락**을 보면 돼요.

## 1. 함수란 (수학에서 프로그램으로)

### 수학의 함수

어렸을 때 수학 시간에 이런 걸 배웠어요.

```
f(x) = 2x + 1
f(5) → 2 × 5 + 1 → 11
f(3) → 2 × 3 + 1 → 7
```

x 값 하나에 결과(y) 값이 **딱 하나씩만** 대응돼요. x가 1이면 y는 3이고, 다른 값이 될 수는 없어요. 이때 x와 y 사이에 있는 **규칙**을 함수라고 해요.

### 프로그램의 함수

같은 걸 프로그래밍 눈으로 보면 이렇게 정리돼요.

| 수학 | 프로그램 |
|---|---|
| 함수 이름 `f` | 함수 이름 |
| 입력값 `x` | 파라미터 |
| 수식 `2x + 1` | 함수에 속한 명령어 |
| 결과값 `y` | 리턴값(돌려주는 값) |

강사님이 짚은 중요한 개념 두 가지예요.

1. **입력값이 있고, 출력값이 있고, 계산이 재사용된다.** 입력값만 바꿔서 `2x + 1`이라는 계산을 몇 번이든 다시 써요.
2. **함수를 쓰려면 그 함수가 미리 정의되어 있어야 한다.** `f(1)`은 1, `f(2)`는 2, `f(3)`은 3이라는 결과만 보고는 어떤 규칙인지 알 수 없어요. `f(x) = x`라는 정의가 먼저 있어야 해요.

## 2. def로 함수 정의하고 사용하기

### 정의하는 모양

```python
def 함수이름(파라미터):
    함수에 속한 명령어 ...
    return 리턴값(혹은 식)
```

- `def`는 **define(정의하다)** 을 줄인 예약어(파이썬이 미리 정해 둔 단어)예요.
- 괄호 안의 입력값을 프로그램에서는 **파라미터**라고 불러요.
- 결과로 돌려줄 값은 `return` 뒤에 써요. 변수가 올 수도 있고 수식이 올 수도 있어요.
- `f(x) = 2x + 1`을 파이썬으로 옮기면 아래처럼 돼요. `*`는 곱하기예요.

```python
def f(x):
    return 2 * x + 1
```

### 사용하는 흐름

```python
y = f(1)
print(y)
```

1. `1`이 파라미터 `x`로 들어가요.
2. `2 * 1 + 1`을 계산해서 `3`이 돌아와요(반환).
3. 돌아온 `3`이 `y`에 대입되고, `print(y)`로 3이 출력돼요.

`z = f(5)`도 같아요. 5가 `x`로 들어가 `11`이 돌아오고 `z`에 담겨요. `f`를 한 번 정의해 두고 **두 번 재사용**한 거예요.

> 강사님 강조: **함수의 가장 큰 의미는 코드의 재사용이에요.** 지금은 이 재사용이라는 개념만 기억하면 돼요.

> **강의와 다른 점**: 강의 말(06:46쯤)로는 `y = f(1)`의 결과가 "z에 대입된다"고 했는데, 말이 헛나온 거예요. 화면 코드대로 `f(1)`의 결과는 `y`에, `f(5)`의 결과는 `z`에 들어가요.

### 예제 (code/define_function.py)

```python
# 함수 정의하기
def f(x):
    return 2 * x + 1   # * 는 곱하기예요

# 함수 사용하기 (1): 2가 x로 들어가서 2 * 2 + 1 = 5 가 돌아와요
y = f(2)
print(y)

# 함수 사용하기 (2): 5가 x로 들어가서 2 * 5 + 1 = 11 이 돌아와요
z = f(5)
print(z)

# 강의 슬라이드 예: 1을 주면 2 * 1 + 1 = 3 이 돌아와요
print(f(1))

# 한 번 정의한 함수는 입력값만 바꿔서 몇 번이든 다시 써요(재사용)
print(f(3))
```

실행 결과:

```
5
11
3
7
```

실습에서 함수를 정의하는 셀만 실행하면 아무것도 출력되지 않아요. 그래도 파이썬은 이제 `f`라는 함수를 알게 돼요. 그다음 셀에서 `f(2)`를 부를 수 있는 이유예요.

### 정의하지 않은 함수를 부르면

```python
print(g(1))
```

```
NameError: name 'g' is not defined
```

"`g`라는 이름이 정의되지 않았다"는 뜻이에요. 함수는 꼭 **미리 정의**해 두고 써야 해요.

> **참고(강의 밖 내용)**: 실습 중에 마크다운 셀을 코드 셀로 바꾸는 단축키도 나와요. 셀을 편집하던 중이면 `Esc`로 선택 모드로 나간 뒤 `Y`를 누르면 코드 셀이 돼요(마크다운으로 바꾸는 건 `M`). 마우스 우클릭 메뉴에서 바꿔도 돼요.

## 3. print()는 명령어가 아니라 내장 함수

첫 실습부터 써 온 `print`를 정식으로 소개하면 이래요.

- `print`는 **파라미터로 전달된 내용을 출력하는 함수**예요.
- 그러니까 "print 명령어"가 아니라 **"print 함수"** 라고 부르는 게 맞아요. 강사님은 앞으로 "명령어"라는 말 대신 "함수"라는 말을 쓰자고 해요.
- `print(a + b)`처럼 쓸 때마다 같은 `print` 함수를 **재사용**하는 거예요.

그런데 함수는 미리 정의되어 있어야 한다고 했는데, 우리는 `print`를 정의한 적이 없어요. `print`는 **파이썬 안에 미리 정의되어 있어서** 그래요. 이렇게 파이썬이 개발자에게 "쓰세요" 하고 미리 만들어 둔 함수를 **내장 함수**라고 해요. 앞으로 공부할 것 중 하나가 바로 내장 함수의 종류와 기능을 익히는 거예요.

> **강의와 다른 점**: 강의 슬라이드에는 `print`가 "리턴값은 없다"고 적혀 있어요. 출력만 하고 쓸모 있는 값을 돌려주지 않는다는 뜻으로는 맞지만, 파이썬에서는 정확히 **`None`(값 없음을 뜻하는 특별한 값)** 을 돌려줘요. `result = print("출력만 해요")` 다음에 `print(result)`를 하면 `None`이 나와요(아래 예제에서 3.14로 확인).

## 4. 파이썬 공식 매뉴얼 (API 도큐멘테이션)

- 주소: `https://docs.python.org/ko/3/`
- 함수를 비롯해 프로그래밍 언어가 제공하는 기능들을 통틀어 **API**(Application Programming Interface)라고 해요. 이 문서는 쉽게 말해 **파이썬 공식 매뉴얼**이에요.
- 내장 함수 목록: 메인 페이지 → **라이브러리 레퍼런스** → **내장 함수** (`https://docs.python.org/ko/3/library/functions.html`). 함수들이 알파벳 순으로 나와 있고, 하나를 누르면 자세한 사용법이 나와요.

강사님 말로는 세상 어떤 책이나 수업도 이 사이트보다 방대하지 못해요. 파이썬을 만든 사람들이 정리한 원본이라, 다른 책과 수업은 모두 이걸 바탕으로 살을 붙인 거예요. 다만 처음 배우는 사람에게는 문장이 어렵고 예제가 너무 간결해요. 그래서 강사님 역할은 이 내용을 재해석해서 알맞은 예제로 보여 주는 거고, **궁극적인 목표는 여러분이 이 문서를 직접 읽고 이해하게 되는 것**이에요. 다 외울 필요는 없고, 찾아보고 이해할 수 있으면 스스로 실력을 쌓아 갈 수 있어요.

> **참고(강의 밖 내용)**: 강의 화면의 문서는 Python 3.11.1 판이에요. 지금 들어가면 3.14 같은 최신 판이 기본으로 떠요. 왼쪽 위 버전 선택 상자로 판을 고를 수 있고, 메뉴 구성(라이브러리 레퍼런스 → 내장 함수)은 같아요.

## 5. type() 함수: 데이터 타입 확인

`type()`은 **파라미터로 전달받은 값의 데이터 타입을 판단해서 돌려주는** 내장 함수예요.

```python
t = type(변수)
print(t)
```

### 예제 (code/builtin_type.py)

```python
# print 도 함수예요. 파라미터로 받은 내용을 출력해요
print("Hello World")

a = 100
b = 200
print(a + b)   # 같은 print 함수를 또 재사용했어요

# type() 은 파라미터로 받은 값의 데이터 타입을 판단해서 돌려줘요
age = 20
typeOfAge = type(age)
print(typeOfAge)

print(type(3.14))
print(type("안녕"))

# 참고: print 는 화면에 출력만 하고, 돌려주는 값은 None(값 없음)이에요
result = print("출력만 해요")
print(result)
```

실행 결과:

```
Hello World
300
<class 'int'>
<class 'float'>
<class 'str'>
출력만 해요
None
```

`<class 'int'>`는 "int(정수) 종류"라는 뜻이에요. `float`는 실수, `str`은 문자열이에요.

### 파이썬은 대입할 때 타입이 정해져요

강사님이 다른 언어를 배운 사람을 위해 짚은 부분이에요.

- C언어나 Java는 변수를 **선언**할 때 데이터 타입을 같이 적어요. (예: Java의 `int age = 20;`)
- 파이썬은 선언이 없고 그냥 바로 값을 대입해요. 그래서 데이터 타입은 **값을 대입하면서 결정**돼요. `age = 20`이면 정수, `age = "스물"`이면 문자열이에요.

> **참고(강의 밖 내용)**: 공식 문서를 보면 `type`은 `class type(object)`라고 적혀 있어요. 엄밀히는 함수가 아니라 "클래스(자료형 그 자체)"인데, 함수처럼 괄호를 붙여 부를 수 있어서 이번 강의처럼 함수라고 불러도 쓰는 데는 문제없어요. 클래스는 나중에 배워요.

## 6. input() 함수: 키보드로 입력받기

### 모양

```python
변수이름 = input("표시할 메시지 내용")
```

- 보통 변수는 `a = "안녕"`처럼 코드에 값을 직접 적어요. `input()`을 쓰면 **사용자가 키보드로 입력한 값**을 변수에 담을 수 있어요.
- 실행하면 메시지가 보이고, 내용을 입력한 뒤 엔터를 누르면 `input()`이 그 내용을 **돌려줘요(리턴)**. 그 값이 변수에 대입돼요.
- 강사님 말: `=`(대입 연산자)가 있으면 **항상 오른쪽을 먼저** 보세요. `input()`이 먼저 실행되고, 그 결과가 왼쪽 변수에 들어가요.

> **참고(강의 밖 내용)**: 강의처럼 VS Code의 주피터 노트북에서 실행하면 **화면 맨 위에 입력 상자**가 떠요. 터미널에서 `python3 파일.py`로 실행하면 메시지가 터미널에 찍히고 그 자리에서 바로 입력해요. 또 메시지 끝에 공백이 없어서 입력한 글자가 메시지에 딱 붙어 보이니까, `input("정수를 입력하세요: ")`처럼 끝에 `: `를 넣으면 보기 좋아요.

### 입력값은 무조건 문자열이에요

```python
msg1 = input("메시지를 입력하세요")   # Hello Python 입력
print(msg1)
t = type(msg1)
print(t)
```

```
Hello Python
<class 'str'>
```

숫자 `123`을 입력해도 결과는 문자열(`str`)이에요. 강사님이 여러 번 강조해요. **"입력값은 모두 문자열이다. 중요한 거니까 기억하세요."**

> **강의와 다른 점**: 강의에서는 문자열 `"12345"`로는 "더하기 빼기 곱하기 나누기 같은 거 못한다"고 했는데, 정확히는 **숫자 계산이 안 되는** 거예요. 문자열끼리 `+`는 에러 없이 **이어 붙이기**(`"123" + "123"` → `123123`)가 되고, 정수를 곱하면 **반복**(`"123" * 2` → `123123`)이 돼요. 빼기는 `TypeError: unsupported operand type(s) for -: 'str' and 'str'`로 에러가 나요(3.14에서 확인). 그래서 더하기는 에러도 안 나고 엉뚱한 답이 나와서 더 조심해야 해요. 자세한 건 08강 문자열에서 배워요.

### int(), float()로 숫자로 바꾸기

입력받은 값으로 계산을 해야 하면 또 다른 내장 함수를 써요.

| 함수 | 하는 일 |
|---|---|
| `int(값)` | 정수로 바꿔서 돌려줘요 |
| `float(값)` | 실수(소수점 있는 수)로 바꿔서 돌려줘요 |

### 예제 (code/input_to_number.py)

> 이 파일은 바로 실행되도록 `input()` 대신, `input()`이 돌려줬을 문자열을 직접 넣어 뒀어요. 강의처럼 직접 입력해 보려면 `msg2 = "123"`을 `msg2 = input("정수를 입력하세요")`로 바꿔서 실행하면 돼요.

```python
# 문자열 입력받기: 무엇을 입력해도 input() 의 결과는 문자열(str)이에요
msg1 = "Hello Python"
print(msg1)
t = type(msg1)
print(t)

# 숫자를 입력해도 결과는 문자열이에요
msg2 = "123"
print(msg2)
t1 = type(msg2)
print(t1)

# int() 에 넘기면 정수로 바꿔서 돌려줘요
num = int(msg2)
print(num)
t2 = type(num)
print(t2)

# 실수가 필요하면 int() 대신 float() 를 써요
msg3 = "3.14"
print(msg3)
t3 = type(msg3)
print(t3)
fnum = float(msg3)
print(fnum)
t4 = type(fnum)
print(t4)

# 문자열인 채로 더하면 숫자 덧셈이 아니라 이어 붙이기가 돼요
print(msg2 + msg2)            # 123123
print(int(msg2) + int(msg2))  # 246
```

실행 결과:

```
Hello Python
<class 'str'>
123
<class 'str'>
123
<class 'int'>
3.14
<class 'str'>
3.14
<class 'float'>
123123
246
```

`123`과 `3.14`는 바꾸기 전과 후의 출력 모양이 똑같아요. 그래서 눈으로는 구별이 안 되고, `type()`으로 확인해야 `str`인지 `int`/`float`인지 알 수 있어요.

> **참고(강의 밖 내용)**: 소수점이 있는 문자열을 `int()`에 바로 넘기면 에러가 나요.
> ```
> ValueError: invalid literal for int() with base 10: '3.14'
> ```
> "10진수 정수로 읽을 수 없는 글자"라는 뜻이에요. `hello`처럼 숫자가 아닌 글자를 넘겨도 같은 에러가 나요. 실수 모양 문자열은 `float()`로 바꾸세요.

## 7. 정수와 실수 서로 바꾸기

- 정수를 `float()`에 주면 실수를 뜻하는 **`.0`이 붙어요**.
- 실수를 `int()`에 주면 **소수점 아래를 무조건 버려요.** 강사님 말대로 **반올림이 아니라는 점**에 주목하세요. `123.78`은 124가 아니라 `123`이 돼요.

### 예제 (code/int_float_conversion.py)

```python
# 정수를 실수로 변환 --> 정수 뒤에 ".0"이 붙어요
num1 = 100
num2 = float(num1)
print(num2)

# 변환 결과의 데이터 타입 확인 --> 실수(float)
t1 = type(num2)
print(t1)

# 실수를 정수로 변환 --> 소수점을 버려요(반올림이 아니에요)
num3 = 123.78
num4 = int(num3)
print(num4)

# 변환 결과의 데이터 타입 확인 --> 정수(int)
t2 = type(num4)
print(t2)

# 참고: 음수도 소수점을 그냥 잘라 내서 0 쪽으로 가까워져요
print(int(-3.7))
```

실행 결과:

```
100.0
<class 'float'>
123
<class 'int'>
-3
```

> **참고(강의 밖 내용)**: 마지막 줄은 강의에 없는 내용이에요. `int()`는 소수점 아래를 잘라 내기만 해서, 음수 `-3.7`은 더 작은 `-4`가 아니라 `-3`이 돼요.

## 8. 객체란

### 사전적인 뜻

- **객체(object, 오브젝트)** 는 현실 세계에 존재하는 어떤 사물이에요.
- 객체가 중심이 되는 프로그래밍 언어를 **객체지향 언어**라고 해요. 앞에서 배운 4세대 언어의 특징이었어요.
- 둘을 합치면 객체지향 언어는 "현실 세계에 존재하는 것을 프로그래밍 언어로 표현한 것"인데, 강사님 말로는 너무 철학적이라 무슨 말인지 와닿지 않아요.

### 강사님의 정의

> **객체 = 필요에 따라 다른 변수와 함수를 내장하고 있는 특수한 형태의 변수**

어떤 대상을 **명사적인 특성**과 **동사적인 특성**으로 나눠서 정의해요. "회원"이라는 객체를 만든다면 이래요.

| 구분 | 설명 | 사용 예 |
|---|---|---|
| 명사적 특성 (=멤버 변수) | 아이디 | `userid = "hello"` |
| | 비밀번호 | `userpw = "1234"` |
| | 메일주소 | `email = "hello@gmail.com"` |
| 동사적 특성 (=함수, 메서드) | 가입하다 | `def join():` |
| | 탈퇴하다 | `def out():` |
| | 로그인하다 | `def login():` |

- 명사로 표현되는 것은 **변수** 형태로 들어 있어요. 객체에 들어 있는 변수를 **멤버 변수**라고 불러요.
- 동사로 표현되는 것은 **함수** 형태로 들어 있어요. 객체에 들어 있는 함수를 **메서드**라고도 불러요.
- 강사님 말로는 "멤버 변수"는 좀 옛날 말이고, 요즘 언어들은 **프로퍼티(속성)** 라고도 해요.

> **참고(강의 밖 내용)**: 파이썬 공식 문서에서는 객체에 들어 있는 변수와 메서드를 통틀어 **어트리뷰트(attribute, 속성)** 라고 불러요. 파이썬에서 "프로퍼티(property)"는 따로 있는 특별한 기능 이름이라, 파이썬 문서를 읽을 때는 "속성 = 어트리뷰트"로 기억하면 덜 헷갈려요.

### 점(.)으로 꺼내 쓰기

객체 안에 들어 있는 것에 접근할 때는 객체 이름 뒤에 **점(`.`)** 을 붙여요.

```python
print(member.userid)   # 객체이름.변수
member.join()          # 객체이름.함수()
member.login()
```

(위 `member`는 설명용이라, 실제로 실행하려면 `member` 객체를 먼저 만들어야 해요. 객체를 만드는 법은 나중에 배워요.)

강사님이 꼭 기억하라고 한 읽는 법이에요.

- 코드 중간에 점이 나오면 **점 왼쪽은 무조건 객체**예요.
- 점 오른쪽에 **괄호가 없으면 변수**, **괄호가 있으면 함수**예요.

## 9. 파이썬의 모든 변수는 객체

이 개념을 지금 배우는 이유예요. 파이썬에서는 **모든 변수가 객체 형태로 존재**해요. `a = 1`처럼 숫자 하나만 넣어도 파이썬이 그 안에 쓸 수 있는 변수와 메서드를 알아서 넣어 줘요. 그래서 "나는 그냥 숫자 변수를 만들었는데" 코드에 `a.무엇`처럼 점이 나오는 일이 생겨요. 강사님이 변수를 "객체"라고 부르는 이유가 이거예요.

> **참고(강의 밖 내용)**: 더 정확히 말하면 객체인 건 변수가 아니라 **변수에 담긴 값**이에요. 변수는 그 값에 붙인 이름표예요. 또 메서드가 값마다 하나씩 복사돼 들어가는 게 아니라, 값의 종류(`int`, `float` 같은 타입)가 메서드를 갖고 있고 모든 값이 그걸 같이 써요. 처음엔 강사님 말대로 "값을 만들면 쓸 수 있는 기능이 딸려 온다" 정도로 이해하면 충분해요.

### 예제 (code/object_methods.py)

```python
# 실수형 변수의 초기화
pi = 3.14

# 객체에 포함되는 메서드 활용하기 --> 소수점 올림
a = pi.__ceil__()
print(a)

# 객체에 포함되는 메서드 활용하기 --> 소수점 내림
b = pi.__floor__()
print(b)

# 객체.변수 (괄호 없음) : 객체 안에 들어 있는 값을 꺼내요
# 실수 객체에는 real(실수부)이라는 값이 들어 있어요
r = pi.real
print(r)

# 객체.함수() (괄호 있음) : 객체 안에 들어 있는 함수를 실행해요
# 실수 객체의 is_integer() 는 소수점 아래가 0인지 알려 줘요
print(pi.is_integer())
print((4.0).is_integer())

# 참고(강의 밖 내용): 앞뒤에 밑줄 두 개가 붙은 메서드는 보통 직접 부르지 않고
# math 모듈의 ceil(), floor() 를 써요. 결과는 같아요
import math
print(math.ceil(pi))
print(math.floor(pi))
```

실행 결과:

```
4
3
3.14
False
True
4
3
```

- `__ceil__()`(실링, 천장)은 소수점을 **올림**해요. 3.14 → 4
- `__floor__()`(플로어, 바닥)는 소수점을 **내림**해요. 3.14 → 3
- 이름 앞뒤에 밑줄(`_`)이 두 개씩 붙어 있어요. 하나라도 빠지거나 `pi.ceil()`처럼 쓰면 `AttributeError: 'float' object has no attribute 'ceil'`(그런 속성이 없다)가 나요.

`pi.real`, `is_integer()`, `math` 부분은 강의 밖 내용이에요. `객체.변수`와 `객체.함수()`를 직접 비교해 보려고 넣었어요.

### 대입할 때 읽는 법

강사님이 펜으로 정리한 내용이에요.

```python
a = 객체.함수()   # 함수를 실행하고, 그 리턴값을 a에 대입
a = 객체.변수     # 객체가 갖고 있는 변수의 값을 a에 복사
```

> 강사님 말: 객체는 앞으로 어떤 언어로 프로그래밍을 하든 계속 만나게 될 용어라 **첫 단추를 잘 꿰는 게** 무척 중요해요.

## 자주 하는 실수

### 1) 함수를 정의하기 전에 부름

```python
print(f(1))     # NameError: name 'f' is not defined
def f(x):
    return 2 * x + 1
```

파이썬은 위에서 아래로 읽어요. `def`가 먼저 실행된 다음에 불러야 해요.

### 2) def 줄 끝의 콜론(:)이나 들여쓰기를 빼먹음

```python
def f(x)          # SyntaxError: expected ':'
    return 1
```

```python
def f(x):
return 1          # IndentationError: expected an indented block after function definition on line 1
```

`def` 줄 끝에는 `:`을 붙이고, 함수에 속한 줄은 한 칸 안쪽으로 들여 써요.

### 3) return을 빼먹음

```python
def g(x):
    2 * x + 1     # 계산만 하고 돌려주지 않음
print(g(1))       # None
```

계산 결과를 돌려주려면 `return`을 꼭 써요.

### 4) input으로 받은 값을 그대로 계산함

```python
msg = input("정수를 입력하세요")   # 123 입력
print(msg + msg)              # 123123 (이어 붙이기)
print(int(msg) + int(msg))    # 246
```

### 5) 실수 모양 문자열을 int()에 바로 넘김

```python
int("3.14")     # ValueError: invalid literal for int() with base 10: '3.14'
float("3.14")   # 3.14
```

### 6) int()가 반올림해 줄 거라고 생각함

```python
int(123.78)     # 124가 아니라 123
```

### 7) 밑줄 두 개짜리 메서드 이름을 틀리게 씀

```python
pi.ceil()       # AttributeError: 'float' object has no attribute 'ceil'
pi.__ceil__()   # 4
```

## 용어 정리

| 용어 | 쉬운 뜻 |
|---|---|
| 함수 | 재사용할 수 있게 묶어 둔 명령어. 입력을 받아 결과를 돌려줌 |
| def | 함수를 정의(define)할 때 쓰는 예약어 |
| 예약어 | 파이썬이 미리 정해 둔 특별한 단어. 변수 이름으로 못 씀 |
| 파라미터 | 함수에 넣어 주는 입력값 |
| 리턴값(반환값) | 함수가 계산을 마치고 돌려주는 결과값 |
| return | 리턴값을 돌려줄 때 쓰는 키워드 |
| 재사용 | 한 번 정의한 함수를 입력만 바꿔 여러 번 쓰는 것 |
| 내장 함수 | 파이썬에 미리 정의되어 있는 함수. print, type, input, int, float 등 |
| API | 프로그래밍 언어가 제공하는 기능들을 통틀어 부르는 말 |
| API 도큐멘테이션 | 파이썬 공식 매뉴얼(docs.python.org) |
| type() | 값의 데이터 타입을 알려 주는 내장 함수 |
| input() | 키보드로 입력한 내용을 문자열로 돌려주는 내장 함수 |
| int() / float() | 값을 정수 / 실수로 바꿔 주는 내장 함수 |
| None | "값 없음"을 뜻하는 특별한 값 |
| 객체(object) | 필요에 따라 다른 변수와 함수를 내장하고 있는 특수한 변수 |
| 객체지향 언어 | 객체가 중심이 되는 프로그래밍 언어 |
| 멤버 변수 | 객체 안에 들어 있는 변수. 프로퍼티, 속성이라고도 함 |
| 메서드 | 객체 안에 들어 있는 함수 |
| NameError | 정의되지 않은 이름을 썼을 때 나는 에러 |
| ValueError | 값의 모양이 맞지 않을 때 나는 에러. 예: `int("3.14")` |
| AttributeError | 객체에 없는 변수나 메서드를 찾을 때 나는 에러 |
