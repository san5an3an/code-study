# 07. 연산자

## 이 강의에서 배우는 것

- 연산자가 무엇이고, 크게 어떤 종류(대입, 산술, 단항, 비교, 논리)가 있는지
- 나눗셈 연산자 세 가지: `/`(소수점까지), `//`(몫만), `%`(나머지만), 그리고 거듭제곱 `**`
- `+=`, `-=`처럼 계산 결과를 자기 자신에게 다시 넣는 줄임 표현
- 비교 연산자와 논리 연산자(`and`, `or`)의 결과는 `True` 아니면 `False`라는 것
- 연산자 우선순위: 괄호가 제일 먼저, `and`가 `or`보다 먼저
- `==`와 `is`의 차이
- 첫 번째 프로젝트: BMI(신체질량지수) 계산기

> 복습: 지난 강의까지 변수와 자료형(정수, 실수, 문자열, 불린), 함수와 객체를 배웠어요. 이번엔 그 변수들로 계산을 하는 기호, 연산자를 배워요. 강사님은 연산 결과를 실행하기 전에 **먼저 암산으로 맞혀 보고** 결과를 확인하라고 권해요.

## 1. 연산자란

**연산자**는 프로그램에서 계산(연산)을 하려고 쓰는 **특수 기호**예요. 어렸을 때 수학 시간에 배운 더하기(+), 빼기(-), 곱하기(×), 나누기(÷) 기호가 다 연산자예요.

강의 슬라이드는 연산자를 다섯 가지로 나눠요.

| 종류 | 설명 | 기호 |
|---|---|---|
| 대입 연산자 | 변수에 값을 넣거나, 계산 결과를 다른 변수에 넣어요 | `=` |
| 산술 연산자 | 사칙 연산(더하기, 빼기, 곱하기, 나누기). 사칙 연산자라고도 해요 | `+` `-` `*` `/` `//` `%` `**` |
| 단항 연산자(강의 이름) | 변수의 계산 결과를 다시 자기 자신에게 넣어요 | `+=` `-=` `*=` `/=` `//=` `%=` |
| 비교 연산자(관계 연산자) | 두 값을 비교해서 참인지 거짓인지 알려 줘요 | `==` `!=` `>` `>=` `<` `<=` |
| 논리 연산자 | 참/거짓 값끼리 `and`, `or` 계산을 해요 | `and` `or` |

- 키보드에는 `×`, `÷`가 없어서 곱하기는 **별표(`*`)**, 나누기는 **슬래시(`/`)** 로 써요.

> **강의와 다른 점**: 슬라이드와 강의 말로는 비교·논리 연산자가 참이면 `1`, 거짓이면 `0`을 돌려준다고 했는데, 파이썬에서 실제로 출력되는 값은 `True`와 `False`예요. 파이썬 안에서 `True == 1`이 `True`일 만큼 `True`는 1과, `False`는 0과 같게 취급되긴 해요(python3 3.14에서 `print(True == 1)` → `True` 확인). 그래도 화면에는 `True`/`False`로 나온다고 기억하세요.

## 2. 대입 연산자 `=`

`=`는 **오른쪽 값을 왼쪽 변수에 넣는다**는 뜻이에요.

- 수학에서 `=`는 "대입한다"와 "같다" 두 가지 뜻으로 쓰지만, 프로그래밍에서 `=`는 **"대입한다"는 뜻으로만** 써요. "같다"는 `==`(3절)를 써요.
- 대입은 항상 **오른쪽에서 왼쪽으로** 이루어져요. 강사님은 "대입 연산자가 있으면 항상 오른쪽을 먼저 보세요"라고 해요.

두 가지 경우가 있어요.

1. **변수에 값을 대입**: `pi = 3.14`. 일반적인 변수의 초기화(처음 값 넣기) 과정이에요.
2. **변수에 다른 변수를 대입**: `b = a`. `a`에 담긴 값이 `b`로 **복사**돼요. 강사님은 메모리에 `a`라는 이름표를 붙인 칸에 3을 넣고, 또 다른 칸에 `b`라는 이름표를 붙여 3을 그대로 복사해 넣는 그림으로 설명해요.

### 예제 (code/assignment.py)

```python
pi = 3.14
money = 12000
print(pi)
print(money)

a = 3
b = a
print(a, b)

c = 5 + 10   # 오른쪽 5 + 10 을 먼저 계산해서 c 에 넣어요
print(c)
```

실행 결과:

```
3.14
12000
3 3
15
```

> **참고(강의 밖 내용)**: 파이썬 안에서 실제로 일어나는 일은 "값을 새 칸에 복사"라기보다 `a`와 `b`가 **같은 값 3을 함께 가리키는** 거예요. 정수나 문자열처럼 바꿀 수 없는 값에서는 복사라고 생각해도 결과가 똑같으니 지금은 강의 그림대로 이해하면 돼요. 이 차이는 7절 `is`에서 조금 더 나와요.

## 3. 산술 연산자 (사칙 연산과 거듭제곱)

| 연산자 | 뜻 | 예 | 결과 |
|---|---|---|---|
| `+` | 더하기 | `3 + 4` | `7` |
| `-` | 빼기 | `3 - 4` | `-1` |
| `*` | 곱하기 | `3 * 4` | `12` |
| `/` | 나누기(소수점까지) | `3 / 4` | `0.75` |
| `**` | 거듭제곱 | `2 ** 5` | `32` |

슬라이드가 정리한 규칙 세 가지예요.

- 계산 결과는 대입 연산자로 다른 변수에 넣을 수 있어요. 예: `a = 5 + 10`
- **정수와 실수를 같이 계산하면** 정수가 실수로 자동 변환돼서 **결과는 실수**예요. 예: `1 + 1.2` → `2.2`
- **어떤 수도 0으로 나눌 수 없어요.** `10 / 0`은 에러가 나요.

```
ZeroDivisionError: division by zero
```

"0으로 나누기"라는 뜻이에요. `//`, `%`도 0으로 하면 똑같은 에러가 나요.

**거듭제곱**은 곱하기 기호를 두 번(`**`) 써요. `2 ** 5`는 2를 다섯 번 곱한 `2 * 2 * 2 * 2 * 2`, 즉 2의 5제곱이라 `32`예요.

### 예제 (code/arithmetic.py)

강의 노트북 07강-연산자.ipynb의 "기본적인 사칙 연산"이에요. 주피터는 앞 셀에서 만든 변수가 다음 셀에서도 이어지기 때문에 강의에서는 셀을 나눴지만, 파일로는 한 번에 써요.

```python
a = 3
b = 4
c = a + b
print(c)

print(a - b)
print(a * b)
print(a / b)

print(1 + 1.2)
print(2 ** 5)
print(3 ** 5)
```

실행 결과:

```
7
-1
12
0.75
2.2
32
243
```

## 4. 나눗셈 연산자 세 가지 `/`, `//`, `%`

강사님이 "주의하셔야 될 부분"이라고 짚은 곳이에요. 나눗셈 기호가 세 개나 있어요.

| 연산자 | 뜻 | `10 ? 3` | `10 ? 4` |
|---|---|---|---|
| `/` | 소수점 아래까지 계산 | `3.3333333333333335` | `2.5` |
| `//` | 몫만(정수 부분) | `3` | `2` |
| `%` | 나머지만 | `1` | `2` |

강사님 설명: 10 나누기 4가 2.5라는 건 나중에 배운 거고, 더 어릴 때는 "10 나누기 4는 **몫이 2, 나머지가 2**"라고 배웠죠. 그 몫을 구하는 게 `//`, 나머지를 구하는 게 `%`예요.

`/`는 나눠 떨어져도 결과가 실수예요. `10 / 5`는 `2`가 아니라 `2.0`이에요.

### 예제 (code/division.py)

```python
print(10 / 3)
print(10 / 4)
print(10 // 3)
print(10 // 4)
print(10 % 3)
print(10 % 4)
print(10 / 5)
```

실행 결과:

```
3.3333333333333335
2.5
3
2
1
2
2.0
```

### `10 / 3`의 끝자리 5는 왜 나올까요

강의에서는 `/`가 "처리할 수 없는 자리수까지 계속 나누다가 더 이상 못 하겠다 하면 오차를 발생시키고 종료한다"고 설명해요. 그래서 3.333...이 이어지다 맨 끝이 `5`로 끝나요.

> **참고(강의 밖 내용)**: 여기서 "종료"는 프로그램이 멈춘다는 뜻이 아니에요. 실수는 컴퓨터가 정해진 자리수만큼만 담을 수 있어서, 그 자리에서 **반올림한 값**을 결과로 내놓고 계산은 정상적으로 끝나요. 같은 이유로 `0.1 + 0.2`도 `0.30000000000000004`가 나와요(python3 3.14에서 확인). 실수 계산 결과는 아주 작은 오차가 있을 수 있다고 알아 두세요.

> **참고(강의 밖 내용)**: `//`는 정확히는 "소수점 아래 버리기"가 아니라 **더 작은 쪽 정수로 내림**이에요. 양수에서는 똑같지만 음수에서는 달라요. `-7 // 2`는 `-3`이 아니라 `-4`, `-7 % 2`는 `1`이에요. 또 실수끼리 하면 결과도 실수라서 `7.5 // 2`는 `3.0`이에요(모두 python3 3.14에서 확인).

## 5. 단항 연산자(강의 이름) `+=`, `-=`, `*=` ...

어떤 변수의 계산 결과를 **다시 그 변수 자신에게 넣을 때** 쓰는 줄임 표현이에요.

```python
x = 100
x = x + 5   # 오른쪽 100 + 5 = 105 를 먼저 계산해서 다시 x 에 넣어요
```

이걸 줄이면 이렇게 돼요.

```python
x = 100
x += 5      # "x 스스로 5 증가"
```

모든 사칙 연산자에 쓸 수 있어요: `+=`, `-=`, `*=`, `/=`, `//=`, `%=`

> 강사님 정리: 이 중에서 가장 많이 쓰는 것만 집중해서 기억해도 괜찮다고 해요. 강의 말은 "곱하기 이콜과 빼기 이콜"로 들리지만, 화면에서 동그라미 친 건 `+=`와 `-=`예요.

강사님은 실습 끝에 "굉장히 많이 쓰는 연산자"라고 다시 강조해요. 기존 값과 계산해서 그 변수에 **덮어씌우는** 거라, 한 줄 지날 때마다 값이 계속 바뀌어요.

> **강의와 다른 점**: 강의에서는 `+=` 같은 것을 "단항 연산자"라고 부르는데, 파이썬 공식 이름은 **복합 대입 연산자**(augmented assignment, 줄여 쓰는 대입)예요. 파이썬에서 "단항 연산자"는 값 **하나**에만 붙는 `-x`, `+x`, `not x` 같은 걸 가리켜요. python3의 `ast` 모듈로 확인하면 `x += 5`는 `AugAssign`(복합 대입), `-x`와 `not x`는 `UnaryOp`(단항 연산)으로 나와요(3.14에서 확인). 다른 책이나 검색에서 "단항 연산자"를 찾으면 `-x` 이야기가 나오니 헷갈리지 마세요.

> **참고(강의 밖 내용)**: 다른 언어의 `x++`(1 증가)는 파이썬에 없어요. 쓰면 `SyntaxError: invalid syntax`가 나요. 파이썬에서는 `x += 1`로 써요.

### 예제 (code/augmented_assignment.py)

```python
x = 100
x = x + 5
print(x)

x = 100
x += 5
print(x)

a = 1
a += 100   # 1 + 100 -> 101
a *= 10    # 101 * 10 -> 1010
a //= 3    # 1010 // 3 -> 336
a %= 5     # 336 % 5 -> 1
print(a)
```

실행 결과:

```
105
105
1
```

1010을 3으로 나누면 몫이 336이고 나머지는 버려요. 336을 5로 나눈 나머지가 1이라서 최종 값은 `1`이에요.

## 6. 비교 연산자

어렸을 때 **부등식**으로 배운 거예요. 같다, 다르다, 크다, 크거나 같다, 작다, 작거나 같다를 비교해요.

| 같다 | 다르다 | 초과(크다) | 이상(크거나 같다) | 미만(작다) | 이하(작거나 같다) |
|---|---|---|---|---|---|
| `==` | `!=` | `>` | `>=` | `<` | `<=` |

- **같다는 `=` 두 개(`==`)** 예요. `=` 하나는 대입이라서 완전히 다른 뜻이에요.
- `!`(느낌표)는 "아니다(not)"라는 뜻이 있어서 `!=`는 "같지 않다"예요.
- 수학의 `≥`, `≤`는 키보드로 못 치니까 `>=`, `<=`처럼 부등호와 `=`를 이어서 써요. 순서는 **부등호가 먼저, `=`가 뒤**예요.

비교 결과는 참 아니면 거짓, 둘 중 하나라서 **논리값(bool형)** 으로 나와요. `True`가 참, `False`가 거짓이에요. 강사님 말대로 **첫 글자는 대문자**예요. `true`라고 쓰면 그런 이름이 없다는 에러(`NameError`)가 나요.

> **강의와 다른 점**: 슬라이드 표에는 "같다 `==` 혹은 `is`", "다르다 `!=` 혹은 `not is`"라고 적혀 있는데, 두 군데가 틀렸어요.
> - `not is`라는 연산자는 없어요. `x not is 1`은 `SyntaxError: invalid syntax`예요. 맞는 표기는 **`is not`** 이에요(강의 실습 화면도 `is not`으로 씀).
> - `is`는 `==`와 같은 뜻이 아니에요. 자세한 건 7절에서 봐요.

### 예제 (code/comparison.py)

```python
print(100 == 50)
print(100 != 50)
print(100 >= 50)
print(100 > 50)
print(100 < 50)
print(100 <= 50)

result = 100 > 50   # 비교 연산도 하나의 수식이라 결과를 변수에 담을 수 있어요
print(result)
```

실행 결과:

```
False
True
True
True
False
False
True
```

> 강사님이 짚은 부분: 비교 결과를 변수에 담을 수 있다는 걸 나중에 기억 못 하는 사람이 많대요. 이것만 기억해도 코드가 훨씬 간결해질 수 있다고 강조해요.

## 7. `==`와 `is`의 차이

강의 마지막 실습은 `is` 연산자예요.

```python
x = 100
y = 100.0
print(x == y)       # True
print(x != y)       # False
print(x is y)       # False
print(x is not y)   # True
```

- `==`, `!=`는 **값**만 비교해요. 정수 `100`과 실수 `100.0`은 값이 같아서 `x == y`는 `True`예요.
- `is`, `is not`은 결과가 다르게 나왔어요. `x is y`는 `False`예요.

> **강의와 다른 점**: 강의에서는 "`is`는 비교하는 값의 **데이터 타입까지 일치해야만** True"라고 설명해요. 위 예제 결과는 그 설명과 맞아 보이지만, 정확한 뜻은 **"두 변수가 같은 객체(메모리 속 같은 값 하나)를 가리키는가"** 예요. 그래서 자료형이 같고 값도 같아도 `False`가 나올 수 있어요. 아래 예제의 `p`와 `q`는 둘 다 정수 1000인데 `p is q`는 `False`예요(python3 3.14, CPython에서 확인). 자료형까지 같은지 보고 싶으면 `type(p) == type(q)`처럼 따로 비교해요.
>
> 또 코드에 숫자를 직접 적어 `x is 100`처럼 쓰면 파이썬이 경고를 줘요.
> ```
> SyntaxWarning: "is" with 'int' literal. Did you mean "=="?
> ```
> "`==`를 쓰려던 것 아니냐"는 뜻이에요. **값이 같은지 볼 때는 항상 `==`** 를 써요. `is`는 나중에 배울 `None`과 비교할 때(`x is None`) 주로 써요.

> **참고(강의 밖 내용)**: 강의 실습 주석에 "1과 1.0을 같다고 판별"이라고 적혀 있는데, 변수 값은 `100`과 `100.0`이에요. 1과 1.0이든 100과 100.0이든 `==` 결과는 똑같이 `True`예요.

### 예제 (code/is_operator.py)

```python
x = 100
y = 100.0
print(x == y)
print(x != y)
print(x is y)
print(x is not y)

p = 1000
q = int("1000")            # 문자열을 바꿔서 새로 만든 정수예요
print(p == q)
print(type(p) == type(q))
print(p is q)
```

실행 결과:

```
True
False
False
True
True
True
False
```

## 8. 논리 연산자 `and`, `or`

중학교 수학의 **명제** 단원에서 나오는 내용이에요. 비교 연산 결과나 논리값(`True`/`False`)끼리 `and`, `or` 계산을 해요.

### and: 모두 참일 때만 참

| and | True | False |
|---|---|---|
| **True** | True | False |
| **False** | False | False |

하나라도 거짓이 있으면 전체가 거짓이에요.

### or: 하나라도 참이면 참

| or | True | False |
|---|---|---|
| **True** | True | True |
| **False** | True | False |

`False or False`만 거짓이에요.

### 비교 연산과 결합하기

비교 연산의 결과도 `True`/`False`라서, 그 결과로 논리 연산을 할 수 있어요.

```python
a = 100 > 50          # True
b = 20 > 10           # True
print(a and b)        # True and True -> True

c = 100 >= 100 and 50 == 10   # True and False -> False
print(c)
```

비교 연산자(`>=`, `==`)가 `and`보다 먼저 계산되기 때문에 괄호 없이 써도 돼요(9절 우선순위).

### 예제 (code/logical.py)

```python
print(True and True)
print(True and False)
print(False and True)
print(False and False)

print(True or True)
print(True or False)
print(False or True)
print(False or False)

a = 100 > 50
b = 20 > 10
print(a and b)

c = 100 >= 100 and 50 == 10
print(c)
print(100 != 200 and 100 == 100)
```

실행 결과:

```
True
False
False
False
True
True
True
False
True
False
True
```

> **강의와 다른 점**: 학습 정리에서 강사님은 `and`, `or` 양쪽에 있는 값이 **반드시** 불린(`True`/`False`)이거나 불린으로 계산되는 식이어야 한다고 했어요. 처음 배울 때는 그렇게 쓰는 게 맞지만, 파이썬 문법이 그걸 강제하지는 않아요. 숫자를 넣어도 에러 없이 실행돼요. 예를 들어 `print(0 or 5)`는 `5`, `print(3 and 7)`은 `7`이 나와요(python3 3.14에서 확인). 이 동작은 나중에 조건문을 배울 때 다시 나오니, 지금은 "양쪽에 True/False가 나오는 식을 쓴다"로 연습하세요.

## 9. 연산자 우선순위

강사님 말로는 우선순위는 **괄호로 감싸면 무조건 거기가 제일 먼저**라는 것만 기억해도 부담이 크지 않아요.

슬라이드 표를 정리하면 이래요(위가 먼저 계산돼요).

| 순위 | 연산자 | 설명 |
|---|---|---|
| 1 | `( )` | 괄호로 감싼 식 |
| 2 | `**` | 거듭제곱 |
| 3 | `+x`, `-x` | 양수, 음수 부호 |
| 4 | `*`, `/`, `//`, `%` | 곱하기, 나누기, 몫, 나머지 |
| 5 | `+`, `-` | 더하기, 빼기 |
| 6 | `is`, `is not`, `<`, `<=`, `>`, `>=`, `!=`, `==` | 비교 |
| 7 | `not x` | 논리 not(참/거짓 뒤집기) |
| 8 | `and` | 논리 and |
| 9 | `or` | 논리 or |

- 3위 음수 부호 예: `x = 5`일 때 `y = -x`면 `y`는 `-5`예요.
- 곱하기·나누기가 더하기·빼기보다 먼저인 건 수학과 같아요.
- `not`은 참과 거짓을 뒤집어요. `not True`는 `False`예요.

> 강사님이 특별히 기억하라고 한 것: **`and`가 `or`보다 먼저**예요. `True and True or False`는 `True and True`가 먼저 `True`가 되고, 그다음 `True or False`가 돼서 `True`예요. 나머지 순위는 쓰다 보면 자연스럽게 익혀진다고 해요.

> **강의와 다른 점**: 슬라이드 6위 칸에 `=`가 들어 있는데 `==`의 오타예요. `=`는 대입이라 식 안에 쓰면 `print(1 = 1)`처럼 `SyntaxError`가 나요(python3 3.14에서 확인, 에러 문구가 "perhaps you meant "=="?"라고 알려 줘요). 또 6위 설명이 "멤버십과 균등 테스트"인데, 멤버십 검사는 나중에 배울 `in`, `not in`이고 이 표에는 빠져 있어요. 그리고 강의 말로 2위 `**`를 "제곱근"이라고 했는데, `**`는 **거듭제곱**(지수)이에요. 제곱근은 반대로 "어떤 수를 제곱하면 이 값이 되는가"를 구하는 거예요.

> **참고(강의 밖 내용)**: `**`가 부호보다 먼저라서 `-2 ** 2`는 `(-2) ** 2 = 4`가 아니라 `-(2 ** 2) = -4`예요(python3 3.14에서 확인). 음수를 거듭제곱하려면 괄호를 쳐요.

### 예제 (code/precedence.py)

```python
print(2 + 3 * 4)
print((2 + 3) * 4)

x = 5
y = -x
print(y)

print(True and True or False)
print(False or True and False)     # False or (True and False)
print((False or True) and False)
```

실행 결과:

```
14
20
-5
True
False
False
```

## 11. 첫 번째 프로젝트: BMI 계산기

이번 강의에서 첫 번째 프로젝트가 나왔어요. **신체질량지수(BMI, Body Mass Index)** 로 비만도를 계산하는 프로그램이에요.

슬라이드 내용이에요.

- 비만 판정의 올바른 지표는 체지방량이지만 직접 재기 어려워서, 표준체중이나 BMI처럼 간접적으로 재는 방법을 많이 써요. BMI는 헬스장의 체지방 분석 같은 데서도 많이 쓰는 공식이라고 강사님이 설명해요.
- 계산식: **BMI = 체중(kg) ÷ 신장(m)의 제곱**
- 슬라이드의 판정 기준: 저체중 20 미만, 정상 20 - 24, 과체중 25 - 29, 비만 30 이상

요구사항(슬라이드 "요구사항 (2/2)"):

1. 사용자에게 **정수형** 변수 몸무게와 키를 입력받아요.
2. 입력받을 때 보여 주는 메시지는 마음대로 정해도 돼요.
3. 몸무게 변수 이름은 `myWeight`, 키 변수 이름은 `myHeight`로 해요.
4. 몸무게는 kg 단위(예: 85), 키는 m 단위(예: 1.75)로 입력받아요.
5. BMI 계산식을 적용해서 자신의 BMI 수치를 출력해요.

제출 방법은 강의에서 따로 공지한다고만 했어요.

> **강의와 다른 점**: 요구사항 1번은 "정수형"으로 받으라고 하고, 4번은 키를 m 단위(1.75처럼)로 받으라고 해서 서로 맞지 않아요. `int(input())`으로 받으면 `1.75`를 넣었을 때 `ValueError: invalid literal for int() with base 10: '1.75'` 에러가 나요(python3 3.14에서 `int('1.75')`로 확인). 키를 m 단위로 받으려면 `float()`로 실수로 바꿔야 해요. 정수로 꼭 받고 싶다면 키를 cm(예: 175)로 받고 계산할 때 100으로 나누는 방법도 있어요. 과제를 낼 때는 공지된 기준을 꼭 확인하세요.

입력을 받는 모양은 이렇게 돼요(이 파일은 입력을 기다리니 code 폴더에는 값을 미리 넣은 판만 넣었어요).

```python
myWeight = int(input("몸무게(kg): "))
myHeight = float(input("키(m): "))
```

### 예제 (code/bmi_example.py)

계산식만 확인하려고 값을 미리 넣은 판이에요. `**`가 `/`보다 먼저라서 괄호 없이 `myHeight ** 2`부터 계산돼요.

```python
myWeight = 85
myHeight = 1.75
bmi = myWeight / myHeight ** 2
print(bmi)
```

실행 결과:

```
27.755102040816325
```

> **참고(강의 밖 내용)**: 변수 이름 `myWeight`처럼 단어 첫 글자를 대문자로 잇는 방식은 과제 요구사항에 맞춘 거예요. 파이썬에서는 보통 `my_weight`처럼 밑줄로 잇는 이름을 더 많이 써요.

## 자주 하는 실수

### 1) 같다를 `=` 하나로 씀

```python
print(1 = 1)    # SyntaxError
print(1 == 1)   # True
```

`=`는 대입, `==`는 같다예요.

### 2) `/` 결과가 정수일 거라고 생각함

```python
print(10 / 5)    # 2.0  (나눠 떨어져도 실수)
print(10 // 5)   # 2
```

### 3) `//`와 `%`를 헷갈림

```python
print(10 // 4)   # 2  몫
print(10 % 4)    # 2  나머지
print(10 // 3)   # 3  몫
print(10 % 3)    # 1  나머지
```

### 4) 0으로 나눔

```python
print(10 / 0)    # ZeroDivisionError: division by zero
```

### 5) `True`, `False`를 소문자로 씀

```python
print(true)      # NameError: name 'true' is not defined. Did you mean: 'True'?
print(True)      # True
```

### 6) `not is`라고 씀, 값 비교에 `is`를 씀

```python
print(x not is y)   # SyntaxError
print(x is not y)   # 맞는 순서
print(x == y)       # 값이 같은지는 == 로 봐요
```

### 7) `and`와 `or`가 섞였을 때 왼쪽부터 계산한다고 생각함

```python
print(False or True and False)     # False  (and 가 먼저)
print((False or True) and False)   # False
print(True or False and False)     # True   (True or (False and False))
```

헷갈리면 괄호를 치세요.

### 8) `x++`처럼 씀

```python
x++       # SyntaxError
x += 1    # 파이썬에서는 이렇게
```
