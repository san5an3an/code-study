# 08. 문자열

## 이 강의에서 배우는 것

- 문자열이 무엇이고, 따옴표로 어떻게 만드는지
- 문자열끼리 더하기(이어 붙이기)와 문자열에 정수 곱하기(반복하기), 그리고 안 되는 연산
- `input()`으로 받은 값이 문자열이라서 생기는 함정
- 이스케이프 문자: `\"`, `\'`, `\n`, `\t`, `\\`
- 이스케이프 문자 없이 따옴표를 넣는 방법(따옴표 쌍 바꾸기)

> 복습: 지난 강의까지 숫자 변수와 연산자를 배웠어요. 이번엔 글자를 담는 변수인 문자열을 배워요. 강사님 말대로 앞으로 어떤 프로그램을 짜든 계속 쓰는 중요한 자료형이라, 문자열 단원은 세 강의(08~10강)에 걸쳐 이어져요.

## 1. 문자열이란

**문자열**은 문장을 담는 변수예요. 문장은 글자(문자)가 줄지어 모인 거라서 "문자들이 열을 이뤘다", 즉 문자열이라고 불러요. 강사님 정리로는 "문장 변수"예요.

### 만드는 법

문장을 **쌍따옴표(`"`)** 나 **홑따옴표(`'`)** 의 쌍으로 감싸면 돼요.

```python
msg1 = "Life is too short"   # 쌍따옴표로 시작하면 쌍따옴표로 끝내요
msg2 = 'You need Python'     # 홑따옴표로 시작하면 홑따옴표로 끝내요
```

- 따옴표 안에는 무엇이 들어가든 전부 문자열이에요. `"100"`처럼 숫자를 감싸도 숫자가 아니라 글자 `1`, `0`, `0`이에요.
- 시작과 끝 따옴표는 **같은 종류**여야 해요.

### 예제 (code/string_basics.py)

```python
msg1 = "Life is too short"
msg2 = 'You need Python'
print(msg1)
print(msg2)

num_text = "100"
print(num_text)
```

실행 결과:

```
Life is too short
You need Python
100
```

### 따옴표를 섞으면 에러

```python
msg3 = "Python Study'
```

```
SyntaxError: unterminated string literal (detected at line 1)
```

"종료되지 않은 문자열 리터럴"이라는 뜻이에요. 쌍따옴표로 열었으니 파이썬은 쌍따옴표가 다시 나올 때까지를 문자열로 보는데, 끝까지 안 나오니까 "문자열이 안 끝났다"고 알려 주는 거예요. (리터럴은 코드에 직접 적은 값이라는 뜻이에요.)

강사님 조언: 에러 문구가 나오면 그냥 지나치지 말고 무슨 뜻인지 꼭 찾아보세요. 번역기를 돌려 봐도 좋아요. 그게 쌓이면 실력이 돼요.

## 2. 문자열의 연산

문자열도 계산을 할 수는 있지만 숫자처럼 자유롭지는 않아요. 되는 건 딱 두 가지예요.

| 연산 | 뜻 | 예 | 결과 |
|---|---|---|---|
| 문자열 `+` 문자열 | 이어 붙이기 | `"Hello" + "Python"` | `HelloPython` |
| 문자열 `*` 정수 | 그 수만큼 반복 | `"Hello" * 3` | `HelloHelloHello` |

뺄셈, 나눗셈, 거듭제곱 같은 건 전부 안 돼요. 문장을 빼거나 나눈다는 게 말이 안 되니까요.

### 안 되는 것 두 가지

**문자열 + 숫자**는 에러예요.

```python
print("Hello" + 100)
```

```
TypeError: can only concatenate str (not "int") to str
```

"문자열(str)에는 문자열만 이어 붙일 수 있다(int는 안 됨)"는 뜻이에요.

> 강사님이 짚은 부분: 자바를 배운 사람이 많이 헷갈려해요. 자바는 `"Hello" + 100`을 쓰면 100을 알아서 글자로 바꿔 `Hello100`을 만들어 주는데, 파이썬은 서로 다른 자료형끼리 더하는 걸 허용하지 않고 에러를 내요.

**문자열 × 문자열**도 에러예요.

```python
msg = "Hello" * "World"
```

```
TypeError: can't multiply sequence by non-int of type 'str'
```

"정수가 아닌 것(str)과는 곱할 수 없다"는 뜻이에요. 곱하는 쪽은 꼭 정수여야 해요.

### 예제 (code/string_operations.py 앞부분)

```python
msg1 = "Life is too short"
msg2 = "You need Python"
print(msg1 + ", " + msg2)   # 쉼표와 띄어쓰기도 문자열이라 같이 이어 붙여요

name = "Python"
print(name * 5)             # Python을 5번 반복
```

실행 결과:

```
Life is too short, You need Python
PythonPythonPythonPythonPython
```

## 3. 따옴표로 감싼 숫자는 문자열이에요 (input 함정)

```python
pay = "20000"
bonus = "100"
print(pay + bonus)
```

실행 결과:

```
20000100
```

20100이 아니라 `20000100`이에요. 둘 다 문자열이라 더하기가 **숫자 덧셈이 아니라 이어 붙이기**가 됐어요.

강사님은 이걸 송금 예로 설명해요. `input()`으로 송금할 금액을 두 번 받아 더했는데(20000, 100), `input()`으로 받은 값은 **무조건 문자열**이라서 20100원이 아니라 이천만 백 원이 되어 버리는 거예요.

> **강의와 다른 점**: 강의 말로는 "200100"이라고 했지만, 실제로 `"20000" + "100"`은 `20000100`이에요(화면의 실행 결과도 20000100). 말하다 숫자를 줄여 읽은 거예요.

해결 방법은 앞 강의에서 배운 `int()`로 정수로 바꾼 뒤 더하는 거예요.

```python
print(int(pay) + int(bonus))   # 20100
```

`input()`과 함께 쓸 때는 보통 이렇게 써요.

```python
money = int(input("송금할 금액: "))
```

## 4. print로 여러 값 이어서 출력하기

```python
m1 = "Hello"
m2 = "World"
print(m1 + m2)   # HelloWorld  (사이에 공백 없음)
print(m1, m2)    # Hello World (쉼표로 넘기면 사이에 공백 하나)
```

- `+`로 붙이면 그대로 딱 붙어요.
- `print`에 쉼표(`,`)로 값을 여러 개 넘기면, `print`가 **사이에 공백 하나를 넣어서** 출력해요.

> **강의와 다른 점**: 강의 화면(05:30쯤)에는 `print(m1 m2)`처럼 쉼표 없이 띄어 쓰면 붙여서 출력한다고 적혀 있는데, 파이썬 3에서는 에러예요.
> ```
> SyntaxError: invalid syntax. Perhaps you forgot a comma?
> ```
> 따옴표 문자열을 **직접** 나란히 쓴 `print("Hello" "World")`는 `HelloWorld`가 되지만, 이건 변수가 아니라 코드에 적은 문자열끼리만 되는 특별한 규칙이에요. 변수를 붙이고 싶으면 `+`를 쓰세요.

### 예제 (code/string_operations.py 뒷부분)

실행 결과:

```
20000100
20100
Hello World
HelloWorld
```

## 5. 이스케이프 문자

### 왜 필요한가

쌍따옴표로 감싼 문자열 안에 쌍따옴표를 넣고 싶을 때가 있어요. `Hello "Python" World`를 출력하려고 이렇게 쓰면

```python
print("Hello "Python" World")
```

파이썬은 두 번째 쌍따옴표에서 문자열이 끝났다고 보고, 뒤에 오는 `Python`을 이해하지 못해 에러를 내요.

```
SyntaxError: invalid syntax. Is this intended to be part of the string?
```

`syntax`는 "문법"이에요. 문법이 올바르지 않다는 뜻이에요.

### 해결: 따옴표 앞에 역슬래시

```python
print("Hello \"Python\" World")   # Hello "Python" World
```

역슬래시(`\`)와 따옴표가 합쳐져서 **특수문자 한 글자**가 돼요. 그래서 문자열을 끝내지 않고 따옴표 자체로 출력돼요.

### 이스케이프 문자란

- 우리말로 **확장 문자**라고도 해요. 쉽게 말해 **문자열 안에 넣는 특수문자**예요.
- 원래는 터미널이나 프린터처럼 출력하는 기기에게 "여기서 줄 바꿔", "여기서 탭만큼 띄워" 같은 동작을 시키려고 만든 거예요.
- **역슬래시 + 글자 하나 = 한 글자**예요. 두 글자처럼 보여도 한 글자라는 점을 조심하세요.

| 쓰는 법 | 뜻 |
|---|---|
| `\n` | 줄바꿈(엔터 친 것처럼). 개행 문자라고도 해요 |
| `\t` | 탭 |
| `\"` | 쌍따옴표 |
| `\'` | 홑따옴표 |
| `\\` | 역슬래시 자체 |

> **강의와 다른 점**: 강의에서 `\t`를 "띄어쓰기 4개"라고 했는데, 정확히는 공백 여러 개가 아니라 **탭 한 글자**예요. 화면에서는 다음 탭 칸까지 띄워져서, 프로그램에 따라 4칸이나 8칸 너비로 보이고 앞 글자 길이에 따라 띄워지는 칸 수도 달라져요.

### 역슬래시 모양이 글꼴마다 달라요

키보드 엔터키 옆의 `₩`(원 표시) 키가 역슬래시예요. 한글 글꼴(굴림 등)에서는 `₩`로, 영문 글꼴에서는 `\`로 보여요. **같은 글자**고 이름도 "원"이 아니라 **역슬래시**라고 읽어요. 물음표 키에 있는 `/`(슬래시)와는 방향이 반대예요.

### 예제 (code/escape_chars.py)

```python
print("Life is \"too\" short")                 # 쌍따옴표
print('Life is \'too\' short')                 # 홑따옴표
print("Life is too short\nYou need Python")    # 줄바꿈
print("Life is too short\tYou need Python")    # 탭
print("Life is too short\\You need Python")    # 역슬래시 자체
```

실행 결과(탭은 칸 너비만큼 띄워져 보여요):

```
Life is "too" short
Life is 'too' short
Life is too short
You need Python
Life is too short	You need Python
Life is too short\You need Python
```

### 역슬래시를 하나만 쓰면?

`"C:\python"`처럼 `\p` 같은, 정해져 있지 않은 이스케이프 문자를 쓰면 다른 언어들은 대개 에러를 내요. 파이썬은 알아서 역슬래시를 그대로 출력해 줘요.

> **강의와 다른 점**: 강의에서는 파이썬이 아무 말 없이 알아서 처리한다고 했는데, 파이썬 3.12부터는 경고가 같이 떠요(3.14에서 확인).
> ```
> SyntaxWarning: "\p" is an invalid escape sequence. Such sequences will not work in the future. Did you mean "\\p"?
> ```
> "앞으로는 안 될 거다"라는 뜻이라, 강사님 말대로 역슬래시 자체를 쓸 때는 **항상 `\\` 두 개**로 쓰는 습관을 들이세요. 강사님도 "여러분은 파이썬만으로 끝나지 않을 거다, 다른 언어를 대비해서 두 개 쓰는 습관을 갖추라"고 강조해요.

### 이름은 크게 신경 쓰지 않아도 돼요

다음 강의들에서 **형식 문자**(`%d` 같은 것)와 `format()`에서 쓰는 **치환 문자**(`{ }`)도 배워요. 강사님 생각으로는 이 셋 모두 결국 "특수문자를 표현하는 것"이라, 이름이 헷갈리면 그냥 "특수문자"로 기억해도 괜찮아요. 중요한 건 이름이 아니라 `\n`은 줄바꿈, `\t`는 탭, `\"` `\'`는 따옴표, `\\`는 역슬래시라는 **기능**이에요.

## 6. 이스케이프 문자 없이 따옴표 넣기 (따옴표 쌍 바꾸기)

강사님이 "일종의 꼼수"라고 소개한 방법이에요. 바깥 따옴표와 **다른 종류**의 따옴표는 안에서 그냥 써도 돼요.

### 예제 (code/quote_pairs.py)

```python
print("Life is 'too' short")   # 바깥이 쌍따옴표면 안에서 홑따옴표를 마음껏
print('Life is "too" short')   # 바깥이 홑따옴표면 안에서 쌍따옴표를 마음껏
```

실행 결과:

```
Life is 'too' short
Life is "too" short
```

## 자주 하는 실수

### 1) 시작과 끝 따옴표가 다름

```python
msg = "Hello'   # SyntaxError: unterminated string literal
```

열었던 따옴표와 같은 따옴표로 닫아요.

### 2) 문자열과 숫자를 더함

```python
age = 20
print("나이: " + age)        # TypeError
print("나이: " + str(age))   # 나이: 20  (str()로 글자로 바꿔서 더해요)
print("나이:", age)          # 나이: 20  (쉼표로 넘기면 바꾸지 않아도 돼요)
```

### 3) input으로 받은 숫자를 그대로 더함

```python
a = input()   # 20000 입력
b = input()   # 100 입력
print(a + b)            # 20000100
print(int(a) + int(b))  # 20100
```

### 4) 문자열 안 따옴표를 그대로 넣음

```python
print("Hello "Python" World")     # SyntaxError
print("Hello \"Python\" World")   # 역슬래시를 붙이거나
print('Hello "Python" World')     # 바깥 따옴표를 바꿔요
```

### 5) 역슬래시를 하나만 씀

```python
print("C:\python")    # 출력은 되지만 SyntaxWarning
print("C:\\python")   # C:\python
```

### 6) 쉼표 없이 변수 두 개를 print에 넘김

```python
print(m1 m2)    # SyntaxError
print(m1, m2)   # Hello World
print(m1 + m2)  # HelloWorld
```

| 용어 | 쉬운 뜻 |
|---|---|
| 문자열(str) | 글자들을 따옴표로 감싼 값. 문장을 담는 변수 |
| 리터럴 | 코드에 직접 적은 값. 예: `"Hello"`, `100` |
| 연결 | 문자열을 `+`로 이어 붙이는 것 |
| 이스케이프 문자 | 역슬래시와 글자 하나를 합친 특수문자 한 글자. 확장 문자라고도 함 |
| 개행 문자 | 줄을 바꾸는 특수문자 `\n` |
| 역슬래시 | `\` 글자. 한글 글꼴에서는 `₩`로 보임 |
| SyntaxError | 문법 에러. 코드를 실행하기 전에 문법이 틀려서 나는 에러 |
| TypeError | 자료형 에러. 그 자료형끼리는 할 수 없는 연산을 했을 때 나는 에러 |
| SyntaxWarning | 문법 경고. 실행은 되지만 고치는 게 좋다는 알림 |
