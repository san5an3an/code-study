# 16. 조건문

## 이 강의에서 배우는 것

- 조건문이 무엇이고, 지금까지의 코드와 무엇이 다른지
- `if`문의 모양: 조건식, 콜론(`:`), 들여쓰기로 만드는 블록
- 조건식에 올 수 있는 여러 가지 값: 논리값, 숫자, 비교식, 논리식, 문자열, 리스트·튜플·딕셔너리
- 조건식에서 쓰는 또 다른 연산자: `in`, `not in`, `is`, `is not`
- 들여쓰기 때문에 나는 에러 두 가지(`IndentationError`, `TabError`)
- `if ~ else`문: "그렇지 않으면"
- `if ~ elif ~ else`문: 여러 경우 중 **가장 처음 만나는 참인 조건**만 실행

> 복습: 지금까지 짠 코드는 위에서 아래로 한 줄씩 **전부** 실행됐어요. 강사님 말로는 "계산기랑 큰 차이가 없다"고 해요. 이번 강의부터는 조건에 따라 **실행할지 말지**를 고를 수 있어요. 7강에서 배운 비교 연산자(`==`, `!=`, `>` ...)와 논리 연산자(`and`, `or`, `not`)가 여기서 본격적으로 쓰여요.

> 입력에 대해: 강의 실습은 `input()`으로 점수, 나이, Y/N을 받아요. 이 노트의 code 파일은 실행할 때마다 같은 결과가 나오도록 값을 직접 넣었어요. 강의처럼 해 보려면 `score = 72`를 `score = int(input("점수를 입력하세요"))`로 바꾸면 돼요.

## 1. 조건문이란

**조건문**은 무조건 실행되는 게 아니라, **특정 조건을 충족할 때만** 실행되는 구문이에요.

| 종류 | 설명 |
|---|---|
| `if`문 | 주어진 조건이 참(True)일 때만 실행돼요 |
| `if ~ else`문 | 조건이 참이면 `if` 쪽이, 거짓(False)이면 `else` 쪽이 실행돼요 |
| `if ~ elif ~ else`문 | 조건을 여러 개로 잘게 나눠서 쓰는 `if`문이에요 |

강사님 말로는 보통 이 세 가지를 모두 묶어서 그냥 "if문"이라고 불러요.

> **강의와 다른 점**: 강의 슬라이드에는 "다른 프로그래밍 언어에서 제공하는 switch문은 없습니다"라고 적혀 있어요. `switch`라는 이름의 문법은 지금도 없지만, 지금 쓰는 파이썬 3.14에는 비슷한 일을 하는 **`match`문**이 있어요(아래 코드를 python3 3.14로 실행해서 확인).
> ```python
> day = 3
> match day:
>     case 1:
>         print("월요일")
>     case 2:
>         print("화요일")
>     case 3:
>         print("수요일")
>     case _:
>         print("그 밖의 날")
> ```
> 실행 결과는 `수요일`이에요. `case _:`는 "앞의 어느 것에도 안 맞으면"이라서 `else`와 비슷해요. 지금은 `if ~ elif ~ else`만 잘 익혀도 충분해요.

## 2. if문의 구조와 블록

```python
if 조건식:
    ... 실행할 구문 ...
    ... 실행할 구문 ...
```

- `if` 뒤에 **조건식**을 써요.
- 그 뒤에 **콜론(`:`)** 을 찍어서 "밑에 딸린 **블록**이 있어요"라고 알려요.
- 블록에 들어가는 실행문은 `if`보다 **들여쓰기를 더 깊게** 해야 해요. 몇 줄이 들어가든 상관없지만 **모두 같은 깊이**여야 해요.

**블록**은 이번 강의에서 처음 나온 개념이에요. 같은 깊이로 들여쓴 줄들의 묶음이고, 파이썬은 들여쓰기로 "여기까지가 if에 속한 부분"을 알아봐요. 그래서 강사님은 "파이썬은 맨 앞에 들여쓰기를 함부로 하면 안 된다"고 강조해요.

### 예제 (code/if_basics.py 앞부분)

```python
a = 100
if a >= 100:
    print("a는 100보다 크거나 같습니다.")
    print("그러므로 이 부분은 출력됩니다.")

a = 5
if a >= 100:
    print("a는 100보다 크거나 같습니다.")
    print("그러므로 이 부분은 출력됩니다.")
```

`a`가 100일 때는 `100 >= 100`이 참이라 두 줄이 모두 실행되고, `a`가 5일 때는 거짓이라 두 줄 모두 건너뛰어요.

### 한 줄로 쓰기

블록에 실행문이 한 줄뿐이면 줄을 바꾸지 않고 `if 조건식: 실행할 구문`처럼 한 줄에 써도 돼요.

```python
if True: print("한 줄")
```

강사님은 모양이 여러 가지가 되면 오히려 읽기 어려워진다고 이 방법을 **추천하지 않아요**. 항상 줄을 바꿔서 들여쓰는 습관을 들이세요.

### 예제 (code/if_basics.py 뒷부분: 시험 합격)

```python
print("시험시작")
score = 72
if score >= 60:
    print("합격입니다.")
print("시험 끝")
```

"시험시작"과 "시험 끝"은 if 밖에 있어서 무조건 출력되고, "합격입니다."는 60점 이상일 때만 나와요. 파일에서는 72점과 50점 두 경우를 이어서 실행해요.

실행 결과(code/if_basics.py 전체):

```
a는 100보다 크거나 같습니다.
그러므로 이 부분은 출력됩니다.
시험시작
합격입니다.
시험 끝
시험시작
시험 끝
```

> **참고(강의 밖 내용)**: 강사님은 주피터에서 "코드가 끝까지 종료되지 않으면 출력되는 내용은 없다"고 했는데, 이건 VS Code 주피터 화면에서 보이는 모습이에요. 터미널에서 `python3`로 실행하면 `시험시작`이 먼저 나오고 그다음 입력을 기다려요. 72를 넣어 실행해 보면 이렇게 나와요(입력한 72 자체는 키보드로 친 것이라 화면에만 보여요).
> ```
> 시험시작
> 점수를 입력하세요합격입니다.
> 시험 끝
> ```
> `input("점수를 입력하세요")`의 안내 문구 뒤에 줄바꿈이 없어서 결과가 붙어 보여요. `"점수를 입력하세요: "`처럼 끝에 공백을 넣으면 보기 좋아요.

## 3. if문에 쓰는 조건식의 여러 형태

조건식에는 비교식만 오는 게 아니에요. 값 자체를 넣어도 파이썬이 참/거짓으로 판단해요. 강사님이 "많이 헷갈릴 수 있으니 잘 기억하라"고 한 표예요.

| 형식 | 참 | 거짓 |
|---|---|---|
| 논리값(Boolean) | `True` | `False` |
| 숫자형 | 0이 아닌 모든 값(1, -1도 참) | `0` |
| 비교식 | 식의 결과가 `True` | 식의 결과가 `False` |
| 논리식 | 식의 결과가 `True` | 식의 결과가 `False` |
| 문자열 | 빈 문자열이 아닌 경우 | 빈 문자열 `""` |
| 리스트 | 원소가 하나라도 있는 경우 | `[]` |
| 튜플 | 원소가 하나라도 있는 경우 | `()` |
| 딕셔너리 | 원소가 하나라도 있는 경우 | `{}` |

- **빈 문자열**은 따옴표를 열자마자 닫은 `""`예요. 띄어쓰기 한 칸만 있는 `" "`도 엄연한 글자라서 **참**이에요.

### 예제 (code/truthy_conditions.py)

```python
money = 10000
if money:
    print("택시를 타고")
print("집에가자")

name = "Python"
if name:
    print(name)
print("프로그래밍")

grade = [100, 80, 70]
if grade:
    msg = "국어: {0}, 영어: {1}, 수학: {2}"
    print(msg.format(grade[0], grade[1], grade[2]))
print("성적처리")
```

강의에서는 `# money = 0`처럼 주석을 바꿔 가며 두 경우를 비교했어요. 파일에서는 값을 바꿔 한 번씩 더 실행하고, 끝에 `bool()`로 참/거짓을 직접 찍어 봐요.

실행 결과:

```
택시를 타고
집에가자
집에가자
Python
프로그래밍
프로그래밍
국어: 100, 영어: 80, 수학: 70
성적처리
성적처리
True False
True False
False False False
```

- `money = 0`이면 "택시를 타고" 없이 "집에가자"만 나와요.
- `name = ""`이면 "프로그래밍"만 나와요.
- `grade = []`이면 "성적처리"만 나와요.

강사님 여담: `grade = [100, 80]`처럼 원소가 두 개뿐이면 리스트는 참이라 블록 안으로 들어가는데, `grade[2]`가 없어서 `IndexError: list index out of range`가 나요. 이 예제는 원소가 꼭 세 개라고 가정하고 만든 거예요.

## 4. 비교식과 논리식을 조건으로

### 예제 (code/comparison_logical_if.py)

```python
myage = 19

if myage == 19:
    print("19살 입니다.")

if myage != 20:
    print("20살이 아닙니다.")

if myage > 19:
    print("성인입니다.")

if myage <= 19:
    print("청소년입니다.")

point = 75

# AND --> 전체가 참이어야 결과가 참
if point > 70 and point <= 80:
    print("C학점 입니다.")

# OR --> 하나라도 참이면 전체가 참
if point <= 70 or point > 80:
    print("C학점이 아닙니다.")
```

실행 결과:

```
19살 입니다.
20살이 아닙니다.
청소년입니다.
C학점 입니다.
```

- `if`가 네 개 따로 있어서 **각각** 검사해요. 참인 것은 전부 출력돼요.
- 나이에 20을 넣으면 "성인입니다."만 나와요.
- 75점이면 `True and True`라서 "C학점 입니다.", `False or False`라서 "C학점이 아닙니다."는 안 나와요. 62점을 넣으면 반대로 "C학점이 아닙니다."만 나와요.

(자막에는 "시작점"이라고 잡혔지만 화면의 코드는 "C학점"이에요.)

## 5. 논리값을 조건으로

강사님 말로는 if문을 쓰다 보면 이 경우를 굉장히 많이 헷갈려 해요.

### 예제 (code/bool_conditions.py)

```python
isKorean = True

if isKorean == True:
    print("한국사람입니다...(1)")
if isKorean == False:
    print("한국사람이 아닙니다...(2)")
if isKorean != True:
    print("한국사람이 아닙니다...(3)")
if isKorean != False:
    print("한국사람입니다...(4)")
if isKorean:
    print("한국사람입니다...(5)")
if not isKorean:
    print("한국사람이 아닙니다...(6)")
```

실행 결과:

```
한국사람입니다...(1)
한국사람입니다...(4)
한국사람입니다...(5)
```

- `if isKorean:`은 "이 변수가 참이라면"이에요.
- `if not isKorean:`은 `not True`가 되어 거짓이에요. "이 변수가 거짓이라면"이라는 뜻이에요.
- `isKorean = False`로 바꾸면 (2), (3), (6)이 나와요(강의 화면에서 확인).

> **참고(강의 밖 내용)**: `if isKorean == True:`와 `if isKorean:`은 결과가 같아요. 파이썬에서는 보통 짧은 `if isKorean:`, `if not isKorean:` 모양을 더 많이 써요.

## 6. 조건식에서 쓰는 또 다른 연산자: in, not in, is, is not

| 연산자 | 설명 |
|---|---|
| `A in B` | A는 값, B는 리스트나 문자열 같은 것. A가 B에 들어 있으면 참 |
| `A not in B` | A가 B에 들어 있지 **않으면** 참 |
| `A is B` | A와 B가 같은 객체(같은 상자)면 참 |
| `A is not B` | A와 B가 같은 객체가 아니면 참 |

강사님 판서 예: `k = [1, 2, 3]`, `x = 2`일 때 `y = x in k`는 `True`, `y = x not in k`는 `False`예요.

### 예제 (code/in_conditions.py)

```python
user1 = "hello"
user2 = "world"
memberList = ['hello', 'python', 'life']

a = user1 in memberList
print(a)
b = user2 in memberList
print(b)

if user1 in memberList:
    print( user1 + "(은)는 이미 가입되어 있습니다." )
if user2 in memberList:
    print( user2 + "(은)는 이미 가입되어 있습니다." )
if user1 not in memberList:
    print( user1 + "(은)는 가입되어 있지 않습니다." )
if user2 not in memberList:
    print( user2 + "(은)는 가입되어 있지 않습니다." )

print("py" in "python")
```

실행 결과:

```
True
False
hello(은)는 이미 가입되어 있습니다.
world(은)는 가입되어 있지 않습니다.
True
```

강사님은 이걸 회원가입에 비유해요. 이미 가입된 아이디 목록에 `hello`로 새로 가입하려고 하면 중복이라는 걸 `in`으로 알아낼 수 있어요. 마지막 줄처럼 문자열에서도 글자 조각이 들어 있는지 볼 수 있어요.

> 강사님은 변수 이름을 `memberList`처럼 **카멜 표기법**(단어가 바뀔 때 대문자)으로 고쳐서 썼어요.
>
> **참고(강의 밖 내용)**: 파이썬 공식 스타일 안내(PEP 8)는 변수 이름에 `member_list`처럼 소문자와 밑줄을 쓰는 **스네이크 표기법**을 권해요. 어느 쪽이든 실행은 똑같이 돼요. 이 노트의 code 파일은 강의 화면과 맞추려고 강의 이름을 그대로 썼어요.

### is와 is not

### 예제 (code/is_conditions.py)

```python
a = 123
b = 123
c = 234
if a is b:
    print("a와 b는 같다")
if b is c:
    print("b와 c는 같다")

x = 1
y = 1.0
if x == y:
    print("1) x와 y는 같다")
if x is y:
    print("2) x와 y는 같다")

a = 123.0
b = 123
if a != b:
    print("1) a와 b는 다르다")
if a is not b:
    print("2) a와 b는 다르다")

p = [1, 2, 3]
q = [1, 2, 3]
print(p == q)
print(type(p) == type(q))
print(p is q)
```

실행 결과:

```
a와 b는 같다
1) x와 y는 같다
2) a와 b는 다르다
True
True
False
```

- `==`는 값만 비교해요. `1 == 1.0`은 `True`예요.
- `1`과 `1.0`은 `is`로 보면 `False`예요.
- `123.0 != 123`은 값이 같으니 거짓이라 1)은 안 나오고, `is not`은 참이라 2)만 나와요.

> **강의와 다른 점**: 강의(슬라이드와 노트북 설명)는 "`is`는 **데이터 타입까지** 비교한다"고 설명해요. 위 예제 1, 2, 3번째 결과는 그 설명과 맞아 보이지만, 정확한 뜻은 **"두 변수가 같은 객체(메모리 속 같은 값 하나)를 가리키는가"** 예요. 그래서 마지막 `p`와 `q`처럼 **자료형도 값도 같은데** `p is q`가 `False`일 수 있어요(python3 3.14로 실행해서 확인, 7강 노트에도 같은 내용이 있어요). `a = 123`, `b = 123`에서 `a is b`가 `True`인 것도 파이썬(CPython)이 같은 숫자 객체를 함께 쓰기 때문이지, 자료형이 같아서가 아니에요. 값이 같은지 볼 때는 `==`, 자료형까지 보고 싶으면 `type(a) == type(b)`를 쓰세요. `is`는 보통 `x is None`처럼 `None`을 확인할 때 써요.

> **강의와 다른 점**: 슬라이드 판서에 적힌 `1 is 1`처럼 숫자를 **직접** `is`로 비교하면, 파이썬 3.14에서 경고가 같이 떠요(`python3 -W default`로 확인).
> ```
> SyntaxWarning: "is" with 'int' literal. Did you mean "=="?
> ```
> "혹시 `==`를 쓰려던 거 아니냐"는 뜻이에요. 숫자나 문자열 값을 비교할 때는 `==`를 쓰세요.

> **강의와 다른 점**: 강의 화면의 `is not` 예제는 `print("2) b와 c는 다르다")`라고 적혀 있는데, 실제로 비교한 건 `a`와 `b`예요. code 파일에서는 `"2) a와 b는 다르다"`로 고쳐 적었어요.

## 7. if문 사용할 때 주의할 점: 들여쓰기

### (1) 들여쓰기 깊이가 서로 다르면 에러

```python
a = 100
if a >= 100:
  print("a는 100보다 크거나 같습니다.")      # 두 칸
    print("그러므로 이 부분은 출력됩니다.")   # 네 칸
```

```
IndentationError: unexpected indent
```

`indent`는 "들여쓰기"예요. "예상하지 못한 들여쓰기"라는 뜻이에요.

### (2) 스페이스와 탭을 섞으면 에러

겉으로는 깊이가 똑같아 보여도, 한 줄은 스페이스 4번, 다른 줄은 탭 1번으로 들여쓰면 에러예요. 직접 드래그해 보기 전에는 눈으로 구별이 안 돼요.

```
TabError: inconsistent use of tabs and spaces in indentation
```

"들여쓰기에 탭과 스페이스를 일관되지 않게 썼다"는 뜻이에요. **한 가지 종류로 일관되게** 써야 해요.

강사님 농담: "띄어쓰기 때문에 빈정 상하는 언어가 파이썬이다." 다행히 VS Code는 탭 키를 누르면 자동으로 스페이스 4개로 바꿔 넣어서, 이 상황은 강사님이 일부러 만든 거예요.

두 에러 모두 python3 3.14로 실행해서 같은 문구가 나오는 걸 확인했어요.

## 8. if ~ else문: 그렇지 않으면

강사님이 "이거 하나만 기억하면 된다"고 한 말: **else = 그렇지 않으면**.

```python
if 조건식:
    ... 실행할 구문 ...
else:
    ... 반대 경우에 실행할 구문 ...
```

- `if` 조건이 참이면 `if` 블록만 실행하고 `else`는 건너뛰어요.
- 거짓이면 `if` 블록을 건너뛰고 `else` 블록을 실행해요.
- `else`는 **혼자 쓸 수 없고**, 반드시 `if` 뒤에 와야 해요. 혼자 쓰면 `SyntaxError: invalid syntax`가 나요(3.14로 확인).
- `if`만 있으면 조건이 안 맞을 때 그냥 지나가지만, `else`를 붙이면 반대 경우까지 처리할 수 있어요.

### 예제 (code/else_basics.py)

```python
is_korean = False
if is_korean == True:
    print("한국사람입니다.")
else:
    print("한국사람이 아닙니다.")

print("시험시작")
score = 53
if score >= 60:
    print("합격입니다.")
else:
    print("불합격입니다.")
print("시험 끝")

answer = "y"
if answer.upper() == "Y":
    isKorean = True
else:
    isKorean = False

if isKorean:
    print("한국사람 입니다...(1)")
else:
    print("한국사람이 아닙니다...(2)")

if not isKorean:
    print("한국사람이 아닙니다...(3)")
else:
    print("한국사람 입니다...(4)")

user1 = "hello"
user2 = "world"
memberList = ['hello', 'python', 'life']
if user1 in memberList:
    print("%s는 이미 가입되어 있습니다." % user1)
else:
    print("%s는 가입되어 있지 않습니다." % user1)
if user2 in memberList:
    print("%s는 이미 가입되어 있습니다." % user2)
else:
    print("%s는 가입되어 있지 않습니다." % user2)
```

실행 결과:

```
한국사람이 아닙니다.
시험시작
불합격입니다.
시험 끝
한국사람 입니다...(1)
한국사람 입니다...(4)
hello는 이미 가입되어 있습니다.
world는 가입되어 있지 않습니다.
```

- 강의에서는 `input("한국인입니까? (Y/N)")`으로 받았어요. 사용자가 `y`나 `Y` 어느 쪽을 칠지 모르니, 둘 다 검사하는 대신 12강에서 배운 `upper()`로 **무조건 대문자로 바꾼 뒤** `"Y"` 하나만 비교해요. 강사님 말로는 이렇게 "일관되게 처리"하면 조건이 이중으로 들어가지 않아 편해요.
- `n`을 넣으면 (2)와 (3)이 나와요(강의 화면에서 확인).
- 회원 예제의 `%s`는 10강에서 배운 형식 문자예요. 강사님은 else 쪽 문장에 "이미"가 들어가면 어색하다고 빼서 "가입되어 있지 않습니다"로 고쳤어요.

## 9. if ~ elif ~ else문: 여러 경우의 수

```python
if 1차 조건식:
    ... 실행할 구문 ...
elif 2차 조건식:
    ... 실행할 구문 ...
elif 3차 조건식:
    ... 실행할 구문 ...
else:
    ... 반대 경우에 실행할 구문 ...
```

- `if`와 `else` 사이에 `elif`로 두 번째, 세 번째 조건을 나열해요. (`elif`는 else if를 줄인 말이에요. 자막에는 "lif"로 잡혔어요.)
- 파이썬은 위에서부터 순서대로 조건을 따지다가 **가장 처음 만나는 참인 조건**의 블록만 실행하고 나머지는 보지 않고 나가요. 강사님이 계속 강조한 부분이에요.
- 그 아래에 참인 조건이 또 있어도 무시해요.
- `elif`는 필요한 만큼 쓸 수 있고, 맨 끝 `else`는 필요 없으면 생략해도 돼요. `else`가 없는데 모든 조건이 거짓이면 아무것도 실행되지 않아요.

### 예제 (code/elif_grades.py)

```python
print("시험시작")

point = 72

if point > 90:
    print("A학점")
elif point > 80:
    print("B학점")
elif point > 70:
    print("C학점")
elif point > 60:
    print("D학점")
else:
    print("F학점")

print("시험 끝")
```

72점이면 `72 > 90` 거짓, `72 > 80` 거짓, `72 > 70` 참이라 "C학점"을 출력하고 끝나요. `72 > 60`도 참이지만 이미 앞에서 실행했으니 보지 않아요. 파일 뒷부분에는 90점과 30점(else 없음) 경우도 있어요.

실행 결과:

```
시험시작
C학점
시험 끝
B학점
else 가 없어서 위에서는 아무것도 안 나왔어요
```

> **참고(강의 밖 내용)**: 조건이 `point > 90`이라 **90점은 A가 아니라 B**예요(위 결과 4번째 줄). `>`는 "초과", `>=`는 "이상"이에요. 90점부터 A로 하고 싶으면 `point >= 90`처럼 써야 해요. 점수를 나눌 때는 경계값을 꼭 한 번씩 넣어 보세요.

> **참고(강의 밖 내용)**: 순서가 중요해요. `elif point > 60`을 맨 위에 두면 95점도 첫 조건에서 참이 되어 "D학점"이 나와 버려요. 범위가 좁은(큰 점수) 조건부터 위에 써요.

## 자주 하는 실수

### 1) 콜론을 빠뜨림

```python
if x > 3          # SyntaxError: expected ':'
    print(x)
```

### 2) 블록을 들여쓰지 않음

```python
if x > 3:
print(x)          # IndentationError: expected an indented block after 'if' statement on line 1
```

### 3) 블록 안 들여쓰기 깊이가 다름, 탭과 스페이스를 섞음

```python
if a >= 100:
  print("두 칸")
    print("네 칸")   # IndentationError: unexpected indent
```

에디터가 탭을 스페이스 4개로 바꿔 주게 두고, 한 블록은 같은 깊이로 맞춰요.

### 4) else를 혼자 씀

```python
else:                # SyntaxError: invalid syntax
    print("혼자")
```

`else`는 항상 `if`(또는 `elif`) 바로 뒤에 와요.

### 5) " "(공백 한 칸)을 빈 문자열로 착각함

```python
print(bool(" "))   # True
print(bool(""))    # False
```

### 6) 값 비교에 is를 씀

```python
x = 1
y = 1.0
print(x == y)   # True  (값 비교는 ==)
print(x is y)   # False (같은 객체인지 보는 것)
```

### 7) elif 순서를 거꾸로 씀

```python
point = 95
if point > 60:
    print("D학점")   # 95점인데 여기서 끝나요
elif point > 90:
    print("A학점")
```

넓은 조건이 위에 있으면 아래 조건까지 갈 일이 없어요. 좁은 조건부터 써요.
