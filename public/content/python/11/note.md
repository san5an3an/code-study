# 11. format 메서드를 활용한 문자열 포메팅

## 이 강의에서 배우는 것

- 문자열 객체가 갖고 있는 `format()` 메서드로 문자열 안의 빈자리를 값으로 채우는 방법
- 치환 문자 `{0}`, `{1}`처럼 **인덱스 번호**로 자리를 정하는 방법
- `{price}`, `{unit}`처럼 **이름**으로 자리를 정하는 방법, 그리고 둘을 섞어 쓰는 규칙
- `>`, `<`, `^`로 오른쪽·왼쪽·가운데 정렬하고, 빈칸을 원하는 글자로 채우는 방법
- 소수점 자리수, 전체 자릿수, 0 채우기를 함께 쓰는 방법
- 문자열 안에 중괄호 `{ }`를 그대로 넣는 방법(`{{ }}`)

> 복습: 지난 강의(10강)에서는 `%d`, `%s`, `%f` 같은 **형식 문자**로 문자열 포메팅을 했어요. 이번엔 같은 일을 `format()` 메서드로 해요. 강사님 말로는 다른 책에서는 이걸 "문자열의 고급 포메팅"이라고도 부를 만큼, 형식 문자보다 기능이 더 많아요.

---

## 1. 치환 문자와 format() 메서드

**치환 문자**는 문자열 안에 넣어 두는 "빈자리 표시"예요. 중괄호로 숫자를 감싸서 `{0}`, `{1}`처럼 써요. 나중에 `format()`에 넘긴 값이 이 자리에 들어가요.

형식 문자와 비교하면 이래요.

| | 형식 문자 (10강) | 치환 문자 (11강) |
|---|---|---|
| 모양 | `%d`, `%s`, `%f` | `{0}`, `{1}` |
| 자료형 | 정수냐 문자열이냐를 꼭 적어야 함 | 따지지 않음. 위치(인덱스)만 정함 |
| 값을 넣는 법 | `"..." % (값1, 값2)` | `"...".format(값1, 값2)` |

### 왜 `문자열.format()`일까

강사님이 6강에서 배운 내용을 다시 짚어요. 파이썬에서는 모든 변수가 **객체**이고, 객체는 안에 또 다른 변수와 함수를 품고 있는 특수한 변수예요. 객체 안에 들어 있는 함수를 **메서드**라고 해요. 그래서 문자열 변수를 만들면 `변수.format(...)`처럼 점을 찍고 메서드를 부를 수 있어요. 강사님 말로 "코딩하다가 다짜고짜 점이 나오면 왼쪽은 무조건 객체"예요.

- `format()`은 앞의 문자열에 치환 문자가 들어 있을 때 써요.
- `format()`에 넘긴 값들이 순서대로 **0번째, 1번째, 2번째...** 예요. 번호는 **항상 0부터** 시작해요.
- 넘기는 값의 **자료형은 구분하지 않아요**. 숫자든 문자열이든 그냥 넣어 줘요. 강사님이 꼽은 `format()`의 편한 점이에요.

### 예제 (code/index_formatting.py)

```python
text = "이 과자는 {0}{1}입니다."
print(text.format(2000, "원"))

msg1 = "I eat {0} apples"
print(msg1.format(3))

msg2 = "{0}은 {1}년 {2}월 {3}일 입니다."
print(msg2.format("개강일", 2023, 1, 26))

print("{1}, {0}, {1}".format("A", "B"))
```

실행 결과:

```
이 과자는 2000원입니다.
I eat 3 apples
개강일은 2023년 1월 26일 입니다.
B, A, B
```

- `2000`(숫자)과 `"원"`(문자열)을 섞어 넘겨도 아무 문제 없어요.
- 마지막 줄처럼 문자열 안에서 번호 순서를 바꾸거나 같은 번호를 두 번 써도 돼요.
- 넘긴 값보다 큰 번호를 쓰면 에러예요. `"{2}".format(1, 2)` → `IndexError: Replacement index 2 out of range for positional args tuple`

> **참고(강의 밖 내용)**: 슬라이드에서는 변수 이름을 `str`로 썼는데, `str`은 파이썬이 이미 쓰는 이름(문자열로 바꾸는 `str()` 함수)이에요. `str = "..."`라고 하면 그 뒤로 `str(3)`이 `TypeError: 'str' object is not callable`로 망가져요. 그래서 이 노트의 코드는 `text`라는 이름으로 바꿨어요.

## 2. 인덱스 번호 대신 이름 쓰기

`{0}` 대신 `{price}`, `{unit}`처럼 **이름**을 쓸 수도 있어요. 강사님 말로 "좀 더 직관적"이에요.

- 이름은 **변수 이름 규칙**만 지키면 무엇이든 돼요.
- `format()`에는 `이름=값, 이름=값` 형식으로 넘겨요.
- 중요한 건 **순서를 상관하지 않는다**는 거예요. 인덱스 번호는 순서를 꼭 지켜야 하지만, 이름은 이름으로 찾아가니까 순서가 아무래도 돼요.

### 예제 (code/name_formatting.py)

```python
text = "이 과자는 {price}{unit}입니다."
print(text.format(unit="원", price=2000))

msg3 = "{name}은 {yy}년 {mm}월 {dd}일 입니다."
print(msg3.format(mm=10, name="종강일", dd=20, yy=2023))
print(msg3.format(name="종강일", yy=2023, mm=10, dd=20))
```

실행 결과:

```
이 과자는 2000원입니다.
종강일은 2023년 10월 20일 입니다.
종강일은 2023년 10월 20일 입니다.
```

`unit`을 먼저 넘겼는데도 `{price}` 자리에 2000이 정확히 들어갔어요. 아래 두 줄도 넘기는 순서만 다르고 결과는 같아요.

## 3. 숫자 형식과 이름 형식 섞어 쓰기

둘을 같이 쓸 수도 있는데, 규칙이 하나 있어요. **`format()` 안에서 이름 없는 값(인덱스용)을 먼저 쓰고, 이름=값은 뒤에** 써야 해요.

강사님이 알려 준 방법:

1. 일단 `format()`에 넘길 값을 이름 없이 쭉 나열해요. 0번째, 1번째, 2번째...라고 생각해요.
2. **맨 뒤 값부터** 원하는 만큼 이름을 붙여요.
3. 문자열 안의 치환 문자를 그 이름으로 바꿔요.

여기서 말하는 "순서"는 `format()`에 넘기는 값의 순서만 뜻해요. **문자열 안**에서는 `{1}`, `{0}`, `{name}`이 어떤 순서로 섞여도 괜찮아요.

### 예제 (code/mixed_formatting.py)

```python
text = "이 {0}(은)는 {1} {name}입니다."
print(text.format("책", "좋은", name="교과서"))

print("{1} {0}은 {name}입니다.".format("책", "좋은", name="교과서"))
print("{name}는 {1} {0}입니다.".format("책", "좋은", name="교과서"))

msg4 = "{0}은 {yy}년 {mm}월 {dd}일 입니다."
print(msg4.format("생일", yy=2023, mm=1, dd=31))
```

실행 결과:

```
이 책(은)는 좋은 교과서입니다.
좋은 책은 교과서입니다.
교과서는 좋은 책입니다.
생일은 2023년 1월 31일 입니다.
```

### 이름=값을 먼저 쓰면 에러

```python
print(text.format(name="교과서", "책", "좋은"))
```

```
SyntaxError: positional argument follows keyword argument
```

"이름 없는 값(positional argument)이 이름=값(keyword argument) 뒤에 왔다"는 뜻이에요. 문법 에러라서 실행하기 전에 바로 멈춰요.

> 강사님 조언: 이렇게 섞는 방식은 헷갈려서 강사님도 실제로는 잘 안 써요. 인덱스 번호로만 가든지, 이름으로만 가든지 **하나로 통일**하는 걸 권해요. 그래도 알아는 둬야 해요.

## 4. 출력값 정렬하기

치환 문자 안 숫자 뒤에 **콜론(`:`)** 을 찍고, 정렬 기호와 **전체 자릿수**를 써요. 10강의 `%10s` 같은 것과 같은 거예요.

| 쓰는 법 | 뜻 | 10강과 비교 |
|---|---|---|
| `{0:>10}` | 전체 10칸, 오른쪽 정렬 | `%10s`와 같음 |
| `{0:<10}` | 전체 10칸, 왼쪽 정렬 | `%-10s`와 같음 |
| `{0:^10}` | 전체 10칸, 가운데 정렬 | 형식 문자엔 없음 |

괄호 모양이 가리키는 쪽으로 붙는다고 기억하면 쉬워요. `^`는 키보드에서 **Shift + 숫자 6**으로 쳐요.

### 예제 (code/align_formatting.py)

```python
print("이 {0:>10}(은)는 {1:>10}원 입니다.".format("사과", 1200))
print("이 {0:<10}(은)는 {1:<10}원 입니다.".format("사과", 1200))
print("이 {0:^10}(은)는 {1:^10}원 입니다.".format("사과", 1200))

msg5 = "[{0:>5}]!!Python, [{1:>9}]~Python"
print(msg5.format("Hi", "Welcome"))

msg6 = "[{0:<5}]!!Python, [{1:<9}]~Python"
print(msg6.format("Hi", "Welcome"))

msg7 = "[{0:^10}]!!Python, [{1:^9}]~Python"
print(msg7.format("Hi", "Hello"))

print("[{0:5}] [{1:5}]".format("ab", 12))
```

실행 결과:

```
이         사과(은)는       1200원 입니다.
이 사과        (은)는 1200      원 입니다.
이     사과    (은)는    1200   원 입니다.
[   Hi]!!Python, [  Welcome]~Python
[Hi   ]!!Python, [Welcome  ]~Python
[    Hi    ]!!Python, [  Hello  ]~Python
[ab   ] [   12]
```

- 강사님은 실습에서 치환 문자를 **대괄호 `[ ]`로 감싸서** 자리가 어디까지인지 눈으로 보여 줬어요. 공백이 몇 칸인지 헷갈릴 때 따라 해 보면 좋아요.
- 가운데 정렬은 남는 칸을 양쪽에 나눠요. `Hi`(2글자)를 10칸에 넣으면 남는 8칸이 4칸씩 나뉘어요.
- 마지막 줄: 정렬 기호를 안 쓰면 **문자열은 왼쪽, 숫자는 오른쪽**으로 정렬돼요.

> **참고(강의 밖 내용)**: 남는 칸이 홀수면 가운데 정렬은 오른쪽에 한 칸을 더 둬요. `"[{:^10}]".format("abc")` → `[   abc    ]` (왼쪽 3칸, 오른쪽 4칸).

> **참고(강의 밖 내용)**: 자릿수는 **글자 수**로 세요. `"사과"`는 2글자라서 10칸에 넣으면 공백 8개가 붙어요. 그런데 한글은 화면에서 영문보다 폭이 넓게 보여서, 터미널에서는 위 첫 세 줄처럼 줄이 딱 안 맞아 보일 수 있어요. 계산이 틀린 게 아니에요.

강사님 말로는 가운데 정렬은 개인적으로 많이 쓰지는 않는대요.

## 5. 빈칸을 원하는 글자로 채우기

10강의 형식 문자는 빈칸을 **0으로밖에** 채울 수 없었어요. `format()`은 **어떤 글자든** 돼요. 정렬 기호 **왼쪽**에 채울 글자를 써요.

| 쓰는 법 | 뜻 |
|---|---|
| `{0:*>10}` | 10칸 오른쪽 정렬, 빈칸은 `*` |
| `{0:*<10}` | 10칸 왼쪽 정렬, 빈칸은 `*` |
| `{0:*^10}` | 10칸 가운데 정렬, 빈칸은 `*` |

순서는 **인덱스 번호 → 콜론 → 채울 글자 → 정렬 기호 → 자릿수**예요.

### 예제 (code/fill_char_formatting.py)

```python
print("이 {0:*>10}(은)는 {1:@>10}원 입니다.".format("사과", 1200))
print("이 {0:*<10}(은)는 {1:@<10}원 입니다.".format("사과", 1200))
print("이 {0:*^10}(은)는 {1:@^10}원 입니다.".format("사과", 1200))

msg8 = "[{0:~<5}]!!Python!! [{1:*^9}]!!Python"
print(msg8.format("Hi", "Hello"))

print("{0:0<10}".format(1200))
```

실행 결과:

```
이 ********사과(은)는 @@@@@@1200원 입니다.
이 사과********(은)는 1200@@@@@@원 입니다.
이 ****사과****(은)는 @@@1200@@@원 입니다.
[Hi~~~]!!Python!! [**Hello**]!!Python
1200000000
```

마지막 줄을 보세요. `1200`을 왼쪽 정렬하고 뒤를 0으로 채우니 `1200000000`처럼 **전혀 다른 숫자처럼** 보여요. 강사님 말로는 형식 문자는 이렇게 값이 바뀌어 보이는 출력을 지원하지 않았는데, `format()`은 "값이 바뀌건 말건 있는 그대로" 출력해 줘요. 그만큼 활용 범위가 넓은 거예요. 대신 보는 사람이 헷갈릴 수 있으니 숫자 뒤에 0을 채우는 건 조심해서 써요.

## 6. 소수점 표현하기

강사님이 "내용이 좀 길다"고 한 부분이에요. 하나씩 쌓아 가면 어렵지 않아요.

| 쓰는 법 | 뜻 | `123.456789`를 넣으면 |
|---|---|---|
| `{0}` | 형식 없이 값 그대로 | `123.456789` |
| `{0:f}` | 실수 형식, 소수점 아래 **6자리** | `123.456789` |
| `{0:0.4f}` 또는 `{0:.4f}` | 소수점 아래 4자리까지(5째 자리에서 반올림) | `123.4568` |
| `{0:10.4f}` | 전체 10칸, 소수점 4자리, 빈칸은 공백, 오른쪽 정렬 | `  123.4568` |
| `{0:010.4f}` | 위와 같지만 빈칸을 **0**으로 | `00123.4568` |
| `{0:<010.4f}` | 0으로 채우고 **왼쪽** 정렬 | `123.456800` |
| `{0:^010.4f}` | 0으로 채우고 **가운데** 정렬 | `0123.45680` |

- **전체 자릿수에는 소수점도 한 칸**으로 들어가요. `123.4568`은 `1 2 3 . 4 5 6 8`로 8칸이라, 10칸이면 앞에 2칸이 남아요.
- `12.34567`을 `.3f`로 하면 `12.346`(6칸)이라, 10칸이면 4칸이 남아요.
- 정렬 기호를 안 쓰면 **기본은 오른쪽 정렬**이에요. 그래서 `{0:>010.4f}`와 `{0:010.4f}`는 결과가 같아요.
- 강사님은 `.4f` 앞에 0을 붙여 `0.4f`로 쓰는 편이래요. 더 분명해 보여서 그런 거고, 결과는 같으니 취향대로 쓰면 돼요.

### 예제 (code/float_formatting.py)

```python
print("{0:f} + {1:0.3f}".format(123.456789, 12.34567))
print("{0:f} / {0}".format(12.34567))

msg9 = "{0:0.4f}"
print(msg9.format(123.456789))
print("{0:.4f}".format(123.456789))

msg10 = "[{0:10.4f}]"
print(msg10.format(123.456789))
print("[{0:10.4f}] + [{1:10.3f}]".format(123.456789, 12.34567))

msg11 = "{0:010.4f}"
print(msg11.format(123.456789))
print("{0:010.4f} + {1:010.3f}".format(123.456789, 12.34567))

print("{0:<010.4f} + {1:<010.3f}".format(123.456789, 12.34567))
print("{0:^010.4f} + {1:^010.3f}".format(123.456789, 12.34567))

print("{0:$>10.2f} {0:!<10.2f}".format(3.14159))
```

실행 결과:

```
123.456789 + 12.346
12.345670 / 12.34567
123.4568
123.4568
[  123.4568]
[  123.4568] + [    12.346]
00123.4568
00123.4568 + 000012.346
123.456800 + 12.3460000
0123.45680 + 0012.34600
$$$$$$3.14 3.14!!!!!!
```

> **강의와 다른 점**: 강의에서는 `{0:f}`가 "있는 값을 그대로 출력한다"고 했어요. 슬라이드 예인 `123.456789`는 마침 소수점 아래가 6자리라 그대로처럼 보였을 뿐이고, 실제로 `f`는 **소수점 아래를 6자리로 맞춰요**. `"{0:f}".format(12.34567)`은 `12.345670`(끝에 0이 붙음)이에요. 값을 정말 그대로 보고 싶으면 강사님이 덧붙인 말처럼 `{0}`만 쓰면 돼요(3.14에서 확인, 위 실행 결과 둘째 줄).

- 마지막 줄처럼 0 대신 `$`, `!` 같은 다른 글자로 채울 수도 있어요. 강사님 말로 "어떤 글자든" 돼요. 다만 0이 아닌 글자는 정렬 기호 앞에 써야 해요(`{0:$>10.2f}`).

> **참고(강의 밖 내용)**: "반올림"이 우리가 학교에서 배운 것과 다르게 나올 때가 있어요. `"{0:.2f}".format(2.675)`는 `2.68`이 아니라 `2.67`, `"{0:.0f}".format(2.5)`는 `3`이 아니라 `2`예요. 컴퓨터는 실수를 정확히 저장하지 못하고(2.675는 실제로 2.67499...로 저장돼요), 딱 절반일 때는 짝수 쪽으로 보내는 규칙을 쓰기 때문이에요. 보통 출력용으로는 신경 쓰지 않아도 되지만, 돈 계산처럼 정확해야 할 때는 이런 점이 있다는 걸 기억해 두세요.

> **참고(강의 밖 내용)**: "자료형을 구분하지 않는다"는 건 `{0}`처럼 형식을 안 쓸 때 얘기예요. `f` 같은 형식을 붙이면 그 형식에 맞는 값이어야 해요. `"{0:f}".format("abc")` → `ValueError: Unknown format code 'f' for object of type 'str'`

---

## 7. 문자열 안에 중괄호 그대로 넣기

치환 문자 자체가 중괄호를 쓰니까, 진짜 중괄호를 출력하고 싶으면 **두 겹**(`{{`, `}}`)으로 써요. 앞에서 배운 것과 규칙이 같아요.

| 출력하고 싶은 것 | 쓰는 법 | 배운 강의 |
|---|---|---|
| `\` | `\\` | 8강 이스케이프 문자 |
| `%` | `%%` | 10강 형식 문자 |
| `{`, `}` | `{{`, `}}` | 11강 format |

강사님 말로 "규칙성이 있으니까 쉽죠".

### 예제 (code/brace_escape.py)

```python
msg12 = "{{python}}은 {0}다"
print(msg12.format("쉽"))
print(msg12.format("좋", python="내가 사용하는"))

msg13 = "{python}은 {0}다"
print(msg13.format("쉽", python="우리가 배우는"))
```

실행 결과:

```
{python}은 쉽다
{python}은 좋다
우리가 배우는은 쉽다
```

### 한 겹으로 쓰면 에러

```python
msg12 = "{python}은 {0}다"
print(msg12.format("쉽"))
```

```
KeyError: 'python'
```

`{python}`을 이름 형식의 치환 문자로 알아듣고 `python`이라는 이름의 값을 찾는데, `format()`에 그런 값을 안 넘겼으니 "python이 뭔데?" 하고 에러가 나는 거예요.

- 실습에서 강사님은 `python='우리가 배우는'`을 넘겨서 에러를 없애 보이기도 했어요(위 마지막 예). 하지만 원래 하려던 건 중괄호를 **그대로** 출력하는 거니까 두 겹으로 쓰는 게 정답이에요.
- 두 겹으로 쓴 뒤에는 `python=...`을 넘겨도 쓸 곳이 없어서 그냥 무시돼요(에러 아님).

## 정리와 강사님 조언

- 실습 예제는 슬라이드의 모든 내용을 다 담진 않았고, 강사님이 평소 많이 쓰는 기법 위주예요. 실습에 나온 것만 익혀도 충분하대요.
- 학습 정리 1~3번(인덱스 번호, 0부터 시작, 이름=값)은 실제로 많이 쓰고, 4번(자릿수와 정렬 기호)은 자주 쓰지는 않아서 강사님도 쓸 일이 있으면 **개인 노트를 보면서** 코딩한대요.
- 그래서 강사님 조언: 전부 달달 외우지 말고, **나만의 레퍼런스 노트**를 하나 만들어 두고 필요할 때마다 찾아보세요. 영어 사전 외우듯 외우면 안 쓰다 잊어버리지만, 자주 들춰 보며 익숙해진 건 잘 안 잊어버려요.
- 다음 강의에서는 `format()` 말고 문자열 객체가 가진 다른 메서드들을 실습 위주로 배워요.

> **참고(강의 밖 내용)**: `{}`처럼 번호를 비워 두면 왼쪽부터 0, 1, 2...가 자동으로 붙어요. `"{}{}입니다.".format(2000, "원")` → `2000원입니다.` 단, 한 문자열 안에서 `{0}`과 `{}`를 섞으면 `ValueError: cannot switch from manual field specification to automatic field numbering`이 나요. 또, 문자열 앞에 `f`를 붙이는 **f-string**(`f"이 과자는 {price}원입니다."`)을 쓰면 변수를 중괄호 안에 바로 넣을 수 있어요. 콜론 뒤 규칙(`:>10`, `:.2f` 등)은 이번에 배운 것과 똑같아요.

## 자주 하는 실수

### 1) 이름=값을 이름 없는 값보다 먼저 씀

```python
"{0} {name}".format(name="교과서", "책")   # SyntaxError: positional argument follows keyword argument
"{0} {name}".format("책", name="교과서")   # 책 교과서
```

### 2) 넘긴 값보다 큰 번호를 씀

```python
"{2}".format(1, 2)   # IndexError: Replacement index 2 out of range for positional args tuple
```

번호는 0부터 세요. 값이 2개면 `{0}`, `{1}`까지만 있어요.

### 3) 중괄호를 그대로 출력하려고 한 겹만 씀

```python
"{python}은 {0}다".format("쉽")     # KeyError: 'python'
"{{python}}은 {0}다".format("쉽")   # {python}은 쉽다
```

### 4) 채울 글자를 정렬 기호 뒤에 씀

```python
"{0:>*10}".format("Hi")   # ValueError: Invalid format specifier '>*10' for object of type 'str'
"{0:*>10}".format("Hi")   # ********Hi
```

채울 글자는 정렬 기호 **왼쪽**이에요.

### 5) `{0:f}`가 값을 그대로 보여 줄 거라고 생각함

```python
"{0:f}".format(12.34567)   # 12.345670  (소수점 아래 6자리로 맞춤)
"{0}".format(12.34567)     # 12.34567
```

### 6) 전체 자릿수에 소수점을 안 셈

`"{0:10.4f}".format(123.456789)`는 `123.4568`이 8칸(소수점 포함)이라 앞에 공백이 **2칸** 붙어요.

### 7) 변수 이름을 `str`로 지음

```python
str = "{0}원"
str(3)   # TypeError: 'str' object is not callable
```

`text`, `msg`처럼 다른 이름을 쓰세요.

## 용어 정리

| 용어 | 쉬운 뜻 |
|---|---|
| 포메팅(formatting) | 문자열 안 빈자리에 값을 끼워 넣어 원하는 모양으로 만드는 것 |
| 치환 문자 | 문자열 안의 빈자리 표시. `{0}`, `{name}`처럼 중괄호로 씀. 치환자라고도 함 |
| 형식 문자 | 10강에서 배운 `%d`, `%s`, `%f` 같은 빈자리 표시 |
| 객체 | 안에 다른 변수와 함수를 품고 있는 특수한 변수. 파이썬의 모든 변수는 객체 |
| 메서드 | 객체 안에 들어 있는 함수. `문자열.format()`처럼 점을 찍고 부름 |
| 인덱스 | 0부터 세는 순서 번호 |
| 파라미터 | 함수나 메서드에 넘기는 값. 매개변수라고도 함 |
| 정렬 | 정해진 칸 안에서 글자를 오른쪽·왼쪽·가운데로 붙이는 것 |
| 반올림 | 정한 자리 다음 숫자를 보고 올리거나 버리는 것 |
| KeyError | 이름으로 값을 찾는데 그 이름이 없을 때 나는 에러 |
| IndexError | 번호로 값을 찾는데 그 번호가 범위를 넘을 때 나는 에러 |
