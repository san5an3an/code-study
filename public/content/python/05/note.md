# 05. 변수의 이해

## 이 강의에서 배우는 것

- 컴퓨터가 0과 1(이진수)로 데이터를 저장하는 원리: 반도체와 메모리(RAM)
- 변수가 무엇인지: 데이터를 저장하려고 이름을 붙인 메모리 공간
- 대입 연산자 `=`로 변수 만들기, 초기화, 값 바꾸기
- 숫자형 변수의 여러 모양: 정수, 실수, 지수 표기법(`3e5`), 8진수(`0o`), 16진수(`0x`)
- 논리형 변수 `True` / `False`, 내용이 없는 변수 `None`, 문자열 변수
- 주피터 노트북 사용 팁: 다시 열면 "모두 실행", 변수 창, HTML로 내보내기, 변수 이름만 써서 값 보기
- 변수 이름 짓는 규칙과 스네이크 표기법, 카멜 표기법

> 복습: 앞 강의에서 VS Code에 주피터 노트북을 준비하고 첫 파이썬 프로그램을 실행했어요. 이번엔 프로그램이 다루는 데이터를 담는 그릇인 **변수**를 배워요. 강사님 말로는 "오늘 내용은 심플해요". 변수가 무엇인지 확실하게 정리하고 넘어가는 게 목표예요.

## 1. 컴퓨터는 데이터를 어떻게 저장할까

앞에서 "컴퓨터는 이진수(0과 1)밖에 못 알아듣고, 그 이진수 모음을 기계어라고 한다"고 배웠어요. 그럼 0과 1은 컴퓨터 안 어디에 어떻게 저장될까요?

- **반도체**는 전기나 열을 가하면 전기가 통하는 상태와 안 통하는 상태로 바뀔 수 있는 물질이에요.
- 뉴스에서 자주 보이는 동그란 원판을 **웨이퍼**라고 하고, 원료는 **실리콘**이에요.
- 웨이퍼의 한 점에 **전기가 흐르면 1, 안 흐르면 0**으로 보면 이진수를 저장할 수 있어요.
- 이 반도체를 가공해서 만든 게 **메모리**예요. 컴퓨터에 꽂는 **램(RAM)** 이 대표적이고, USB 메모리 같은 것도 반도체로 만들어요.

강사님이 강조한 점: **변수는 메모리의 구조를 이해하는 데서 시작해요.** 여기서 말하는 메모리는 컴퓨터에 꽂는 램 카드라는 걸 기억하세요.

## 2. 변수란

**변수**는 **데이터를 저장하기 위해 프로그램에 의해 이름을 부여받은 메모리 공간**이에요. 프로그램은 결국 데이터를 다루려고 쓰는 거라서, 데이터를 컴퓨터 어딘가(메모리)에 저장해야 하는데, 그 저장 공간에 이름을 붙인 게 변수예요.

### 만드는 법

```python
변수이름 = 값
```

- 파이썬에서는 **이름(키워드)을 쓰고 원하는 값을 대입**해서 변수를 만들어요.
- `=`는 **대입 연산자**예요. 수학의 "같다"가 아니라 "넣어라"라는 뜻이에요.
- 항상 **오른쪽에 쓴 값을 왼쪽 이름에 넣어요.** (오른쪽 → 왼쪽 방향)
- 이름은 아는 영어 단어 아무거나 써도 돼요. 단, 파이썬이 이미 쓰는 **예약어**는 못 써요(7절).

> **강의와 다른 점**: 학습 정리(22:46쯤)에서 "항상 왼쪽에서 오른쪽으로 대입이 되는 거죠"라고 말했는데, 말이 헛나온 거예요. 강의 앞부분과 슬라이드대로 **오른쪽 값이 왼쪽 이름으로** 대입돼요. `a = 100`은 100을 a에 넣는 것이고, 거꾸로 `100 = a`라고 쓰면 `SyntaxError: cannot assign to literal here. Maybe you meant '==' instead of '='?` 에러가 나요(python3 3.14에서 확인).

### 메모리 안에서 일어나는 일

```python
num1 = 100
```

1. 메모리(램)를 아주 크게 확대하면 무수히 많은 작은 칸으로 되어 있어요.
2. 파이썬 코드에 `num1`이라고 쓰면, 메모리 어딘가에 `num1`이라는 **이름표**를 하나 만들어요.
3. 거기에 `100`을 대입하면, 100을 이진수 `1100100`으로 바꿔서 한 칸씩 기록해요. 전기가 통하고, 안 통하고, 또 통하고... 이런 식으로요.

> **참고(강의 밖 내용)**: 이 그림은 처음 배울 때 이해하기 쉬운 비유예요. 실제 파이썬은 값(100)을 메모리에 따로 만들어 두고, 변수 이름이 그 값을 **가리키는** 방식으로 움직여요. 그래서 파이썬 변수는 "값이 든 상자"보다 "값에 붙인 이름표"에 더 가까워요. 지금은 강의 그림대로 이해해도 충분하고, 나중에 리스트 같은 걸 배울 때 이 차이가 중요해져요.

### 예제 (code/variable_basics.py)

```python
# 처음으로 값을 넣는 것을 초기화라고 해요
a = 123
b = -456
print(a)
print(b)

# 한 번 만든 변수에 다른 값을 넣으면 새 변수가 아니라 값이 바뀌어요
a = 10000
print(a)

msg = '안녕하세요. 파이썬'
print(msg)
```

실행 결과:

```
123
-456
10000
안녕하세요. 파이썬
```

### 초기화와 값 바꾸기

- 변수에 **맨 처음 값을 넣는 것**을 **초기화**라고 해요. 위에서 `a = 123`이 초기화예요.
- 이미 있는 `a`에 `a = 10000`을 하면 **새 변수를 만드는 게 아니라 앞에서 만든 변수의 값을 바꾸는 것**이에요.
- 강사님 말대로 "변할 수 있는 수"라서 변수예요. 한 번 만든 뒤에도 값을 언제든 바꿀 수 있어요.

## 3. 숫자형 변수: 정수와 실수

일반적으로 쓰는 숫자형 변수는 두 가지가 거의 90% 이상이에요.

| 종류 | 뜻 | 예 |
|---|---|---|
| 정수(int) | 소수점이 없는 수. 음수도 돼요 | `a = 123`, `b = -456` |
| 실수(float) | 소수점이 있는 수 | `c = 1.2`, `d = -3.45` |

### 예제 (code/float_exponent.py 앞부분)

```python
c = 1.2
d = -3.45
print(c)
print(d)
```

실행 결과:

```
1.2
-3.45
```

## 4. 지수 표기법

아주 크거나 아주 작은 수를 다룰 때 쓰는 방법이에요. 어려운 개념은 아니에요.

- `e5`는 **10의 5제곱을 곱한다**는 뜻이에요. 소수점을 **오른쪽으로 5칸** 옮기고 빈자리는 0으로 채워요.
- `e-3`은 **10의 -3제곱을 곱한다**는 뜻이에요. 소수점을 **왼쪽으로 3칸** 옮겨요.

| 코드 | 계산 | 값 |
|---|---|---|
| `3e5` | 3 × 10의 5제곱 | 300000.0 |
| `4.24e5` | 4.24 × 10의 5제곱 | 424000.0 |
| `4.24e-3` | 4.24 × 10의 -3제곱 | 0.00424 |
| `3e-5` | 3 × 10의 -5제곱 | 0.00003 |

`3`처럼 정수면 `3.0`으로 보고 거기서 소수점을 움직이면 돼요. 엑셀에서 이런 표현을 본 적 있을 거예요.

강사님 말로는 이걸 직접 코드에 쓸 일은 거의 없어요. 대신 **계산 결과가 너무 크거나 작을 때 파이썬이 이런 모양으로 출력해 주는 경우**가 종종 눈에 띌 거예요.

> 지수 표기법으로 쓴 수는 결과가 정수처럼 보여도 항상 **실수**예요. 그래서 `3e5`는 `300000`이 아니라 `300000.0`으로 나와요.

### 예제 (code/float_exponent.py 뒷부분)

```python
e = 3e5          # 3 * (10의 5제곱)
print(e)         # 300000.0

f = 3e-5         # 3 * (10의 -5제곱)
print(f)         # 0.00003 인데, 너무 작아서 파이썬이 3e-05 로 보여줘요
print(f == 0.00003)  # 값은 똑같아서 True 가 나와요

e = 4.24e5
print(e)
f = 4.24e-3
print(f)
```

실행 결과:

```
300000.0
3e-05
True
424000.0
0.00424
```

> **강의와 다른 점**: 강사님이 `3e-5`를 출력했더니 `3e-05`가 나오자 "원본이 그대로 나오네요, 소수점이 너무 깊어서 파이썬이 표시하기 곤란한가 봐요"라고 했어요. 정확히는 **파이썬이 일부러 지수 표기법으로 바꿔 보여 준 것**이에요. 파이썬은 실수가 0.0001보다 작으면(또는 아주 크면) 자동으로 지수 표기법으로 출력해요. 입력한 `3e-5`와 모양도 달라요(`3e-05`). 값은 0.00003 그대로라서 `3e-5 == 0.00003`은 `True`예요. (python3 3.14에서 `print(0.0001)` → `0.0001`, `print(0.00001)` → `1e-05`로 확인)

> **강의와 다른 점**: 강의 슬라이드(지수 표기법, 04:20쯤)에서 `e = 4.24e5` 위의 주석이 `# 지수형태(소수점의 왼쪽 이동)`으로 적혀 있는데, `e5`는 소수점이 **오른쪽**으로 이동해요. 실습 화면의 코드에는 `오른쪽 이동`으로 바르게 적혀 있어요.

## 5. 진법 표현: 8진수와 16진수

이진수 말고 8진수, 16진수도 쓸 수 있어요. 강사님 말로는 **쓸 일은 거의 없고 "이런 게 있구나" 정도만 기억**하면 돼요.

- **8진수**: 숫자가 0~7, 8개만 있어요. 7 다음이 10이에요.
- **16진수**: 0~9 다음에 A, B, C, D, E, F를 쓰고, F 다음이 10이에요.

그런데 그냥 `3`이라고 쓰면 10진수인지 8진수인지 16진수인지 구분이 안 되잖아요. 그래서 앞에 표시를 붙여요.

| 진법 | 쓰는 법 | 예 | 출력 |
|---|---|---|---|
| 10진수 | 그냥 숫자 | `3` | 3 |
| 8진수 | 숫자 `0` + 알파벳 `o` + 숫자 | `0o177` | 127 |
| 16진수 | 숫자 `0` + 알파벳 `x` + 숫자 | `0xABC` | 2748 |

재밌는 점은 **8진수나 16진수를 출력하면 파이썬이 알아서 10진수로 바꿔서 보여 준다**는 거예요.

### 예제 (code/octal_hex.py)

```python
g = 0o177
print(g)         # 1*64 + 7*8 + 7 = 127

h = 0xABC
print(h)         # 10*256 + 11*16 + 12 = 2748

print(3)
```

실행 결과:

```
127
2748
3
```

> **참고(강의 밖 내용)**: 8진수 표시는 영어 소문자 `o`(오)예요. 숫자 `0`(영)과 헷갈리기 쉬워요. 대문자 `0O177`, `0XABC`도 되지만 `O`와 `0`이 더 헷갈리니까 소문자를 쓰세요. 다른 언어처럼 `0177`(0만 붙이기)로 쓰면 파이썬 3에서는 `SyntaxError: leading zeros in decimal integer literals are not permitted; use an 0o prefix for octal integers` 에러가 나요. 이진수는 `0b`를 붙여요(`0b1100100`은 100).

## 6. 논리형, 문자열, 내용이 없는 변수(None)

### 논리형 변수: True / False

참이나 거짓을 저장하는 변수예요.

```python
a = True         # 참을 의미하는 키워드 True 를 a 에 할당
print(a)
b = False        # 거짓을 의미하는 키워드 False 를 b 에 할당
print(b)
```

강사님이 꼭 주의하라고 한 부분: 다른 프로그래밍 언어를 해 본 사람은 `true`, `false`처럼 **소문자**로 쓰는 게 익숙한데, 파이썬은 **첫 글자가 반드시 대문자**예요. 이거 실수하는 경우가 많아요.

```python
a = true
```

```
NameError: name 'true' is not defined. Did you mean: 'True'?
```

소문자 `true`는 파이썬이 아는 단어가 아니라서 "true라는 이름이 정의되지 않았다, True를 말한 거냐"고 알려 줘요.

### 문자열 변수

글자를 담는 변수예요. 메시지니까 `msg`라는 이름으로 만들었어요.

```python
msg = '안녕하세요. 파이썬'
print(msg)
```

- 쌍따옴표(`"`)든 홑따옴표(`'`)든 상관없어요. **앞뒤 짝만 잘 맞으면** 돼요.
- 문자열은 08강부터 자세히 배워요.

### 내용이 없는 변수: None

```python
hello = None
print(hello)
```

- `None`은 "나중에 값을 넣어야지" 하는 뜻으로 **일단 비워 놓고 시작하는 변수**에 넣는 값이에요.
- `print`로 출력하면 `None`이라고 나와요.
- 파이썬에서 아주 자주 쓰이진 않지만 가끔 등장하니까 키워드는 알아 두세요. 어떤 경우에 쓰는지는 뒤 강의에서 더 자세히 봐요.
- `None`도 `True`, `False`처럼 **첫 글자가 대문자**예요.

### 예제 (code/bool_none.py)

```python
a = True
print(a)
b = False
print(b)

hello = None
print(hello)

hello = "Hello"
print(hello)
```

실행 결과:

```
True
False
None
Hello
```

### 기본 자료형 정리

변수에 저장된 값의 종류를 **기본 자료형(Data Type, 데이터 타입)** 이라고 해요. 강의에서 본 것들이에요.

| 자료형 | 파이썬 이름 | 예 |
|---|---|---|
| 정수 | int | `123`, `-456`, `0o177`, `0xABC` |
| 실수 | float | `1.2`, `-3.45`, `4.24e5` |
| 논리값 | bool | `True`, `False` |
| 문자열 | str | `'안녕하세요. 파이썬'` |
| 내용 없음 | NoneType | `None` |

강사님 말로는 잘 쓰이진 않지만 **복소수**라는 종류도 있어요.

> **참고(강의 밖 내용)**: 복소수는 `3+4j`처럼 `j`를 붙여 써요(자료형 이름은 complex). 수학이나 공학 계산 말고는 거의 안 써요. 또 변수에 든 값의 자료형은 `type()`으로 확인할 수 있어요. `print(type(3e5))` → `<class 'float'>`, `print(type(0o177))` → `<class 'int'>`, `print(type(None))` → `<class 'NoneType'>`.

## 7. 변수 이름 짓는 규칙

- **영어, 숫자, 언더바(`_`)** 만 쓸 수 있어요.
- **첫 글자는 숫자가 안 돼요.** (`num1`은 되고 `1num`은 안 돼요)
- 파이썬이 기능을 부여한 키워드, 즉 **예약어**는 못 써요. (`True`, `False`, `None`, `class`, `if` 등)
- **대소문자를 구분해요.** `age`와 `Age`는 서로 다른 변수예요.
- 잘 알려져 있진 않지만 **한글도 돼요.** (그래도 보통은 영어로 써요)

### 띄어쓰기가 필요한 이름

변수 이름에는 띄어쓰기를 못 써요. 단어가 여러 개면 두 가지 방법이 있어요.

| 방법 | 모양 | 예 |
|---|---|---|
| 스네이크 표기법 | 단어 사이를 언더바로 이어요 | `user_name` |
| 카멜 표기법 | 단어 첫 글자를 대문자로 써요 | `userName` |

강사님이 강조한 점: **어떤 방식을 쓰든 자유지만, 한 번 규칙을 정하면 꾸준히 그 규칙만 쓰는 게 좋은 코딩 습관**이에요.

> **참고(강의 밖 내용)**: 카멜 표기법은 보통 **첫 단어는 소문자, 두 번째 단어부터 첫 글자를 대문자**로 써요(낙타 등처럼 중간이 솟아서 카멜). 파이썬 공식 스타일 가이드(PEP 8)는 변수 이름에 **스네이크 표기법**을 권해요. 그래서 파이썬에서는 `user_name`처럼 쓰는 게 더 흔해요.

### 예제 (code/variable_names.py)

```python
num1 = 100
_count = 3
print(num1, _count)

age = 20
Age = 30
print(age, Age)

user_name = "홍길동"   # 스네이크 표기법
userName = "홍길동"    # 카멜 표기법
print(user_name, userName)

점수 = 90
print(점수)
```

실행 결과:

```
100 3
20 30
홍길동 홍길동
90
```

안 되는 이름은 이런 에러가 나요.

```python
1abc = 3        # SyntaxError: invalid decimal literal  (숫자로 시작)
class = 3       # SyntaxError: invalid syntax           (예약어)
my name = 3     # SyntaxError: invalid syntax           (띄어쓰기)
```

> **참고(강의 밖 내용)**: 파이썬 3.14의 예약어는 35개예요. `import keyword` 후 `print(keyword.kwlist)`로 전부 볼 수 있어요.

## 8. 주피터 노트북 사용 팁

이번 실습은 VS Code에서 새 주피터 노트북을 만들어 진행했어요.

### 새 노트북 만들기

1. `Ctrl + Shift + P`(맥은 `Cmd + Shift + P`)를 누르고 **Create: New Jupyter Notebook**을 선택해요.
2. 처음엔 이름이 `Untitled-1.ipynb`이고 아직 저장 안 된 상태예요. **제일 먼저 `Ctrl + S`로 저장**해요. 화면에서는 `05-변수의_이해.ipynb`로 저장했어요. **확장자(`.ipynb`)까지 꼭** 적어요.
3. 첫 블록을 마크다운으로 바꾸고 제목(`05강 - 변수의 이해`)을 적어요.
4. 마크다운 블록 아래에 추가되는 블록도 자동으로 마크다운이라서, 코드를 쓸 블록은 **코드로 바꿔** 줘야 해요.

### 블록끼리는 실행 내역을 이어 가요

주피터 블록은 서로 떨어져 있어도 **앞에서 실행한 내용을 계속 기억**해요. 그래서 아래 블록에서 `print(a)`를 하면 위 블록에서 만든 `a`를 그대로 쓸 수 있어요.

### 닫았다가 다시 열면 "모두 실행"

노트북을 닫았다 다시 열면 **출력 결과는 화면에 남아 있지만, 실행했던 내역은 전부 잊혀요.** 이 상태에서 새 블록에 `print(b)`를 실행하면 에러가 나요.

```
NameError: name 'b' is not defined
```

"b라는 이름이 정의되지 않았다"는 뜻이에요. 강사님 말대로 **출력 결과가 있다고 해서 실행됐다고 생각하면 안 돼요.**

해결: 위쪽 메뉴의 **모두 실행** 버튼을 눌러 모든 블록을 한 번에 실행한 다음 이어서 작업해요. 그러면 `print(b)`가 정상으로 `False`를 출력해요.

### 변수 창

메뉴의 **변수** 버튼을 누르면 아래쪽에 JUPYTER: VARIABLES 표가 나와요. 지금 쓰고 있는 변수의 이름(Name), 데이터 타입(Type), 마지막으로 저장된 값(Value)을 한눈에 보여 줘서 실행 결과를 따라가기 쉬워요. 화면에서는 `a bool True`, `c float 1.2`, `g int 127`처럼 보였어요.

### HTML로 내보내기

공부한 노트북을 나중에 다시 보고 싶을 때 매번 VS Code를 켜는 건 번거로워요.

1. `Ctrl + Shift + P`(맥은 `Cmd + Shift + P`)를 누르고 `주피터 HTML`로 검색해요.
2. **Jupyter: HTML로 내보내기(Export to HTML)** 를 선택하고 저장해요.
3. 저장한 폴더에 확장자가 `.html`인 파일이 생겨요. 클릭하면 실습 내용을 웹페이지로 볼 수 있어요.

강사님은 이렇게 공부한 내용을 정리하는 것도 하나의 팁이라고 했어요.

### 변수 이름만 써서 값 보기 (주피터 전용)

- `.py` 파이썬 파일에서는 값을 보려면 **반드시 `print`를 써야** 해요.
- 주피터에서는 블록 마지막 줄에 **변수 이름만 써도** 값이 출력돼요.

```python
msg = '안녕하세요. 파이썬'
msg
```

주피터 출력:

```
'안녕하세요. 파이썬'
```

`print`와 달리 문자열이 따옴표째로 보여요.

- 한 블록에 이름을 두 개(`a`, `b`) 쓰면 **마지막 것(`b`)만** 출력돼요. 그래서 이름만 써서 보는 건 **한 블록에 하나씩만** 써요.
- `hello = None` 다음 줄에 `hello`만 쓰면 **아무것도 안 나와요.** 내용이 없으니까요. `print(hello)`로 해야 `None`이 보여요.
- 강사님 조언: 블록을 많이 나눠도 실행에 영향은 없고 오히려 단계별로 점검할 수 있으니 **블록을 자주 나누세요.**

> 이 부분은 주피터에서만 되는 동작이라 `code/` 폴더의 `.py` 파일에는 넣지 않았어요. `.py` 파일에서 변수 이름만 쓰면 아무것도 출력되지 않아요.

> **참고(강의 밖 내용)**: 강의 화면의 파이썬은 3.11.1이에요. 이 노트의 코드와 결과는 파이썬 3.14에서 실행해 확인했고, 이번 강의 내용은 버전 차이 없이 똑같이 동작해요.

## 자주 하는 실수

### 1) True / False / None을 소문자로 씀

```python
a = true    # NameError: name 'true' is not defined. Did you mean: 'True'?
a = True    # 첫 글자는 대문자
```

### 2) 대입 방향을 거꾸로 씀

```python
100 = num1  # SyntaxError (값은 오른쪽, 이름은 왼쪽)
num1 = 100
```

### 3) 숫자로 시작하거나 띄어쓰기가 있는 이름

```python
1num = 3       # SyntaxError
my name = 3    # SyntaxError
num1 = 3       # 숫자는 뒤에
my_name = 3    # 띄어쓰기 대신 언더바
```

### 4) 8진수를 0만 붙여서 씀

```python
g = 0177     # SyntaxError: leading zeros ... use an 0o prefix for octal integers
g = 0o177    # 127
```

### 5) 주피터를 다시 열고 바로 아래 블록부터 실행

```
NameError: name 'b' is not defined
```

출력 결과가 남아 있어도 실행 내역은 사라졌어요. **모두 실행**을 먼저 눌러요.

### 6) 한 블록에 변수 이름만 여러 개 씀

```python
a
b      # 주피터는 마지막 b 만 보여 줘요. 둘 다 보려면 print(a), print(b)
```

### 7) 3e-05를 다른 값으로 착각

`print(3e-5)`가 `3e-05`로 나오는 건 0.00003을 지수 표기법으로 보여 준 것뿐이에요. 값은 같아요.
