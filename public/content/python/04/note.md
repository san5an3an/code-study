# 04. 첫번째 파이썬 프로그램

## 이 강의에서 배우는 것

- 파이썬을 실행하는 가장 원시적인 방법: 명령 프롬프트(윈도우)와 터미널(맥)에서 바로 명령어 입력하기
- 소스 코드가 무엇이고, 메모장으로 `.py` 파일을 만들어 한 번에 실행하는 방법
- VS Code 첫 설정: 한국어 확장, 파이썬 확장, 글꼴 크기, 색 테마
- VS Code에서 작업 폴더를 열고 `.py` 파일과 주피터 노트북(`.ipynb`) 파일 만들기
- 주피터 사용법: 코드 블록과 마크다운 블록, `Shift + Enter`와 `Ctrl + Enter`, `ESC`로 이동 모드
- 주석문: `#` 한 줄 주석과 `"""` 여러 줄 처리

> 복습: 지난 강의(02~03강)에서 윈도우와 맥에 파이썬, VS Code, 주피터를 설치했어요. 이번엔 그걸로 드디어 첫 번째 파이썬 프로그램을 짜 봐요. 강의 목표는 "파이썬 소스코드를 작성하고 실행하여 결과를 확인할 수 있다"예요.

## 1. 가장 원시적인 방법: 명령 프롬프트와 터미널

강사님은 "진짜 파이썬을 코딩하는 FM스러운 방법"부터 보여 줘요. 다만 VS Code가 나오기 전까지는 **흐름을 이해하는 용도라 꼭 따라 할 필요는 없다**고 했어요.

### 윈도우: 명령 프롬프트

1. `윈도우키 + R`로 실행창을 열고 `cmd`를 입력한 뒤 확인을 눌러요.
2. 명령 프롬프트에 `python`이라고 입력하고 엔터를 치면 **파이썬 모드**로 들어가요. 줄 앞에 `>>>`가 보이면 파이썬 명령을 받을 준비가 된 거예요.
3. 명령어를 한 줄씩 입력하고 엔터를 쳐요.

화면에 나온 그대로예요.

```
>>> print("Hello World")
Hello World
>>> a = 100
>>> b = 200
>>> print( a+b )
300
>>>
```

- `print("Hello World")`: `Hello World`라는 메시지를 출력하라는 명령어예요.
- `a = 100`: 100을 의미하는 `a`라는 데이터를 만들어요. 출력 명령이 아니라서 아무것도 안 나와요.
- `print(a + b)`: 두 데이터를 더한 값을 출력해요.

### 맥: 터미널

1. `Command + Space`로 Spotlight 검색창을 열고 "터미널"을 검색해 실행해요. (`Command + +`로 글자를 키울 수 있어요.)
2. 맥에서는 명령어 뒤에 **숫자 3을 붙여요**. `python3`을 입력하면 파이썬 모드로 들어가요.
3. 윈도우와 똑같이 명령어를 입력해요. 결과도 똑같아요.

> **참고(강의 밖 내용)**: 강의 화면은 Python 3.11.1이에요. 지금 이 노트를 확인한 버전은 Python 3.14예요. 이 강의에 나오는 코드는 버전이 달라도 결과가 같아요. 파이썬 모드에서 빠져나올 때는 `exit()`를 입력하면 돼요.

### 이 방법의 단점

- 중간에 틀리면 **처음부터 다시** 해야 해요. 명령 프롬프트는 이미 친 줄을 고칠 수 없어요.
- 까만 배경에 하얀 글씨라 알아보기가 힘들어요.

그래서 잘 쓰지 않는 환경이에요.

## 2. 소스 코드 파일 만들고 실행하기 (메모장)

### 소스 코드란

강사님 판서 그대로예요.

**프로그래밍 언어 → 명령어 → 텍스트 파일 → 소스코드**

프로그래밍 언어로 작성한 명령어들을 텍스트 파일에 기록한 것을 **소스 코드**라고 해요. 파일에 적어 두면 틀린 곳만 고쳐서 다시 실행할 수 있어요.

### 만드는 순서 (윈도우)

1. 바탕화면 폴더 창의 빈 곳에서 마우스 우클릭 → **새로 만들기 → 텍스트 문서**를 골라요.
2. 파일 이름을 `소스코드.py`로 바꿔요. **파이썬 소스 코드의 확장자는 `py`** 예요. 확장자가 보이도록 설정돼 있어야 해요(02강에서 설정).
3. 실행창(`윈도우키 + R`)에 `notepad`를 입력해 메모장을 열고, 만든 파일을 메모장에 끌어다 놓아요.
4. 아까 입력한 명령어를 적고 저장해요.

### 예제 (code/hello_world.py)

```python
print("Hello World")   # 괄호 안의 내용을 화면에 출력해요

a = 100
b = 200

print(a + b)           # a와 b를 더한 값 300을 출력해요
```

실행 결과:

```
Hello World
300
```

> 강사님이 메모장에 처음 쓸 때 `print("Hello World"`처럼 괄호를 하나 덜 닫아서 직접 고쳤어요. 괄호를 안 닫고 실행하면 이런 에러가 나요(3.14에서 확인).
> ```
> SyntaxError: '(' was never closed
> ```
> "여는 괄호 `(`가 닫히지 않았다"는 뜻이에요.

### 소스 코드 실행하기

파이썬 인터프리터(코드를 읽고 실행해 주는 프로그램)한테 이 파일을 알려줘야 해요. 그러려면 **파일이 있는 위치에서** 명령 프롬프트를 열어야 해요.

- 그냥 명령 프롬프트를 열면 위치가 `C:\Users\사용자이름`(홈 폴더)이에요. 거기서 파일 있는 곳까지 명령어로 직접 이동하는 건 번거로워요.
- 강사님 꿀팁: 폴더 창 위쪽 **주소 표시줄의 빈 곳을 클릭**하고, 내용을 지운 뒤 `cmd`를 입력하고 엔터를 치면 **그 폴더 위치에서** 명령 프롬프트가 열려요.
- `dir`을 입력하면 그 폴더 안의 파일 목록이 나와요. `소스코드.py`가 있는지 확인해요.
- `python 소스코드.py`(파이썬 한 칸 띄고 파일 이름)를 입력하면 파일 안의 모든 코드를 **한 번에** 실행해요.

```
C:\Users\leekh\Desktop>python 소스코드.py
Hello World
300
```

맥이라면 터미널에서 `python3 소스코드.py`처럼 입력해요.

여기까지가 "원시적인 방법"이에요. 메모장도 하얀 종이에 까만 글씨뿐이라 불편해요. 강사님은 전체 흐름을 이해하는 차원에서 봐 두라고 했어요.

## 3. VS Code 첫 설정

이제부터는 **같이 따라 해야 하는 부분**이에요. VS Code를 실행하면 기본으로 까만 배경(다크 테마)이에요.

### 강의 슬라이드: Visual Studio Code 필수 설정

**최초 실행 → 한국어 익스텐션 설치 → 파이썬 익스텐션 설치(Microsoft) → 사용하는 글꼴 크기 설정(16 권장)**

### 1) 한국어 확장 설치

- 왼쪽 세로 아이콘 줄에서 **확장(Extensions)** 아이콘을 눌러요.
- `Korean`을 검색하면 한국어 언어 팩이 나와요. **Install**을 눌러요.
- 설치가 끝나면 오른쪽 아래에서 다시 시작할지 물어요. **Restart**를 누르면 메뉴가 한글로 바뀌어요.

### 2) 파이썬 확장 설치

- 확장에서 `python`을 검색해요.
- 여러 개가 나오는데 다 깔 필요는 없어요. **Microsoft가 만든 `Python`** 하나만 설치하면 필요한 최소 항목들이 자동으로 같이 깔려요.
- 설치가 끝나면 버튼 모양이 바뀌고 설치 버튼이 사라져요.

> **참고(강의 밖 내용)**: 확장 구성은 그동안 바뀌어서, 지금은 Python 확장을 깔아도 주피터 확장이 같이 안 깔릴 수 있어요. 주피터 노트북을 만들 때 명령이 안 보이면 확장에서 `Jupyter`(Microsoft)를 검색해 따로 설치하세요. 처음 셀을 실행할 때 `ipykernel` 설치를 물어보면 설치를 눌러 주면 돼요.

### 3) 글꼴 크기와 색 테마

- 왼쪽 맨 아래 **톱니바퀴 아이콘 → 설정(Settings)** 으로 들어가요.
- **Editor: Font Size**(글꼴 크기): 기본 글자가 아주 작아요. 강사님은 수업용으로 22를 썼고, 여러분에게는 **16 정도를 권해요**.
- **색 테마(Color Theme)**: 기본은 다크 테마예요. 강사님은 `Light` 또는 `Light+`로 바꿔 썼어요. 취향대로 고르면 돼요.

## 4. 작업 폴더 열고 .py 파일 실행하기

### 가장 중요한 점: 폴더부터 연다

강사님이 가장 강조한 부분이에요.

- **작업 폴더를 무조건 어딘가에 만들고, 그 폴더를 열어야 해요.**
- **절대 소스 코드 파일을 바로 열지 않아요.** 폴더를 열고, 그 안의 파일을 열어요.

순서:

1. 바탕화면(아무 곳이나 괜찮아요)에 새 폴더를 만들어요. 강의에서는 `파이썬 공부`라고 만들었어요.
2. VS Code 탐색기의 **폴더 열기** 버튼, 또는 **파일 메뉴 → 폴더 열기**로 그 폴더를 지정해요. 윈도우는 프로그램 창 위에, 맥은 화면 맨 위에 파일 메뉴가 있어요.

### .py 파일 만들어 실행

1. 탐색기의 폴더에서 마우스 우클릭 → **새 파일** → 이름을 `HelloPython.py`로 정해요.
2. 앞에서 쓴 코드(`print("Hello World")`, `a = 100`, `b = 200`, `print(a+b)`)를 입력해요.
3. **F5**를 누르고, 디버그 구성을 고르라고 하면 **Python 파일**을 골라요.
4. 아래쪽 터미널에 `Hello World`와 `300`이 나와요.

> **참고(강의 밖 내용)**: 강의 화면을 보면 결과 위에 `FileNotFoundError ...`라는 빨간 글이 같이 찍혔는데, 결과(`Hello World`, `300`)는 정상으로 나왔어요. 실행 도구(디버거) 쪽 메시지라 우리 코드의 문제는 아니에요. 폴더 이름에 띄어쓰기나 한글이 있으면 이런 일이 생길 때가 있어서, 작업 폴더 이름은 `python_study`처럼 영어와 밑줄로 짓는 게 덜 헷갈려요.

### 이 방법의 단점

- 결과 하나 보려고 해야 할 일이 많고 결과를 알아보기도 쉽지 않아요.
- 무엇보다 **모든 코드가 한 번에 일괄 실행**돼요. 나중에 결과를 많이 출력하는 예제에서는 따라가기 힘들어요.

그래서 강사님은 이 `.py` 파일을 지우고, 이제부터는 주피터로 진행해요.

## 5. 주피터 노트북 만들기

VS Code는 주피터를 간접적으로 쓸 수 있게 해 줘요. (주피터 = 코드를 블록으로 나눠 실행하는 도구)

### 만드는 순서

1. **명령 팔레트**를 열어요. 윈도우는 `Ctrl + Shift + P`, 맥은 `Cmd + Shift + P`예요. 화면 위에 명령어 입력 창이 나와요.
2. `jupyter`를 검색하고 **Create: New Jupyter Notebook**을 골라요.
3. `Untitled-1.ipynb`라는 파일이 생겨요. `.ipynb`가 **주피터 전용 파일**의 확장자예요.
4. **일단 저장부터** 해요. `Ctrl + S`(맥은 `Cmd + S`). 저장 위치가 작업 폴더인지 확인하고 이름을 `HelloWorld.ipynb`로 정해요. **확장자를 꼭 적어 주세요.**
5. 왼쪽 탐색기와 실제 폴더에 파일이 생긴 걸 확인해요.

> **강의와 다른 점**: 강의 말로는 "윈도우는 커맨드(cmd) + Shift + P"라고 했는데 반대예요. 슬라이드에 적힌 대로 **윈도우는 `Ctrl`, 맥은 `Cmd`** 예요(`Ctrl (Cmd) + Shift + p`). 말하다 바꿔 읽은 거예요.

> 강사님 팁: 명령 창에서 오타를 지우다가 맨 앞의 `>` 기호까지 지우면 **파일 검색 기능으로 바뀌어요**. 당황하지 말고 `>`를 하나 다시 입력한 뒤 명령어를 치면 돼요.

## 6. 주피터 사용법

주피터는 파이썬 코드를 **원하는 만큼 블록(셀)으로 나눠** 순서대로 실행하고, 결과를 블록 바로 밑에서 볼 수 있어요.

### 블록 실행하기

- 블록에 `print("Hello World")`를 쓰고 왼쪽 **실행 아이콘(▷)** 을 누르면 바로 밑에 결과가 나와요. 아이콘에 마우스를 올리면 단축키(**셀 실행 `Ctrl + Enter`**)가 보여요.
- **+ 코드** 버튼으로 블록을 추가해요.
- `a = 100`, `b = 200` 블록은 실행해도 `print`가 없어서 아무것도 안 나와요.
- 다음 블록에 `print(a + b)`를 쓰고 실행하면 `300`이 나와요.

강사님 말로는, 단계별로 실행할 수 있어서 **중간에 어디서 실수했는지 찾기 쉽고**, 결과를 바로 밑에서 보니까 **훨씬 직관적**이에요.

### Shift + Enter와 Ctrl + Enter

| 단축키 | 하는 일 |
|---|---|
| `Shift + Enter` | 1) 실행 후 다음 블록으로 이동, 2) 밑에 블록이 없으면 실행 후 블록 추가 |
| `Ctrl + Enter` | 현재 블록 실행 후 그 자리에 머물러 있기 |

### 블록 지우기, 출력 지우기, 모두 실행

- 블록마다 위에 작은 도구 상자가 나와요. **휴지통 아이콘**을 누르면 블록이 지워져요.
- 위쪽 **모든 셀의 출력 지우기**: 실행 결과를 전부 지워요.
- 위쪽 **모두 실행**: 블록 전체를 한 번에 일괄 실행해요.

### 마크다운 블록 (글쓰기 블록)

**+ Markdown** 버튼으로 만드는 블록이에요. 블록 오른쪽 아래에 블록 종류(`Python` 또는 `Markdown`)가 적혀 있어서 구별할 수 있어요. 마크다운은 텍스트 문서를 쓰는 표현법인데, 강사님은 기본 기능 한두 개만 쓴다고 했어요.

- `#` 한 칸 띄고 텍스트 → **제목**
- `##` 한 칸 띄고 텍스트 → 그보다 낮은 **소제목**
- `#`이 하나 늘 때마다 제목 수준이 낮아져요. **1부터 6 수준까지** 돼요.
- 일반 글은 그냥 쓰면 돼요.

강의에서 쓴 마크다운 블록:

```
# Title1

## Title2

### Title3

This is Visual Studio Code.

Hello Python
```

실행하면 `Title1`이 가장 큰 제목, `Title2`, `Title3`이 점점 작은 제목으로 보이고 나머지는 보통 글로 보여요. **더블클릭**하면 다시 고칠 수 있어요.

### 블록 순서 바꾸기

블록 왼쪽의 파란 선 옆에 마우스를 대면 손바닥 모양으로 바뀌어요. 그걸 끌어서 블록 순서를 옮길 수 있어요. 코드 블록도 마찬가지예요.

### 키보드로 블록 이동 (이동 모드와 편집 모드)

강사님은 마우스보다 **키보드를 쓰는 게 생산성이 좋다**고 했어요.

| 키 | 하는 일 |
|---|---|
| `ESC` | 이동 모드(명령 모드). 입력 커서가 사라지고, 왼쪽 파란 선이 현재 블록을 표시해요 |
| 방향키 위/아래 | (이동 모드에서) 블록 사이를 이동 |
| `Enter` | 그 블록의 편집 모드로 들어가요 |

강의에서는 이렇게 이동해서 맨 위 마크다운 블록을 `# Hello Python`으로 고쳤어요.

### 강의 슬라이드: Jupyter 사용 방법 요약

1. VSCode 실행 후 반드시 **작업 폴더를 먼저** 열어야 한다.
2. 새 파일은 "파일 → 새 파일" 메뉴, 또는 `Ctrl(Cmd) + Shift + P` 후 "Create: New Jupyter Notebook"(강사님은 명령어 방식을 권해요).
3. 주피터에는 글 작성용 **Markdown 블록**과 소스코드 작성용 **Code 블록** 두 종류가 있다.
4. `ESC` → 이동 모드(방향키로 위아래 이동) / `Enter` → 블록 편집 모드
5. Markdown 블록에서는 `# 제목` 형식으로 블록의 주제를 적을 수 있다.
6. Code 블록에서 `Shift + Enter`는 실행 후 다음 블록 이동(생성), `Ctrl + Enter`는 현재 블록 실행 후 머물러 있기.

## 7. 주석문 (Comment)

### 주석문이란

- 프로그램 소스코드 안에 개발자가 필요에 따라 적는 **설명문**이에요.
- 프로그램이 실행될 때 **제외**돼요. 그래서 실행 결과에 영향을 주지 않아요.
- 특정 명령문이 실행되지 않도록 **차단하는 용도**로도 써요. 예를 들어 `print(...)` 앞에 `#`을 붙이면 그 줄은 실행되지 않아요.

### 주석문의 종류

| 종류 | 쓰는 법 |
|---|---|
| 한 줄 주석 | 문장 앞에 `#`을 붙여요. 여러 줄이면 줄마다 `#`을 붙여요 |
| 여러 줄 처리 | 3중 쌍따옴표 `"""`로 감싸요. 안에서는 줄바꿈이나 들여쓰기가 자유로워요 |

강사님은 3중 쌍따옴표 방식은 개인적으로 선호하지 않아서 **앞으로 `#` 방식으로만** 소개한다고 했어요. 실제로도 **한 줄 주석을 주로 많이 써요.**

> **강의와 다른 점**: 슬라이드는 3중 쌍따옴표를 "여러 줄 주석문"이라고 했는데, 파이썬이 진짜 주석으로 아는 건 `#`뿐이에요. `"""..."""`는 **여러 줄짜리 문자열**이고, 아무 데도 쓰지 않으니 결과에 안 나올 뿐이에요. `python3`의 `ast` 모듈로 확인하면 `Expr(value=Constant(value='...'))`, 즉 "문자열 값 하나"로 읽혀요. 그래서 주피터 블록의 **맨 마지막 줄**에 `"""..."""`만 두고 실행하면 그 문자열이 결과로 화면에 찍혀요. 강사님 말대로 주석은 `#`으로 쓰는 게 안전해요.

### 블록 종류에 따라 #의 뜻이 달라요

강사님이 꼭 주의하라고 한 부분이에요.

- **코드 블록에서의 `#`** → 주석
- **마크다운 블록(줄여서 MK)에서의 `#`** → 제목

### 예제: HelloWorld.ipynb에 주석 적용하기 (code/comments.py)

강의 슬라이드의 노트북은 이렇게 생겼어요.

- 블록 1(마크다운): `# Hello World` → 제목
- 블록 2: `# 메시지를 출력하는 명령어` + `print("Hello World")`
- 블록 3: `a = 100    # 100을 의미하는 a라는 데이터 생성`, `b = 200    # 200을 의미하는 b라는 데이터 생성`
- 블록 4: `# 합산 결과 출력하기` + `print(a + b)`

블록 3처럼 코드 **뒤에** `#`을 붙이면, `#` 앞까지는 정상 코드이고 `#` 뒤부터 주석이에요.

이걸 파이썬 파일 하나로 옮기고, 차단 용도와 `"""`도 넣어 봤어요.

```python
# 메시지를 출력하는 명령어
print("Hello World")

a = 100    # 100을 의미하는 a라는 데이터 생성
b = 200    # 200을 의미하는 b라는 데이터 생성

# 합산 결과 출력하기
print(a + b)

# 명령문 앞에 #을 붙이면 그 줄은 실행되지 않아요(차단 용도)
# print("이 줄은 출력되지 않아요")

# 여러 줄에 주석을 달 때는 줄마다 #을 붙여요
# 첫째 줄 설명
# 둘째 줄 설명

"""
3중 쌍따옴표로 감싸면 여러 줄을 한꺼번에 적을 수 있어요.
여기 적은 내용도 출력되지 않아요.
"""

print("끝")
```

실행 결과:

```
Hello World
300
끝
```

강사님은 이 코드를 **첫 번째 파이썬 프로그램으로 최종 완성**하라고 했어요. 코드는 앞에서 이미 만들었으니 주석만 추가하면 돼요.

## 8. 주피터 블록은 하나의 프로그램이에요

주피터의 또 다른 특징이에요. 블록이 나눠져 있어도 **각각 독립된 프로그램이 아니라 전체가 하나의 프로그램**이에요.

그래서 `print(a + b)` 블록이 제대로 실행되려면 **그 앞의 `a = 100`, `b = 200` 블록이 먼저 실행돼 있어야** 해요. 앞 블록을 실행하지 않으면 `a`와 `b`가 아직 없는 상태라 에러가 나요.

### 예제 (code/jupyter_cells.py)

```python
# [블록 2] 데이터 만들기. print가 없으니 출력되는 건 없어요
a = 100
b = 200

# [블록 3] 블록 2를 먼저 실행해야 a, b가 있어서 에러가 안 나요
print(a + b)
```

실행 결과:

```
300
```

블록 2를 건너뛰고 블록 3만 실행하면 이런 에러가 나요(3.14에서 확인).

```
NameError: name 'a' is not defined
```

"`a`라는 이름이 정의되지 않았다(아직 만든 적 없다)"는 뜻이에요.

> **참고(강의 밖 내용)**: 반대로, 블록을 지우거나 고쳐도 **이미 실행해서 만든 변수는 남아 있어요**. 그래서 순서가 꼬였다 싶으면 위쪽 **재시작** 버튼을 누른 뒤 **모두 실행**으로 처음부터 다시 돌려 보세요.

## 자주 하는 실수

### 1) 괄호를 덜 닫음

```python
print("Hello World"    # SyntaxError: '(' was never closed
print("Hello World")   # 여는 괄호와 닫는 괄호를 짝 맞춰요
```

### 2) 맥에서 `python`만 입력함

맥에서는 `python3`라고 입력해요. 파일 실행도 `python3 소스코드.py`예요.

### 3) 폴더를 안 열고 파일만 바로 엶

VS Code에서는 **작업 폴더를 먼저 열고** 그 안에서 파일을 만들고 열어요.

### 4) 주피터 파일 이름에 확장자를 안 씀

저장할 때 `HelloWorld.ipynb`처럼 `.ipynb`까지 적어요.

### 5) 앞 블록을 실행하지 않고 뒤 블록만 실행함

```python
print(a + b)   # 앞 블록(a = 100, b = 200)을 안 돌렸다면 NameError: name 'a' is not defined
```

### 6) 마크다운 블록과 코드 블록의 # 헷갈림

코드 블록에서 `# Hello World`는 주석이라 아무것도 안 나와요. 제목으로 보이게 하려면 **마크다운 블록**에 써요.

### 7) 문자열 안의 #을 주석으로 착각함

```python
print("# 이건 주석이 아니에요")   # 따옴표 안의 #은 그냥 글자라서 그대로 출력돼요
```
