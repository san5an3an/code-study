# 10강. 메소드 정의와 호출

## 이 강의에서 배우는 것

- 메소드(함수)가 무엇인지, 왜 만들어 쓰는지 알아봐요.
- 메소드를 **정의(만들기)** 하고 **호출(부르기)** 하는 방법을 익혀요.
- `void` 가 "돌려주는 값이 없다"는 뜻이라는 것, 그리고 `return` 이 "부른 곳으로 돌아가기"라는 것을 배워요.
- 메소드를 부를 때 값을 넘기는 **전달값(argument)** 과, 그 값을 받는 **매개변수(parameter)** 를 구분해요.
- 배운 것을 이용해 팩토리얼을 구하는 메소드를 직접 만들어 봐요.

---

## 1. 메소드란?

**메소드(method)** 는 "어떤 일을 하는 코드 묶음에 이름을 붙여 둔 것"이에요. **함수(function)** 라고도 부르는데, 자바에서는 세 단어(메소드, 함수, function)를 같은 뜻으로 써도 괜찮아요.

비유하자면 메소드는 **레시피 카드**예요. "라면 끓이기" 카드를 한 번 써 두면, 라면이 먹고 싶을 때마다 카드 이름만 부르면 돼요. 매번 처음부터 순서를 다시 적을 필요가 없죠.

중요한 성질 두 가지:

1. 메소드는 **만들어 두기만 하면 실행되지 않아요.** 이름을 불러야(호출해야) 실행돼요.
2. 한 번 만들어 두면 **몇 번이든, 어떤 순서로든** 부를 수 있어요.

### 왜 메소드를 쓰나요?

- 같은 코드를 여러 번 복사해 붙이지 않아도 돼요.
- 이름만 보고 무슨 일을 하는지 알 수 있어 코드가 읽기 쉬워져요.
- 고칠 때 메소드 한 곳만 고치면 부르는 곳 전부에 반영돼요.

강사도 "자바 프로그램의 기능은 메소드로 표현된다"며 이 부분을 확실히 익혀 두라고 강조해요.

## 2. 메소드 작성 형식

```
리턴형  메소드이름 ( 매개변수 ) {
    실행할 코드
}
```

| 부분 | 뜻 |
|---|---|
| 리턴형 | 메소드가 일을 끝내고 돌려주는 값의 자료형. 돌려주는 게 없으면 `void` |
| 메소드이름 | 직접 지어요. 이름만 봐도 무슨 일을 하는지 알 수 있게 짓는 게 좋아요 |
| ( 매개변수 ) | 전달받을 값을 담을 변수. 받을 게 없으면 괄호만 `()` |
| { } | 중괄호. "여기부터 여기까지가 이 메소드"라는 범위 표시 |

이번 강의의 코드에는 앞에 `public static` 이 붙어요. 이건 나중에 클래스를 배울 때 설명하니까, 지금은 **그대로 따라 쓰면 돼요.**

## 3. 전달값이 없는 메소드

가장 단순한 형태부터 봐요. 괄호 안이 비어 있어요.

```java
public class NoArgumentMethod {

    public static void test1() {
        System.out.println("JAVA");
    }

    public static void test2() {
        System.out.println("Python");
    }

    public static void main(String[] args) {
        test1();
        test1();
        test2();
        test1();
    }
}
```

한 줄씩 볼게요.

- `public static void test1() {` : `test1` 이라는 메소드를 만들어요. `void` 이니 돌려주는 값은 없고, `()` 가 비었으니 받는 값도 없어요.
- `System.out.println("JAVA");` : test1 이 불리면 할 일이에요.
- `public static void main(String[] args)` : 사실 `main` 도 메소드예요. 프로그램은 항상 `main` 에서 시작해요.
- `test1();` : test1 을 **호출**해요. 이름 뒤에 괄호와 세미콜론을 붙여요.

실행 결과

```
JAVA
JAVA
Python
JAVA
```

`main` 에서 `test1();` 줄을 지우면 메소드를 만들어 놨어도 "JAVA" 는 안 나와요. 만들기와 부르기는 별개라는 걸 꼭 기억해요.

### 메소드는 어디에 만들까?

강의에서는 `main` 메소드 **위쪽**, 클래스의 중괄호 안에 만들어요. 중요한 건 **다른 메소드 안에 넣지 않는 것**이에요. 메소드끼리는 클래스 안에서 나란히 놓여요. (`main` 아래에 두어도 동작은 같아요.)

강사는 중괄호가 어디서 끝나는지 헷갈리지 않게 `}//test1() end` 처럼 끝에 주석을 달아 둬요. 초보 때 따라 하면 좋은 습관이에요.

## 4. return: 부른 곳으로 돌아가기

메소드는 자기 할 일을 다 하면 **자기를 부른 곳으로 되돌아가는** 성질이 있어요. 이걸 명령어로 쓴 게 `return` 이에요.

```java
public static void test3() {
    System.out.println("KOREA");
    return; // 나를 부른 곳으로 돌아가요
}
```

```java
test3(); // ① 여기서 test3 으로 가서 KOREA 를 찍고
test2(); // ② 다시 돌아와서 다음 줄인 test2 를 실행해요
```

실행 흐름은 이렇게 돼요.

```
main: test3() 호출 ──▶ test3: KOREA 출력, return
main: ◀── 돌아옴, 다음 줄 test2() 호출 ──▶ test2: Python 출력
main: ◀── 돌아옴 ...
```

- **마지막 줄의 return 은 생략 가능해요.** 안 써도 메소드 끝(`}`)에 닿으면 자동으로 돌아가요. 그래서 test1, test2 에는 return 을 안 썼어요.
- 하지만 **메소드 중간에 있는 return 은 생략하면 안 돼요.** 중간에 return 을 만나면 그 아래 코드는 실행하지 않고 바로 돌아가기 때문에, 그건 의미가 있는 코드예요.

### void 를 오해하지 않기

`void` 는 "return 이 없다"가 아니라 "**돌려주는 값**이 없다"는 뜻이에요. `return;` 처럼 뒤에 값이 없으면 void 메소드에서도 쓸 수 있어요. `return 10;` 처럼 값을 돌려주는 형태는 다음 강의(11강)에서 배워요.

## 5. 전달값과 매개변수

메소드를 부를 때 괄호 안에 값을 넣어서 **넘겨줄** 수 있어요.

- **전달값(argument, 아규먼트)** : 부르는 쪽에서 넘겨주는 값. 예) `test4(10)` 의 `10`
- **매개변수(parameter, 파라미터)** : 메소드 쪽에서 그 값을 받아 담는 변수. 예) `test4(int a)` 의 `a`

비유하면 전달값은 **택배 상자**, 매개변수는 **택배를 받는 우편함**이에요. 우편함에는 어떤 크기의 상자가 들어올지(자료형)가 정해져 있어야 해요.

```java
public static void test4(int a) {
    System.out.println(a);
}

public static void main(String[] args) {
    test4(10);
    test4(30);
    test4(50);
}
```

- `int a` : 정수 하나를 받을 매개변수예요. 자바에서는 매개변수 이름 앞에 **자료형을 반드시** 써야 해요.
- `test4(10);` : 10 이 `a` 에 들어간 채로 test4 가 실행돼요.

실행 결과

```
10
30
50
```

같은 메소드인데 넘기는 값만 바꾸면 결과가 달라져요. 이게 매개변수를 쓰는 이유예요.

### 전달값이 여러 개일 때

여러 개를 넘길 땐 **쉼표(,)로 구분**해요. 받는 쪽도 같은 개수, 같은 순서로 매개변수를 만들어요.

```java
public static void test5(int a, int b, int c) {
    System.out.println(a + b + c);
}

test5(6, 7, 8); // a=6, b=7, c=8
test5(2, 4, 6); // a=2, b=4, c=6
```

실행 결과

```
21
12
```

주의: 셋 다 int 라고 해서 `(int a, b, c)` 처럼 줄여 쓰면 **에러**예요. 매개변수의 자료형은 하나하나 다 적어야 해요.

### 자료형이 서로 다른 전달값

```java
public static void test6(float a, double b) {
    System.out.println(a + b);
}

test6(1.2f, 3.4);
```

- `1.2f` : 끝에 `f` 가 붙었으니 float 값이에요(04강 복습). 그래서 `float a` 가 받아요.
- `3.4` : 소수점 숫자는 기본이 double 이라 `double b` 가 받아요.

실행 결과

```
4.600000047683716
```

4.6 이 딱 안 나오는 이유는, float 은 정밀도가 낮아서 1.2 를 정확하게 저장하지 못하기 때문이에요. 이 값이 double 로 바뀌어 더해지면서 오차가 보이는 거예요.

### 전달받은 값 응용하기 (반복문과 함께)

```java
public static void test7(char ch, int a) {
    for (int b = 1; b <= a; b++) {
        System.out.print(ch);
    }
    System.out.println();
}

test7('#', 100);
```

- `char ch` 에는 `'#'`, `int a` 에는 `100` 이 들어가요.
- for 문(07강)이 b 를 1부터 a(=100)까지 늘리며 `#` 을 찍어요.
- `print` 는 줄바꿈을 안 해서 옆으로 쭉 이어 찍혀요. `println` 으로 쓰면 한 줄에 하나씩 100줄이 나와요.

실행 결과 (`#` 100개가 한 줄로)

```
####################################################################################################
```

## 6. 이름이 같아도 다른 변수예요

test4 의 `a` 와 test5 의 `a` 는 **완전히 다른 변수**예요. 매개변수는 자기 메소드 안에서만 살아 있고, 메소드가 끝나면 사라져요.

```java
public static void change(int a) {
    a = 999;
    System.out.println("change 안의 a: " + a);
}

public static void main(String[] args) {
    int a = 5;
    change(a);
    System.out.println("main 안의 a: " + a);
}
```

실행 결과

```
change 안의 a: 999
main 안의 a: 5
```

`change(a)` 를 하면 main 의 a 자체가 넘어가는 게 아니라 **값 5 가 복사되어** 넘어가요. 그래서 메소드 안에서 바꿔도 main 의 a 는 그대로예요. (이 예제는 강사의 주의사항을 확인하려고 덧붙인 거예요.)

## 7. 실습: 팩토리얼 메소드

**팩토리얼** 은 어떤 수부터 1까지 차례로 곱한 값이에요. 4 팩토리얼(4!)은 4 x 3 x 2 x 1 = 24 예요.

```java
public static void fact(int a) {
    long gop = 1;
    for (int f = a; f >= 1; f--) {
        gop = gop * f;
    }
    System.out.println(gop);
}

public static void main(String[] args) {
    fact(4);
    fact(3);
}
```

- `long gop = 1;` : 곱한 결과를 모아 둘 변수예요. 곱셈 누적은 **1에서 시작**해야 해요. 0에서 시작하면 뭘 곱해도 0이에요. 팩토리얼은 금방 커지니까 int 보다 큰 `long` 을 썼어요.
- `for (int f = a; f >= 1; f--)` : f 가 a 부터 1까지 하나씩 줄어들어요.
- `gop = gop * f;` : 지금까지 곱한 값에 f 를 곱해서 다시 저장해요.

실행 결과

```
24
6
```

메소드를 한 번 만들어 두니, 3! 이 필요하면 `fact(3)` 만 부르면 돼요.

## 자주 하는 실수

| 증상 / 에러 메시지 | 원인 | 해결 |
|---|---|---|
| `The method test2() is undefined for the type ...` (이클립스) / `cannot find symbol` (javac) | 메소드를 **부르기만 하고 만들지 않았거나** 이름 철자가 달라요 (`Test1` vs `test1`) | 메소드를 정의하고, 대소문자까지 똑같이 맞춰요 |
| 메소드를 만들었는데 아무것도 출력되지 않아요 | 정의만 하고 main 에서 **호출하지 않았어요** | main 안에 `메소드이름();` 을 써요 |
| `Syntax error, insert ";" to complete BlockStatements` / `';' expected` | 호출 줄 끝에 세미콜론 빠짐 (강의 [16:01] 에서도 실제로 발생) | `test4(30);` 처럼 `;` 를 붙여요 |
| `(int a, b, c)` 에서 에러 (`<identifier> expected`) | 매개변수 자료형을 생략했어요 | `(int a, int b, int c)` 처럼 하나씩 다 적어요 |
| `The method test4(int) ... is not applicable for the arguments ()` / `method test4 in class ... cannot be applied to given types` | 전달값 개수나 자료형이 매개변수와 맞지 않아요 | 매개변수 개수, 순서, 자료형에 맞게 값을 넘겨요 |
| `illegal start of expression` (javac) 등 문법 에러가 여러 개 | 메소드를 **main 안에** 만들었어요 | 메소드는 main 바깥, 클래스 중괄호 안에 나란히 둬요 |
| `Unreachable code` / `unreachable statement` | 메소드 중간의 `return;` 바로 아래에 코드를 썼어요 | return 다음 코드는 실행될 수 없어요. 위치를 다시 생각해요 |
| `Cannot make a static reference to the non-static method` (이클립스) / `non-static method ... cannot be referenced from a static context` (javac) | 메소드 앞에 `static` 을 빼먹었어요 | 지금은 `public static void ...` 를 그대로 써요 |

## 용어 정리

| 용어 | 쉬운 뜻 |
|---|---|
| 메소드 (method) | 이름을 붙여 둔 코드 묶음. 불러야 실행돼요 |
| 함수 (function) | 메소드와 같은 뜻으로 쓰는 말 |
| 정의 | 메소드를 만드는 것 (이름, 매개변수, 할 일 작성) |
| 호출 | 메소드 이름을 불러 실행시키는 것. `test1();` |
| 리턴형 | 메소드가 돌려주는 값의 자료형 |
| void | 돌려주는 값이 없다는 표시 |
| return | 나를 부른 곳으로 돌아가라는 명령어 |
| 전달값 (argument) | 메소드를 부를 때 괄호 안에 넣어 넘기는 값 |
| 매개변수 (parameter) | 메소드가 전달값을 받아 담는 변수 |
