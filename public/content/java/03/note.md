# 03강. 변수와 상수

## 이 강의에서 배우는 것

- 컴퓨터가 다루는 값(데이터)은 종류가 있고, 처음엔 **수치형 · 문자형 · 논리형** 세 가지만 구분하면 돼요.
- 따옴표가 붙느냐 안 붙느냐에 따라 같은 `123`, `true`도 전혀 다른 종류의 값이 돼요.
- **상수**는 값 그 자체(3은 언제나 3), **변수**는 값을 담아 두는 이름 붙은 상자예요.
- 자바에서 변수는 처음 한 번 **자료형**(예: `int`)을 붙여 만들어야 하고, `=`는 "같다"가 아니라 "넣어라"라는 뜻이에요.

---

## 1. 데이터란?

프로그램은 우리가 컴퓨터에 값을 넣으면, 컴퓨터가 그 값을 가공해서 새로운 정보를 만들어 내는 도구예요. 이때 컴퓨터가 다루는 모든 값을 **데이터(data)** 또는 **값(value)** 이라고 불러요.

자바에서는 데이터마다 **종류(타입, type)** 를 분명히 알려 줘야 해요. 종류에 따라 할 수 있는 일이 다르기 때문이에요. 예를 들어 숫자끼리는 더하기·빼기를 할 수 있지만, "대한민국"이라는 글자를 나누기 할 수는 없죠.

강의에서 정리한 표는 이래요.

| 데이터의 종류 | 데이터 타입 | 특징 |
|---|---|---|
| 수치형 | 정수형 | 소수점이 없다 |
| 수치형 | 실수형 | 소수점이 있다 |
| 문자형 | String | `"` 또는 `'` 로 감싼다 |
| 논리형 | boolean | 맞다(`true`), 틀리다(`false`) |

> 비유: 마트 진열대를 떠올려 보세요. 과일 코너, 음료 코너, 생활용품 코너가 나뉘어 있어야 계산도 정리도 편하죠. 데이터 종류도 "이 값은 어느 코너 물건인지" 정해 두는 거예요.

---

## 2. 수치형 데이터 (숫자)

숫자로 된 값이에요. 계산기처럼 사칙연산(더하기, 빼기, 곱하기, 나누기)을 할 수 있는 건 숫자뿐이에요.

- **정수**: 소수점이 없는 숫자. `3`, `-5`, `0`
  - 앞에 `-`를 붙이면 음수(음의 정수)가 돼요. 수학이랑 똑같아요.
- **실수**: 소수점이 있는 숫자. `2.4`, `-5.6`
  - 특이한 점: `7.` 처럼 점만 찍고 뒤를 비워도 자바는 실수로 봐요. 그래서 출력하면 `7.0`이 나와요.

```java
System.out.println(3);     // 양의 정수
System.out.println(-5);    // 음의 정수
System.out.println(2.4);   // 실수
System.out.println(-5.6);  // 음의 실수
System.out.println(7.);    // 점이 있으니 실수
```

- `System.out.println( 값 );` 은 괄호 안의 값을 콘솔(결과창)에 한 줄 출력하라는 명령이에요. 2강에서 배운 그 문장이에요.
- `//` 뒤는 **주석**이라 컴퓨터가 무시해요. 사람이 읽으라고 쓰는 메모예요.

실행 결과:

```
3
-5
2.4
-5.6
7.0
```

---

## 3. 문자형 데이터 (글자)

글자로 된 값이에요. 자바에서는 **반드시 따옴표로 감싸야** 글자라고 알아들어요. 문자열을 영어로 **String(스트링)** 이라고도 불러요.

- 큰따옴표 `" "` : 여러 글자를 담을 수 있어요. `"KOREA"`, `"대한민국"`
- 작은따옴표 `' '` : 딱 한 글자만. `'B'`, `'가'`
  - 둘 사이에 차이가 있긴 한데(다음 강의에서 자세히 나와요), 지금은 "둘 다 문자형"이라고만 기억해도 충분해요.

```java
System.out.println("KOREA");    // 문자열
System.out.println("대한민국");  // 한글도 큰따옴표로
System.out.println('B');        // 한 글자
System.out.println('가');       // 한글 한 글자
System.out.println(123);        // 숫자 123
System.out.println("123");      // 문자 "123"
```

실행 결과:

```
KOREA
대한민국
B
가
123
123
```

### 왜 따옴표가 꼭 필요할까?

따옴표 없이 `System.out.println(KOREA);` 라고 쓰면, 자바는 `KOREA`를 글자가 아니라 **어떤 이름(변수 이름 같은 것)** 으로 생각하고 찾으러 가요. 그런 이름은 없으니 에러가 나요. Eclipse에서는 줄 앞에 빨간 X 표시가 뜨고, 그 위에 마우스를 올리면 무엇이 틀렸는지 알려 줘요. 빨간 X는 오타만 찾으면 되는, 가장 고치기 쉬운 에러예요.

### 주의: `123` 과 `"123"` 은 다른 값

화면에는 둘 다 `123`으로 똑같이 보여요. 하지만

- `123` 은 **숫자**라서 계산할 수 있고,
- `"123"` 은 **글자**라서 숫자처럼 계산되지 않아요.

프로그램을 쓰는 사람(사용자)은 몰라도 되지만, 만드는 사람(개발자)은 반드시 구분해야 해요. 따옴표가 붙으면 무조건 문자형이 된다고 기억하세요.

---

## 4. 논리형 데이터 (참/거짓)

**boolean(불린)** 이라고도 불러요. 값이 딱 두 개뿐이에요.

- `true` : 맞다, 참
- `false` : 틀리다, 거짓

나중에 "점수가 60점 이상인가?" 같은 조건을 따질 때 이 값이 쓰여요.

```java
System.out.println(true);     // 논리형: 참
System.out.println(false);    // 논리형: 거짓
System.out.println("true");   // 따옴표가 있으니 문자열
System.out.println("false");  // 이것도 문자열
```

실행 결과:

```
true
false
true
false
```

결과는 똑같아 보이지만 위 두 줄은 논리형, 아래 두 줄은 문자형이에요. 여기서도 규칙은 같아요. **따옴표가 붙으면 문자형**이에요. 그리고 `true`, `false`는 소문자로 써야 해요(`True`라고 쓰면 에러).

---

## 5. 상수 (constant)

**상수**는 바뀌지 않는 값 그 자체예요. `3`은 언제나 3이고, `-5`는 언제나 -5고, `"JAVA"`는 언제나 JAVA죠. 다른 뜻을 갖지 않아요.

- 데이터 종류마다 쓰는 방법이 조금씩 달라요. 숫자는 그냥 쓰고, 문자열은 큰따옴표로 감싸요. 그래서 `"JAVA"`는 **문자열 상수**라고 불러요.

```java
System.out.println(3);       // 정수 상수
System.out.println(-5);      // 정수 상수
System.out.println(2.4);     // 실수 상수
System.out.println("JAVA");  // 문자열 상수
```

실행 결과:

```
3
-5
2.4
JAVA
```

> 일상에서도 "그건 이제 상수야"(절대 안 바뀜), "변수가 생겼어"(바뀔 수 있는 요소)라고 말하죠. 프로그래밍에서도 같은 뜻이에요.

---

## 6. 변수 (variable)

**변수**는 값을 저장해 두는 **이름 붙은 공간**이에요. 상자에 이름표 `a`를 붙여 두었다고 생각해 보세요. 이 상자에는 어떤 때는 3을, 어떤 때는 7을, 어떤 때는 9를 넣을 수 있어요. 담긴 값이 늘 바뀔 수 있어서 "변수(변하는 수)"라고 불러요.

> 비유: 사물함에 이름표를 붙여 두는 것과 같아요. 이름표(변수 이름)는 그대로인데 안에 든 물건(값)은 바꿔 넣을 수 있어요.

### 자료형을 먼저 정해야 해요

자바에서는 변수를 **처음 만들 때 한 번**, 그 상자에 어떤 종류의 값을 넣을지 정해야 해요. 이것을 **자료형**이라고 해요.

- 형식: `자료형 변수이름`
- `int` 는 "정수만 담는 상자"라는 뜻이에요 (자세한 자료형은 다음 강의 4강에서 배워요).
- 이렇게 자료형과 이름을 붙여 처음 만드는 것을 **변수를 선언한다**고 해요.

정수 상자라고 해 놓고 실수(2.4 같은 값)를 넣으려 하면 자바는 에러를 내요. 왜 이렇게 깐깐하게 정할까요? 상자 크기와 모양을 미리 정해 두면 컴퓨터가 메모리를 알맞게 준비할 수 있고, 엉뚱한 값이 들어가는 실수를 프로그램을 실행하기 전에 미리 잡아 줄 수 있기 때문이에요.

### 대입 연산자 `=`

수학에서 `=`는 "양쪽이 같다"는 뜻이지만, 자바에서는 **"오른쪽 값을 왼쪽 변수에 넣어라(대입해라)"** 라는 뜻이에요. 그래서 `=`를 **대입 연산자**라고 불러요. 항상 오른쪽에서 왼쪽으로 흐른다고 생각하면 돼요.

```java
int a = 7;                   // 정수 상자 a를 만들고 7을 넣어라
System.out.println(a);       // a 안의 값을 출력
System.out.println(a + 3);   // a의 값(7)에 3을 더한 값을 출력

a = 9;                       // a에 9를 새로 넣어라 (int는 다시 안 씀)
System.out.println(a);       // 이제 a는 9

System.out.println("a");     // 따옴표가 있으니 변수가 아니라 글자 a
```

한 줄씩 보면:

1. `int a = 7;` : 정수만 담는 상자 `a`를 만들고(선언) 7을 넣어요.
2. `println(a)` : 따옴표가 없으니 "a라는 상자 안에 든 값"을 꺼내서 출력해요. 그래서 `a`가 아니라 `7`이 나와요.
3. `println(a + 3)` : 글자 a에 3을 더하는 게 아니라, a 안의 값 7에 3을 더해요. 결과는 10.
4. `a = 9;` : 이미 만든 상자니까 `int`는 다시 붙이지 않아요. 새 값이 들어오면 이전 값 7은 깨끗이 지워지고(덮어쓰기) 9가 남아요.
5. `println("a")` : 따옴표로 감쌌으니 변수가 아니라 글자 `a` 그 자체, 즉 문자열 상수예요.

실행 결과:

```
3
-5
2.4
JAVA
7
10
9
a
```

(앞의 네 줄은 5절 상수 예제를 같은 파일 위쪽에 함께 둔 결과예요. 전체 코드는 `code/VariableExample.java`에 있어요.)

### 보충: `a + 3` 은 a를 바꾸지 않아요

```java
int score = 50;
System.out.println(score + 10);  // 60 (계산해서 보여 주기만 함)
System.out.println(score);       // 50 (그대로)
score = 80;                      // 대입해야 값이 바뀜
System.out.println(score);       // 80
score = score + 5;               // 지금 값 80에 5를 더해 다시 score에 넣음
System.out.println(score);       // 85
```

실행 결과:

```
50
60
50
80
85
```

`score = score + 5;` 는 수학으로 보면 말이 안 되는 식이지만, 자바에서는 "오른쪽(score + 5 = 85)을 먼저 계산해서 왼쪽 상자 score에 넣어라"라는 뜻이라 자연스러워요. 이 예제는 강의 내용을 이해하기 위한 보충 예제예요(`code/AssignExample.java`).

## 7. Eclipse 사용 팁 (강의에서 나온 것)

- **패키지(package)** 는 그냥 폴더라고 생각하면 돼요. 강의에서는 `src` 우클릭 → New → Package로 `oop03` 패키지를 만들고, 그 안에 클래스를 만들어요. (OOP는 객체지향 프로그래밍 Object-Oriented Programming의 약자예요.)
- 클래스 만들기: 패키지 우클릭 → New → Class → 이름 입력(`Test01_data`, `Test02_variable`) → `public static void main(String[] args)` 체크 → Finish. 자바는 기본적으로 클래스 단위로 코드를 써요.
- 저장: `Ctrl + S`. 저장 안 된 파일은 탭 이름 앞에 `*`가 붙어요.
- 실행: `Ctrl + F11`. 결과는 아래나 옆의 **콘솔(Console) 창**에 나와요. 콘솔 창은 드래그해서 원하는 위치로 옮길 수 있어요.
- 글자 크기: `Ctrl + Shift + (+)` 로 크게, `Ctrl + Shift + (-)` 로 작게.
- macOS에서는 `Ctrl` 자리를 대부분 `Cmd`로 바꿔 쓰면 돼요 (저장 `Cmd + S`, 글자 크기 `Cmd + +`/`Cmd + -`). 실행 단축키는 Eclipse 설정에 따라 다를 수 있으니 상단의 초록색 실행(Run) 버튼을 눌러도 돼요.
- 터미널에서 직접 실행하려면 `code` 폴더에서:
  ```
  javac -encoding UTF-8 VariableExample.java
  java VariableExample
  ```
  (이 노트의 예제 파일은 연습하기 쉽게 `package` 줄 없이 만들었어요. 강의 화면에는 맨 위에 `package oop03;` 이 있어요.)

## 자주 하는 실수

| 증상 / 에러 메시지 | 원인 | 해결 |
|---|---|---|
| `error: cannot find symbol` (예: `println(KOREA)`) | 글자인데 따옴표를 빼먹어서, 자바가 `KOREA`라는 이름을 찾다 실패함 | `"KOREA"` 처럼 큰따옴표로 감싸기 |
| `error: incompatible types: possible lossy conversion from double to int` (예: `int a = 2.4;`) | 정수 상자(`int`)에 실수를 넣으려 함 | 정수 값을 넣거나, 실수용 자료형(`double`, 4강)을 쓰기 |
| `error: cannot find symbol` (예: `b = 3;`) | 변수를 선언하지 않고 바로 씀 (자료형 빠짐) | 처음 한 번은 `int b = 3;` 처럼 자료형을 붙이기 |
| `error: variable a is already defined in method main(String[])` | 이미 만든 변수 앞에 `int`를 또 붙임 (`int a = 9;`) | 두 번째부터는 `a = 9;` 처럼 이름만 쓰기 |
| `error: unclosed character literal` (예: `'AB'`) | 작은따옴표에 두 글자 이상을 넣음 | 여러 글자는 큰따옴표 `"AB"` 로 |
| `error: ';' expected` | 문장 끝 세미콜론 `;` 빠짐 | 줄 끝에 `;` 붙이기 |
| `a`를 출력했는데 값 대신 글자 `a`가 나옴 | `println("a")` 처럼 따옴표로 감쌈 | 변수 값을 보려면 `println(a)` 처럼 따옴표 없이 |
| `True`, `FALSE` 에서 에러 | 논리값은 소문자만 인정 | `true`, `false` 로 쓰기 |

## 용어 정리

| 용어 | 쉬운 뜻 |
|---|---|
| 데이터(data), 값(value) | 컴퓨터가 다루는 모든 값 |
| 타입(type) / 자료형 | 값의 종류. 변수에 어떤 종류의 값을 넣을지 정하는 것 |
| 수치형 | 숫자 데이터. 계산할 수 있음 |
| 정수 | 소수점이 없는 숫자 (3, -5) |
| 실수 | 소수점이 있는 숫자 (2.4, 7.0) |
| 문자형, 문자열(String) | 따옴표로 감싼 글자 데이터 |
| 논리형(boolean, 불린) | 참(true)과 거짓(false) 두 값만 있는 데이터 |
| 상수(constant) | 바뀌지 않는 값 그 자체 |
| 문자열 상수 | `"JAVA"` 처럼 따옴표로 감싼 고정된 글자 |
| 변수(variable) | 값을 담아 두는 이름 붙은 공간. 값이 바뀔 수 있음 |
| `int` | 정수만 담는 자료형 |
| 변수 선언 | `int a` 처럼 자료형과 이름을 붙여 변수를 처음 만드는 것 |
| 대입 연산자 `=` | 오른쪽 값을 왼쪽 변수에 넣으라는 기호 |
| 주석 `//` | 컴퓨터가 무시하는 메모 |
| 콘솔(Console) | 실행 결과가 글자로 출력되는 창 |
| 패키지(package) | 클래스를 묶어 두는 폴더 |
