# 06강. 제어문 - if 조건문 및 switch-case문

## 이 강의에서 배우는 것

- 프로그램은 원래 위에서 아래로 한 줄씩 실행되는데, **제어문**을 쓰면 그 흐름을 원하는 대로 바꿀 수 있어요.
- **if 조건문**: 조건이 맞는지(true) 틀린지(false)에 따라 실행할 코드를 고르는 방법 (1형식, 2형식, 중첩 if)
- **switch-case문**: 어떤 값과 "똑같은" 항목을 목록에서 찾아 실행하는 방법 (break, default 포함)
- 성적 프로그램(평균, 합격/불합격, 학점)과 switch 예제로 직접 연습해요.

---

## 1. 제어문이란? 프로그램의 "흐름"을 바꾸는 것

지금까지 짠 코드는 모두 **위에서 아래로, 왼쪽에서 오른쪽으로** 한 줄씩 차례대로 실행됐어요. 하지만 실제 프로그램은 "점수가 70점 이상이면 합격, 아니면 불합격"처럼 **상황에 따라 다른 일**을 해야 하죠.

이렇게 실행 흐름을 바꾸는 문법을 **제어문**(control statement)이라고 해요. 이번 강의에서는 그중 **조건문** 두 가지를 배워요.

> 비유: 길을 걷다가 갈림길을 만났을 때 "비가 오면 왼쪽 지하도로, 아니면 오른쪽 공원길로" 가는 것과 같아요. 조건에 따라 가는 길이 달라지죠.

---

## 2. if 조건문

### 2-1. 조건(condition)이란?

if 바로 뒤의 괄호 `( )` 안에는 **조건**을 써요. 조건은 반드시 **맞다(true) 또는 틀리다(false)** 중 하나로 답이 나오는 식이어야 해요. 이런 true/false 값을 **불린(boolean) 값**이라고 불러요.

조건을 만들 때는 앞에서 배운 **비교 연산자**를 주로 써요.

| 연산자 | 뜻 | 예시 (kor = 100일 때) |
|---|---|---|
| `>=` | 크거나 같다(이상) | `kor >= 70` → true |
| `>` | 크다(초과) | `kor > 100` → false |
| `<=` | 작거나 같다(이하) | `kor <= 59` → false |
| `<` | 작다(미만) | `kor < 60` → false |
| `==` | 같다 | `kor == 100` → true |
| `!=` | 다르다 | `kor != 100` → false |

그리고 조건이 true냐 false냐에 따라 **중괄호 `{ }` 안의 코드가 실행될지 말지**가 결정돼요.

### 2-2. 세 가지 형태

| 1형식 | 2형식 | 중첩 if (else if) |
|---|---|---|
| `if (조건) {`<br>&nbsp;&nbsp;true일 때만 실행<br>`}` | `if (조건) {`<br>&nbsp;&nbsp;true이면 실행<br>`} else {`<br>&nbsp;&nbsp;false이면 실행<br>`}` | `if (조건1) {`<br>&nbsp;&nbsp;조건1이 true이면 실행<br>`} else if (조건2) {`<br>&nbsp;&nbsp;조건2가 true이면 실행<br>`} else {`<br>&nbsp;&nbsp;위 조건이 모두 false일 때 실행<br>`}` |

- 1형식, 2형식: 조건을 **한 번만** 물어봐요.
- 중첩 if: 조건을 **여러 개** 차례로 물어봐요.
- 세 형태는 한 프로그램 안에서 얼마든지 섞어 쓸 수 있어요.

### 2-3. 실습 준비 - 성적 프로그램

강의에서는 "무궁화"라는 학생의 성적으로 연습해요.

```java
String name = "무궁화";              // 이름
int kor = 100, eng = 100, mat = 35;  // 국어, 영어, 수학 점수

double aver = (kor + eng + mat) / 3.0;  // 평균

System.out.printf("이름 : %s\n", name);
System.out.printf("국어 : %d\n", kor);
System.out.printf("영어 : %d\n", eng);
System.out.printf("수학 : %d\n", mat);
System.out.printf("평균 : %.2f\n", aver);
```

- `int kor = 100, eng = 100, mat = 35;` : 같은 자료형 변수 여러 개를 쉼표로 한 줄에 만들 수 있어요.
- `(kor + eng + mat) / 3.0` : **괄호가 아주 중요해요.** 괄호가 없으면 연산자 우선순위 때문에 `mat / 3.0`이 먼저 계산되어 `100 + 100 + 11.67 = 211.67` 같은 이상한 값이 나와요.
- `3`이 아니라 `3.0`으로 나누는 이유: 정수끼리 나누면 소수점이 버려지기 때문에, 실수 `3.0`으로 나눠서 결과를 실수(double)로 받으려는 거예요.
- printf 서식 복습: `%s` 문자열, `%d` 정수, `%.2f` 소수 둘째 자리까지, `\n` 줄바꿈 (05강 내용이에요).

실행 결과:

```
이름 : 무궁화
국어 : 100
영어 : 100
수학 : 35
평균 : 78.33
```

### 2-4. 1형식 - 조건이 맞을 때만 실행

문제: 평균이 95점 이상이면 "장학생"을 출력하세요.

```java
if (aver >= 95) {                    // 평균이 95 이상인가?
    System.out.println("장학생");    // 맞을 때(true)만 실행
}
```

- "평균"은 변수 `aver`에 들어 있으니 조건에 `aver`를 그대로 써요.
- 지금 평균은 78.33이에요. 머릿속으로 값을 넣어 보면 `78.33 >= 95` → **false**. 그래서 "장학생"은 출력되지 **않아요**.
- 수학 점수를 100으로 바꾸면 평균이 100이 되어 `100 >= 95` → true, 이때 "장학생"이 출력돼요.

**왜 이렇게 쓰나요?** 계산해 둔 데이터 중에서 "조건에 맞는 경우에만" 무언가를 하고 싶을 때 쓰는 게 1형식이에요. 조건이 틀리면 아무 일도 하지 않고 다음 줄로 넘어가요.

### 2-5. 2형식 - 둘 중 하나를 고르기 (if-else)

문제: 국어 점수가 70점 이상이면 "합격", 아니면 "불합격"을 출력하세요.

```java
if (kor >= 70) {                       // 국어 점수가 70 이상인가?
    System.out.println("국어:합격");    // true면 이쪽
} else {                               // 그렇지 않으면(false)
    System.out.println("국어:불합격");  // 이쪽
}
```

- "70점 이상"은 70을 **포함**하므로 `>=`를 써요. (`>`를 쓰면 딱 70점인 학생이 불합격이 돼요.)
- `kor`가 100이면 `100 >= 70` → true → **국어:합격**
- `kor`를 50으로 바꾸면 `50 >= 70` → false → **국어:불합격**
- if와 else는 **하나의 덩어리**예요. 둘 중 **반드시 하나만** 실행돼요. (앞에서 배운 삼항 연산자 `조건 ? A : B`와 비슷한 역할이에요.)

### 2-6. 중첩 if (else if) - 조건이 여러 개일 때

문제: 수학 점수가 90 이상 A, 80 이상 B, 70 이상 C, 60 이상 D, 나머지는 F학점을 출력하세요.

```java
if (mat >= 90) {
    System.out.println("수학:A학점");
} else if (mat >= 80) {
    System.out.println("수학:B학점");
} else if (mat >= 70) {
    System.out.println("수학:C학점");
} else if (mat >= 60) {
    System.out.println("수학:D학점");
} else {
    System.out.println("수학:F학점");
}
```

동작 순서를 `mat = 35`로 따라가 볼게요.

1. `35 >= 90`? 틀림 → else로 내려가서 다음 조건
2. `35 >= 80`? 틀림 → 다음
3. `35 >= 70`? 틀림 → 다음
4. `35 >= 60`? 틀림 → 다음
5. 더 물어볼 조건이 없으니 마지막 `else` 실행 → **수학:F학점**

`mat = 100`이라면 첫 조건 `100 >= 90`이 true라서 "수학:A학점"을 출력하고 **덩어리 전체를 바로 빠져나가요.** 아래쪽 `mat >= 80`은 물어보지도 않아요.

**왜 중요한가요?** 이 if~else if~else 전체가 **하나의 덩어리**라서, 위에서부터 처음 true가 된 곳 **딱 한 군데만** 실행돼요. 그래서 "80 이상" 조건에 "90 미만"을 따로 쓰지 않아도 돼요. 이미 위에서 90 이상은 걸러졌으니까요. 마지막 `else`는 필요 없으면 생략해도 돼요.

> 팁: 강사가 강조한 공부법 - 변수 값을 직접 조건식에 넣어 "35 >= 90? 틀림" 하고 손으로 따라가 보세요. 그리고 점수를 여러 번 바꿔서 실행해 결과가 달라지는지 꼭 확인하세요.

국어 50, 영어 100, 수학 10으로 바꿔 실행하면 평균 53.33, "국어:불합격", "수학:F학점"이 나오고, 셋 다 100으로 바꾸면 "장학생", "국어:합격", "수학:A학점"이 나와요.

전체 코드: `code/GradeIf.java`

## 3. switch-case문

### 3-1. 개념 - "똑같은 값"을 목록에서 찾기

switch-case문은 **어떤 값을 가지느냐에 따라** 실행할 문장을 고르는 문법이에요. 여러분이 만든 **case 목록** 중에서 switch 괄호 안의 값과 **정확히 일치하는** 것을 찾아 실행해요.

> 비유: 엘리베이터 버튼과 같아요. "3"을 누르면 3층에서만 멈추죠. "3보다 크면" 같은 개념은 없어요. 딱 그 숫자와 같은 층을 찾아가요.

형식:

```java
switch (값) {
    case 값1 : 실행문; break;
    case 값2 : 실행문; break;
    case 값3 : 실행문; break;
    default : 실행문;
}
```

- `case 값 :` 뒤에 콜론(`:`)을 찍고 실행할 문장을 써요. 콜론은 문법이니 빠뜨리면 안 돼요.
- `break` : switch 덩어리를 **완전히 빠져나가라**는 명령이에요.
- `default` : 찾는 값이 목록에 **없을 때** 무조건 실행돼요.
- break와 default는 **필수가 아니에요.** 필요할 때 쓰면 돼요.

**중요:** switch는 "크다/작다" 같은 범위 비교는 못 해요. **같은지**만 확인해요. 범위로 판단해야 하면 if문을 쓰세요.

### 3-2. 기본 예제

```java
switch (20) {
    case 10 : System.out.println("SEOUL"); break;
    case 20 : System.out.println("BUSAN"); break;   // 20과 일치!
    case 30 : System.out.println("JEJU");  break;
}
```

실행 결과:

```
BUSAN
```

- 괄호 안의 20과 같은 `case 20`을 찾아 "BUSAN"을 출력하고, `break`를 만나 switch를 빠져나가요.
- 10을 넣으면 SEOUL, 30을 넣으면 JEJU가 나와요.
- case 목록은 **순서대로(10, 20, 30) 쓰지 않아도 에러는 안 나요.** 하지만 사람이 읽기 헷갈리니 순서대로 쓰는 게 좋아요.
- 강의에서는 `switch(20)`처럼 숫자를 직접 넣었지만, 실제로는 `switch(city)`처럼 변수를 넣는 경우가 대부분이에요.

### 3-3. break가 없으면? - 아래로 "흘러내려가요"

```java
switch (20) {
    case 10 : System.out.println("국어"); break;
    case 20 : System.out.println("영어");          // break 없음!
    case 30 : System.out.println("수학"); break;
}
```

실행 결과:

```
영어
수학
```

- 20과 일치하는 `case 20`에서 "영어"를 출력해요.
- 그런데 break가 없어서 switch를 빠져나가지 못하고, 프로그램 원래 흐름대로 **다음 줄로 계속 내려가요.** 그래서 `case 30`의 "수학"까지 출력되고, 거기 있는 break에서 비로소 빠져나가요.
- 이걸 "fall-through(흘러내림)"라고 불러요. **에러가 아니라 문법 규칙**이에요. 일부러 이렇게 써야 할 때도 있으니, break를 넣을지 말지는 프로그램 전체를 보고 판단하면 돼요.

### 3-4. default - 목록에 없을 때

```java
switch (60) {
    case 10 : System.out.println("개나리"); break;
    case 20 : System.out.println("진달래"); break;
    case 30 : System.out.println("무궁화"); break;
    default : System.out.println("기타");
}
```

실행 결과:

```
기타
```

- 60은 10, 20, 30 어디에도 없으니 `default`가 실행돼요. 40, 50을 넣어도 "기타"예요.
- default는 보통 **맨 마지막**에 둬요. 맨 마지막이면 어차피 switch가 끝나니까 break를 써도 되고 안 써도 돼요.

### 3-5. 문자(char)도 switch에 넣을 수 있어요

switch 괄호 안에는 정수뿐 아니라 **문자(char)** 도 올 수 있어요. 강의에서 프로젝트(계산기) 힌트로 보여 준 형태예요.

```java
int a = 10, b = 3;
char op = '*';              // 문자는 작은따옴표로 감싸요

switch (op) {
    case '+' : System.out.println(a + " + " + b + " = " + (a + b)); break;
    case '-' : System.out.println(a + " - " + b + " = " + (a - b)); break;
    case '*' : System.out.println(a + " * " + b + " = " + (a * b)); break;
    case '/' : System.out.println(a + " / " + b + " = " + (a / b)); break;
    default  : System.out.println("지원하지 않는 기호예요: " + op);
}
```

실행 결과:

```
10 * 3 = 30
```

- `op`가 `'*'`이니 `case '*'`를 찾아 곱셈 결과를 출력해요.
- 참고로 자바 7부터는 문자열(`String`, 예: `case "서울":`)도 switch에 쓸 수 있어요. (강의에서 다룬 내용은 아니고 참고용이에요.)

전체 코드: `code/SwitchChar.java`

## 4. if와 switch, 언제 무엇을 쓸까?

| 상황 | 추천 | 이유 |
|---|---|---|
| "70점 이상", "60 미만"처럼 **범위**로 판단 | if | switch는 같은지만 비교할 수 있어요 |
| 메뉴 번호 1, 2, 3 / 기호 `+ - * /`처럼 **정해진 값 중 하나** | switch | 목록이 한눈에 보이고 깔끔해요 |
| 조건이 true/false 하나뿐 | if (1형식/2형식) | 가장 단순해요 |

## 자주 하는 실수

1. **조건에 `=` 하나만 쓰기**
   - 코드: `if (kor = 100) { ... }`
   - 에러: `incompatible types: int cannot be converted to boolean`
   - 원인: `=`는 "넣기(대입)"예요. "같다"는 `==` 두 개를 써야 해요.
   - 해결: `if (kor == 100)`

2. **if 조건 뒤에 세미콜론 붙이기**
   - 코드: `if (aver >= 95); { System.out.println("장학생"); }`
   - 증상: 에러는 안 나는데, 평균과 상관없이 **항상** "장학생"이 출력돼요.
   - 원인: `;`에서 if문이 끝나버려서, 뒤의 `{ }`는 if와 관계없는 그냥 블록이 돼요.
   - 해결: `if (...)` 뒤에는 `;`를 쓰지 않아요.

3. **else 앞에 if가 없다는 에러**
   - 에러: `'else' without 'if'`
   - 원인: if 블록의 `}`를 빠뜨렸거나, if와 else 사이에 다른 문장을 넣었을 때 나요.
   - 해결: if 블록의 중괄호 짝을 확인하고, `} else {`가 바로 이어지게 써요.

4. **평균 계산에서 괄호 빼먹기**
   - 코드: `double aver = kor + eng + mat / 3.0;`
   - 증상: 에러는 없지만 100, 100, 35일 때 평균이 78.33이 아니라 211.67로 나와요.
   - 해결: `(kor + eng + mat) / 3.0`

5. **switch에서 break 빼먹기**
   - 증상: 원하는 case 하나만 나와야 하는데 아래 case들까지 줄줄이 출력돼요.
   - 해결: case마다 끝에 `break;`를 붙였는지 확인해요(일부러 흘러내리게 하는 경우 제외).

6. **case에 같은 값을 두 번 쓰기**
   - 에러: `duplicate case label`
   - 해결: case 값은 서로 달라야 해요.

7. **switch에 범위 조건 쓰기**
   - 코드: `case >= 90:` 같은 형태는 문법 에러예요.
   - 해결: 범위 판단은 if~else if로 바꿔요.

8. **else if 순서를 거꾸로 쓰기**
   - 코드: `if (mat >= 60) {D} else if (mat >= 90) {A}` 순서로 쓰면 100점도 D학점이 돼요(첫 조건에서 이미 true라 빠져나가니까요).
   - 해결: 큰 값(더 좁은 조건)부터 차례로 물어봐요.

## 용어 정리

| 용어 | 쉬운 뜻 |
|---|---|
| 제어문 | 프로그램이 실행되는 순서(흐름)를 바꾸는 문법 |
| 조건문 | 조건에 따라 실행할 코드를 고르는 제어문 (if, switch) |
| 조건(조건식) | 결과가 true 또는 false로 나오는 식. 예: `kor >= 70` |
| 불린(boolean) | true(참) 또는 false(거짓) 두 가지 값만 가지는 자료형 |
| 비교 연산자 | 두 값을 비교하는 기호. `>`, `>=`, `<`, `<=`, `==`, `!=` |
| 블록 | 중괄호 `{ }`로 묶은 코드 덩어리 |
| if | 조건이 true일 때만 블록을 실행 |
| else | 앞의 if 조건이 false일 때 실행 |
| else if | 앞 조건이 false일 때 다른 조건을 다시 물어봄 |
| 중첩 if | if~else if~else를 이어서 여러 조건을 차례로 확인하는 형태 |
| switch | 괄호 안의 값과 일치하는 case를 찾아 실행하는 문법 |
| case | switch에서 비교할 목록의 한 항목 |
| break | switch 덩어리를 즉시 빠져나가는 명령 |
| default | 일치하는 case가 없을 때 실행되는 부분 |
| fall-through | break가 없어서 다음 case까지 이어서 실행되는 현상 |
| char | 문자 한 개를 담는 자료형. 작은따옴표 `'A'`로 표기 |
