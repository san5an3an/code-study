# 05강. System.out.printf()의 다양한 출력서식

## 이 강의에서 배우는 것

- `println`(엔터 있음)과 `print`(엔터 없음)의 차이
- 큰따옴표, 작은따옴표, 역슬래시 같은 "명령어용 기호"를 화면에 그냥 글자로 찍는 방법(`\"`, `\'`, `\\`)
- `+` 기호가 숫자끼리는 "덧셈", 문자열이 끼면 "이어 붙이기"가 된다는 것
- `printf`로 값을 원하는 모양(칸 수, 정렬, 소수점 자리)에 맞춰 예쁘게 출력하는 방법(`%d`, `%f`, `%c`, `%s`, `\n`, `\t`)

> 왜 배우나요? 프로그램이 아무리 좋은 결과를 계산해도, 결국 그걸 보는 건 사람이에요. 같은 내용이라도 줄이 가지런하고 소수점이 정리돼 있으면 훨씬 읽기 쉽죠. 워드 프로세서에서 정렬·간격을 맞추는 것과 비슷한 작업이라 어렵게 생각하지 않아도 돼요.

## 1. println 과 print 의 차이

`System.out.println(...)`은 지금까지 써 온 "콘솔(결과창)에 글자 찍기" 명령이에요. 이름 끝의 `ln`은 line(줄)의 줄임말로, **글자를 찍은 뒤 엔터(줄바꿈)까지 쳐 준다**는 뜻이에요. `ln`을 빼고 `print`만 쓰면 **엔터 없이** 글자만 찍어요.

```java
System.out.println("JAVA");     // JAVA 찍고 엔터
System.out.println("PYTHON");   // PYTHON 찍고 엔터
System.out.print("사과");        // 사과 찍고 엔터 안 침
System.out.print("수박");        // 그래서 바로 옆에 수박
System.out.print("참외");        // 또 옆에 참외
System.out.println();           // 괄호가 비어 있으면 엔터만 친다
```

실행 결과:

```
JAVA
PYTHON
사과수박참외
```

비유하자면 `println`은 "말하고 나서 줄을 바꾸는 사람", `print`는 "숨도 안 쉬고 이어서 말하는 사람"이에요.

## 2. 특수문자 출력 (이스케이프 문자)

자바에서 어떤 기호들은 **명령어의 일부**로 쓰여요.

| 기호 | 자바에서의 원래 역할 |
|---|---|
| `"` (큰따옴표) | 문자열(String)의 시작과 끝 |
| `'` (작은따옴표) | 문자 한 개(char)의 시작과 끝 |
| `\` (역슬래시) | 특수한 값을 표시하는 신호, 경로 구분 |

그래서 큰따옴표를 화면에 그냥 찍고 싶어서 `"""`라고 쓰면, 자바는 첫 번째와 두 번째 `"`를 한 쌍으로 묶어 버려서 세 번째 `"`가 짝이 없게 돼요. 결과는 에러예요.

해결법: 기호 앞에 **역슬래시(`\`)를 붙이면** "이건 명령이 아니라 그냥 글자야"라는 뜻이 돼요. 이렇게 `\`로 시작하는 표시를 **이스케이프 문자**(escape, "원래 역할에서 탈출시킨 문자")라고 불러요.

```java
System.out.println("\"");   // 큰따옴표 하나 출력
System.out.println("\'");   // 작은따옴표 하나 출력
System.out.println("\\");   // 역슬래시 하나 출력
System.out.println("그가 \"안녕\"이라고 말했다");
System.out.println("C:\\Users\\java");
```

실행 결과:

```
"
'
\
그가 "안녕"이라고 말했다
C:\Users\java
```

- `\"` 두 글자가 화면에선 `"` 한 글자로 나와요.
- `\\`처럼 역슬래시 자체를 찍을 때도 두 번 써야 해요. 역슬래시 하나는 "다음 글자가 특별하다"는 신호로 먹히기 때문이에요.

> 참고: 글꼴(폰트)에 따라 역슬래시 `\`가 원화 기호 `₩`로 보일 수 있어요. 한국어 윈도우에서 흔한 일인데, **둘은 같은 기호**예요. 윈도우에서는 키보드의 `₩` 키를 누르면 돼요. macOS 한글 입력 상태에서는 같은 키가 진짜 원화 기호(`₩`)를 입력할 수 있으니, 역슬래시가 필요하면 **영문 입력 상태로 바꾼 뒤** 그 키를 누르세요.

## 3. 연결 연산자 `+`

`+`는 원래 덧셈 기호지만, 자바에서는 **문자열이 하나라도 끼어 있으면 "이어 붙이기"**로 바뀌어요.

| 왼쪽 | 오른쪽 | 결과 |
|---|---|---|
| 숫자 | 숫자 | 덧셈 결과(숫자) |
| 숫자 | 문자열 | 이어 붙인 문자열 |
| 문자열 | 숫자 | 이어 붙인 문자열 |
| 문자열 | 문자열 | 이어 붙인 문자열 |

```java
System.out.println(123 + 456);     // 숫자+숫자 -> 덧셈
System.out.println("ONE" + "TWO"); // 문자열끼리 -> 연결
System.out.println("123" + 456);   // 문자열+숫자 -> 연결
System.out.println(123 + "456");   // 숫자+문자열 -> 연결
System.out.println("123+456");     // 따옴표 안의 +는 그냥 글자
```

실행 결과:

```
579
ONETWO
123456
123456
123+456
```

`"123"`처럼 숫자라도 **따옴표로 감싸면 글자(문자열)**예요. 이 차이 때문에 결과가 579가 되느냐 123456이 되느냐가 갈려요.

### 왜 유용한가요?

설명 글자와 변수 값을 한 줄로 이어서 찍을 수 있어요.

```java
int age = 25;                               // 정수 변수 age에 25를 저장
System.out.println("나이: " + age + "살");   // 나이: 25살
```

### 계산은 왼쪽부터 차례로

```java
System.out.println(1 + 2 + "3");     // 33
System.out.println("1" + 2 + 3);     // 123
System.out.println("합: " + (1 + 2)); // 합: 3
```

- `1 + 2 + "3"`: 먼저 `1 + 2`는 숫자끼리라 3, 그다음 `3 + "3"`은 연결이라 `33`.
- `"1" + 2 + 3`: 처음부터 문자열이라 `"12"`, 이어서 `"123"`.
- 덧셈을 먼저 하고 싶으면 괄호로 묶어요.

(이 "왼쪽부터" 예시는 강의 내용을 확장한 보충 설명이에요.)

## 4. printf 로 서식 맞춰 출력하기

`printf`의 `f`는 format(서식)의 약자예요. 기본 모양은 이래요.

```java
System.out.printf("출력서식", 값1, 값2, ...);
```

- 따옴표 안의 일반 글자는 **그대로** 출력돼요.
- 따옴표 안의 `%d`, `%f` 같은 **자리표시자**(값이 들어갈 빈칸)는 쉼표 뒤의 값으로 **순서대로** 바뀌어요.
- 비유: 서식은 "빈칸 있는 양식 용지", 값은 "빈칸에 채워 넣을 내용"이에요.

### 꼭 알아야 할 표시

| 표시 | 뜻 |
|---|---|
| `\n` | 줄바꿈(엔터) |
| `\t` | 탭(넓은 간격) |
| `%d` | 정수(decimal) 자리 |
| `%f` | 실수(소수점 있는 수, floating point) 자리 |
| `%c` | 문자 한 개(character) 자리 |
| `%s` | 문자열(string) 자리 |

`%d`는 **붙여서 한 덩어리**로 써야 해요. `% d`처럼 띄우면 안 돼요.

`printf`는 `println`과 달리 **엔터를 자동으로 치지 않아요.** 줄을 바꾸고 싶으면 `\n`을 직접 넣어야 해요.

### 4-1. 정수 `%d`

```java
System.out.printf("%d %d %d\n", 10, 20, 30); // %d가 3개 -> 값도 3개
System.out.printf("나이 : %d\n", 25);
System.out.printf("\n\n나\t이 : %d\n", 30);  // 빈 줄 2개 + 탭
```

실행 결과(두 번째 줄 다음 빈 줄 두 개, `나`와 `이` 사이는 탭 간격):

```
10 20 30
나이 : 25


나	이 : 30
```

첫 번째 `%d`에는 10, 두 번째에는 20, 세 번째에는 30이 들어가요. `\n`은 원하는 곳에 몇 번이든 넣을 수 있어요.

### 4-2. 칸 수와 정렬 `%5d`, `%-5d`

숫자를 넣으면 "몇 칸을 차지할지"를 정할 수 있어요.

```java
System.out.printf("나이 : #%5d#\n", 25);   // 5칸 잡고 오른쪽 정렬
System.out.printf("나이 : #%-5d#\n", 25);  // 5칸 잡고 왼쪽 정렬
```

실행 결과:

```
나이 : #   25#
나이 : #25   #
```

- `#`은 아무 의미 없는 기호예요. 빈칸이 몇 개인지 눈으로 보려고 양쪽에 붙인 거예요.
- `%5d`: 5칸 중 25가 2칸을 쓰고, **앞에** 빈칸 3개 → 오른쪽 정렬.
- `%-5d`: 마이너스(`-`)를 붙이면 **앞에서부터** 채워서 뒤에 빈칸 3개 → 왼쪽 정렬.

### 4-3. 실수 `%f`, 소수점 자리 `%.2f`

```java
System.out.printf("%f %f\n", 1.2, 3.4);
System.out.printf("키:%f\n", 165.7);
System.out.printf("키:#%9.2f#\n", 165.7);   // 전체 9칸, 소수 2자리, 오른쪽 정렬
System.out.printf("키:#%-9.2f#\n", 165.7);  // 전체 9칸, 소수 2자리, 왼쪽 정렬
System.out.printf("키:#%.2f#\n", 165.7);    // 소수 2자리만 지정
```

실행 결과:

```
1.200000 3.400000
키:165.700000
키:#   165.70#
키:#165.70   #
키:#165.70#
```

- 그냥 `%f`는 소수점 아래를 **6자리**까지 보여 줘요.
- `%9.2f`: 점 앞의 9는 "전체 칸 수"(소수점 `.`도 한 칸으로 셈), 점 뒤의 2는 "소수점 아래 자리 수". `165.70`은 6칸이니 앞에 빈칸 3개.
- `%.2f`: 전체 칸은 신경 쓰지 않고 소수점 아래 2자리만. 실전에서 제일 많이 써요(예: 평균 점수, 금액).
- 자리를 줄이면 **반올림**돼요. 예: `175.456`을 `%.1f`로 찍으면 `175.5`.

### 4-4. 문자 `%c`, 문자열 `%s`

```java
System.out.printf("%c\n", 'A');       // 문자 한 개는 작은따옴표
System.out.printf("#%-5c#\n", 'B');   // 5칸, 왼쪽 정렬
System.out.printf("%s\n", "APPLE");   // 문자열은 큰따옴표
System.out.printf("#%-5s#\n", "HI");  // 5칸, 왼쪽 정렬
System.out.printf("#%5s#\n", "HI");   // 5칸, 오른쪽 정렬
```

실행 결과:

```
A
#B    #
APPLE
#HI   #
#   HI#
```

칸 수·정렬 규칙은 `%d`와 똑같아요.

### 4-5. 섞어 쓰기와 표 만들기

```java
String name = "홍길동";
int age = 20;
double height = 175.456;
char grade = 'A';
System.out.printf("이름:%s 나이:%d 키:%.1f 등급:%c\n", name, age, height, grade);

System.out.printf("%-8s%5s\n", "item", "price");
System.out.printf("%-8s%5d\n", "apple", 1200);
System.out.printf("%-8s%5d\n", "melon", 15000);
```

실행 결과:

```
이름:홍길동 나이:20 키:175.5 등급:A
item    price
apple    1200
melon   15000
```

서식의 순서와 값의 순서가 **1:1로 맞아야** 해요. 칸 수를 맞추면 표처럼 줄이 가지런해져요. (이 섞어 쓰기·표 예시는 강의 내용을 응용한 보충 예시예요. 표에는 영어를 썼는데, 한글은 화면에서 영문보다 넓게 보여서 칸이 어긋나 보일 수 있기 때문이에요.)

## 자주 하는 실수

| 증상 / 에러 메시지 | 원인 | 해결 |
|---|---|---|
| `String literal is not properly closed by a double-quote` (Eclipse) / `unclosed string literal` (javac) | 문자열 안에 `"`를 그냥 씀 | `\"`로 바꾸기 |
| `Invalid escape sequence` / `illegal escape character` | 역슬래시 하나만 쓰고 뒤에 이상한 글자가 옴 (예: `"C:\Users"`) | 역슬래시를 `\\`로 두 번 쓰기 |
| `java.util.MissingFormatArgumentException: Format specifier '%d'` | `%d`는 3개인데 값은 2개만 줌 | 서식 개수와 값 개수를 맞추기 |
| `java.util.IllegalFormatConversionException: d != java.lang.Double` | `%d`(정수) 자리에 `3.14`(실수)를 줌 | 실수는 `%f`, 정수는 `%d` |
| `IllegalFormatConversionException: f != java.lang.Integer` | `%f` 자리에 정수 `10`을 줌 | `10.0`처럼 실수로 주거나 `%d`로 바꾸기 |
| 출력이 다음 출력과 한 줄에 붙어 나옴 | `printf`는 엔터를 자동으로 안 침 | 서식 끝에 `\n` 넣기 |
| `/n`을 썼는데 그대로 `/n`이 찍힘 | 슬래시(`/`)와 역슬래시(`\`)를 헷갈림 | 줄바꿈은 역슬래시 `\n` |
| `java.util.UnknownFormatConversionException` | `printf("50% 할인\n")`처럼 `%` 기호 자체를 찍으려 함 (자바는 `%` 뒤를 서식으로 읽으려 함) | `%` 글자를 찍으려면 `%%`로 쓰기 |
| 숫자 앞에 이상한 빈칸이 하나 생김 | `% d`처럼 `%`와 `d` 사이를 띄움 (자바에서는 "앞에 공백 하나 붙여라"라는 다른 뜻이 됨) | `%d`는 붙여서 한 덩어리로 쓰기 |
| `"1" + 2`가 3이 아니라 12가 나옴 | 따옴표로 감싼 숫자는 문자열 | 계산할 값은 따옴표 없이 쓰기 |

## 용어 정리

| 용어 | 쉬운 뜻 |
|---|---|
| 콘솔 | 프로그램의 글자 결과가 나오는 창 |
| `println` | 글자를 찍고 줄을 바꾸는 출력 명령 |
| `print` | 글자만 찍고 줄은 안 바꾸는 출력 명령 |
| `printf` | 서식(모양)을 정해서 출력하는 명령 |
| 문자열 (String) | 큰따옴표로 감싼 글자 묶음. 예: `"APPLE"` |
| 문자 (char) | 작은따옴표로 감싼 글자 한 개. 예: `'A'` |
| 정수 | 소수점 없는 수. 예: 25 |
| 실수 | 소수점 있는 수. 예: 165.7 |
| 이스케이프 문자 | `\`로 시작해 특별한 뜻을 갖는 표시. 예: `\n`, `\"` |
| 역슬래시 | `\` 기호. 폰트에 따라 `₩`로 보이기도 함 |
| 연결 연산자 | 문자열을 이어 붙이는 `+` |
| 출력 서식 | `%d`, `%.2f`처럼 값이 들어갈 자리와 모양을 정하는 표시 |
| 자리표시자 | 나중에 값으로 바뀔 빈칸. `%d` 등 |
| 정렬 | 정해진 칸 안에서 왼쪽/오른쪽에 붙이는 것 |
