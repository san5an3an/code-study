# 04강. 기본 자료형

## 이 강의에서 배우는 것

- 자바의 자료형은 크게 **기본 자료형**과 **참조 자료형** 두 갈래로 나뉜다는 것
- 기본 자료형 다섯 종류: 정수형(byte, short, int, long), 실수형(float, double), 문자형(char), 논리형(boolean), 그리고 예외적으로 함께 배우는 문자열형(String)
- 자료형마다 "그릇 크기"가 달라서 담을 수 있는 값의 범위가 다르다는 것
- 변수의 특징 세 가지: 자료형은 처음 한 번만 쓴다, 같은 자료형은 쉼표로 한 번에 선언할 수 있다, 값은 언제든 바뀔 수 있다
- 실무에서 가장 많이 쓰는 건 정수는 `int`, 실수는 `double`

---

## 1. 자료형이 뭐예요?

**자료형(data type, 데이터 타입)** 은 "이 변수에 어떤 종류의 값을 넣을 건지" 미리 정해 두는 이름표예요.

비유하면 부엌 그릇이에요. 국은 국그릇에, 물은 컵에, 간장은 종지에 담죠. 자바도 정수를 담을 그릇, 소수를 담을 그릇, 글자를 담을 그릇이 따로 있어요. 변수를 만들 때 "어떤 그릇인지"를 이름 앞에 써 줘야 해요.

```java
int age = 20;
```

- `int` : 자료형. "정수를 담는 그릇이에요"라는 뜻
- `age` : 변수 이름(그릇에 붙인 이름표)
- `=` : 대입 연산자. 오른쪽 값을 왼쪽 변수에 넣어라
- `20` : 넣을 값
- `;` : 문장 끝 표시

**왜 굳이 자료형을 쓰나요?** 컴퓨터는 값을 메모리라는 공간에 저장하는데, 종류에 따라 필요한 공간 크기와 저장 방식이 달라요. 자료형을 미리 알려 주면 자바가 알맞은 크기의 공간을 잡아 주고, 엉뚱한 값(예: 숫자 그릇에 글자)을 넣으려 하면 실행 전에 미리 에러로 알려 줘요. 실수를 일찍 잡아 주는 안전장치인 셈이에요.

자바의 자료형은 두 갈래예요.

| 구분 | 설명 | 예 |
|---|---|---|
| 기본 자료형 | 값 자체를 담는 가장 기초적인 자료형 | int, double, char, boolean 등 |
| 참조 자료형 | "클래스"라고도 부름. 나중에 배움 | String 등 |

> 크기 숫자(1바이트, 2바이트...)는 억지로 외우지 않아도 돼요. 자주 쓰다 보면 자연스럽게 익혀져요. "어느 쪽이 더 크다" 정도의 순서만 기억하면 충분해요.

## 2. 정수형: byte, short, int, long

**정수**는 소수점이 없는 수예요(예: 3, -10, 2026). 정수를 담는 그릇은 네 가지인데, 차이는 **그릇 크기**뿐이에요.

| 자료형 | 크기 | 담을 수 있는 범위 |
|---|---|---|
| byte | 1바이트 | -128 ~ 127 |
| short | 2바이트 | -32,768 ~ 32,767 |
| int | 4바이트 | 약 -21억 ~ 21억 |
| long | 8바이트 | 약 -922경 ~ 922경 |

> **바이트(byte)** : 컴퓨터 메모리 크기의 단위. 숫자가 클수록 큰 그릇이에요.

순서: `byte < short < int < long`

그릇이 클수록 더 큰 수를 담을 수 있어요. 소주잔(byte)에 물 한 바가지(200)를 부으면 넘치듯, `byte`에 127보다 큰 수를 넣으면 에러가 나요.

**가장 기본은 `int`** 예요. 특별한 이유가 없으면 정수는 `int`를 쓰면 돼요. `short`는 자바에서 거의 안 쓰고, `long`은 21억을 넘는 아주 큰 수가 필요할 때 써요.

### 선언과 대입을 따로 하기

```java
byte b;      // b라는 byte형 변수를 만든다 (선언)
b = 3;       // b에 3을 넣는다 (대입)
System.out.println(b);      // 3
System.out.println(b + 1);  // 4
```

- **선언** : "이런 이름의 그릇을 하나 만들어 줘"라고 알리는 것
- **대입** : 그 그릇에 값을 넣는 것
- `b + 1` 은 "b에 들어 있는 값(3)에 1을 더한 결과"를 출력할 뿐이에요. b 자체가 4로 바뀌지는 않아요.
- 코드에서 `b`는 알파벳 b가 아니라 **변수 b** 로 읽어야 해요.

### 선언과 대입을 한 줄에

```java
short s = 5;
int i = 7;
long l = 9;
```

만들면서 바로 값을 넣을 수도 있어요. 실제로는 이 방식을 더 자주 써요.

실행 결과:
```
5
7
9
```

## 3. 변수의 특징 세 가지

### (1) 자료형은 처음 한 번만 쓴다

```java
int i = 7;
int i = 2;   // 에러!
```

`int i`라고 쓰는 순간 "i라는 그릇을 새로 만들어라"라는 뜻이 돼요. 이미 i가 있는데 또 만들라고 하니까 자바가 "이미 있는 이름이에요" 하고 거부해요. 값을 바꾸고 싶으면 자료형 없이 이름만 써요.

```java
i = 2;       // OK. 이미 있는 i에 새 값만 넣기
```

### (2) 같은 자료형은 쉼표로 한 번에 선언할 수 있다

```java
int c = 2, d = 4;
System.out.println(c + d);  // 6
```

`int c = 2;` 와 `int d = 4;` 를 두 줄로 쓴 것과 같아요. 자료형이 같을 때만 가능해요.

### (3) 변수의 값은 바뀔 수 있다

```java
c = 10;
d = 20;
System.out.println(c + d);  // 30
```

이름이 "변수(變數, 변하는 수)"인 이유예요. 새 값을 넣으면 이전 값은 사라지고 새 값으로 계산돼요.

전체 예제(`code/IntegerTypes.java`) 실행 결과:
```
3
4
5
7
9
6
30
```

## 4. 실수형: float, double

**실수**는 소수점이 있는 수예요(예: 1.2, 3.14). 그릇은 두 가지예요.

| 자료형 | 크기 | 특징 |
|---|---|---|
| float | 4바이트 | 숫자 뒤에 `f`를 **반드시** 붙임 |
| double | 8바이트 | 숫자 뒤에 `d`를 붙일 수 있지만 **생략 가능** |

`double`이 그릇이 더 커서 소수점 아래를 더 정밀하게(더 많은 자리까지) 표현해요.

> 강의 슬라이드에는 float는 소수점 9자리, double은 18자리라고 되어 있어요. 일반적으로 알려진 값은 float 약 7자리, double 약 15~16자리(유효숫자 기준)예요. 어느 쪽이든 핵심은 "double이 훨씬 정밀하다"예요.

```java
float f = 1.2f;    // f 필수
double d = 3.4d;   // d 붙여도 되고
double d2 = 3.4;   // 안 붙여도 됨 (보통 이렇게 씀)
System.out.println(f);
System.out.println(d);
System.out.println(d2);
```

실행 결과:
```
1.2
3.4
3.4
```

**왜 float에는 f를 붙여야 하나요?** 자바는 소수점 있는 숫자를 그냥 쓰면 기본적으로 `double`로 취급해요. `1.2`만 쓰면 "큰 그릇(double)에 담긴 1.2"가 되는데, 이걸 작은 그릇(float)에 그대로 부으면 넘칠 수 있다고 보고 자바가 막아요. `1.2f`라고 쓰면 "처음부터 float용 숫자예요"라고 알려 주는 거예요. 이렇게 숫자 뒤에 붙이는 글자를 **접미사**라고 해요.

반대로 double은 원래 기본값이라 `d`를 생략해도 되고, f를 매번 붙이는 수고도 없어요. 그래서 자바에서는 **float보다 double을 훨씬 많이 써요.**

## 5. 문자형: char

**char**(캐릭터)는 글자 **딱 하나**를 담는 그릇이에요. 크기는 2바이트예요.

```java
char ch = 'A';
System.out.println(ch);  // A
```

- 반드시 **작은따옴표 `' '`** 로 감싸요.
- 안에는 글자 한 개만 들어가요. `'AB'`는 에러예요.

---

## 6. 문자열형: String

**문자열**은 글자 여러 개가 줄줄이 이어진 것(단어, 문장)이에요. 자료형 이름은 `String`이에요.

```java
String str = "KOREA";
System.out.println(str);  // KOREA
```

- 반드시 **큰따옴표 `" "`** 로 감싸요.
- `String`은 첫 글자가 **대문자 S**예요. `string`이라고 쓰면 에러예요.

**주의:** String은 엄밀히 말하면 기본 자료형이 **아니라 참조 자료형(클래스)** 이에요. 그런데 워낙 자주 쓰고 사용법이 기본 자료형과 거의 같아서 지금 같이 배우는 거예요. 기본 자료형들은 이름이 전부 소문자(int, double, char...)인데 String만 대문자로 시작하는 것도 "클래스"라서 그래요.

정리하면 따옴표로 구별해요.

| 쓰는 법 | 자료형 | 뜻 |
|---|---|---|
| `'A'` | char | 글자 하나 |
| `"A"` | String | 글자 하나짜리 문자열 |
| `"KOREA"` | String | 여러 글자 문자열 |

`code/CharAndString.java` 실행 결과:
```
A
KOREA
```

## 7. 논리형: boolean

**boolean**(불리언)은 **true(참)** 또는 **false(거짓)** 두 값만 담는 그릇이에요. 강의에서는 크기를 1바이트로 소개해요.

전등 스위치를 떠올리면 돼요. 켜짐(true) 아니면 꺼짐(false), 둘 중 하나뿐이에요.

```java
boolean flag = true;      // 따옴표 없이!
System.out.println(flag);  // true

flag = false;              // 값 바꾸기
System.out.println(flag);  // false
```

실행 결과:
```
true
false
```

- `true`, `false`는 따옴표 없이 소문자로 써요. `"true"`라고 쓰면 문자열이 되어 에러가 나요.
- **왜 필요해요?** "로그인했나?", "점수가 60점 이상인가?" 같은 예/아니오 상태를 저장할 때 써요. 나중에 배울 if 조건문에서 아주 많이 써요.
- `flag`는 "깃발"이라는 뜻으로, 예/아니오 상태를 표시하는 변수에 관례적으로 많이 붙이는 이름이에요.

| 분류 | 자료형 | 크기 | 예시 값 | 비고 |
|---|---|---|---|---|
| 정수형 | byte | 1바이트 | `3` | |
| 정수형 | short | 2바이트 | `5` | 잘 안 씀 |
| 정수형 | **int** | 4바이트 | `7` | **정수 기본** |
| 정수형 | long | 8바이트 | `9` | 아주 큰 정수 |
| 실수형 | float | 4바이트 | `1.2f` | f 필수 |
| 실수형 | **double** | 8바이트 | `3.4` | **실수 기본**, d 생략 가능 |
| 문자형 | char | 2바이트 | `'A'` | 작은따옴표, 한 글자 |
| 논리형 | boolean | 1바이트 | `true` | true/false만 |
| (참조형) | String | - | `"KOREA"` | 큰따옴표, 클래스 |

## 자주 하는 실수

### 1) 같은 변수를 두 번 선언

```java
int i = 7;
int i = 2;
```
- 에러: `variable i is already defined in method main(String[])`
  (Eclipse 한글판: "중복된 로컬 변수 i" 같은 메시지)
- 원인: 자료형을 또 붙여서 같은 이름의 변수를 새로 만들려고 함
- 해결: 두 번째부터는 `i = 2;` 처럼 이름만 쓴다

### 2) float에 f를 안 붙임

```java
float f = 1.2;
```
- 에러: `incompatible types: possible lossy conversion from double to float`
- 원인: `1.2`는 기본적으로 double로 취급되는데, 더 작은 float 그릇에 넣으려고 함
- 해결: `1.2f` 로 쓰거나, 그냥 `double`을 쓴다

### 3) char에 큰따옴표 사용

```java
char c = "A";
```
- 에러: `incompatible types: String cannot be converted to char`
- 원인: 큰따옴표로 감싸면 String이 됨
- 해결: `'A'` 처럼 작은따옴표 사용

### 4) boolean에 따옴표 사용

```java
boolean b = "true";
```
- 에러: `incompatible types: String cannot be converted to boolean`
- 해결: `boolean b = true;` (따옴표 없이)

### 5) 그릇보다 큰 값 넣기

```java
byte x = 200;
```
- 에러: `incompatible types: possible lossy conversion from int to byte`
- 원인: byte는 127까지만 담을 수 있음
- 해결: 더 큰 그릇인 `int`를 쓴다

### 6) 대소문자 틀림

```java
int i = 7;
System.out.println(I);   // 대문자 I
string s = "hi";         // 소문자 string
```
- 에러: `cannot find symbol`
- 원인: 자바는 대문자와 소문자를 완전히 다른 글자로 봄
- 해결: 변수 이름은 선언할 때와 똑같이, `String`은 대문자 S로

## 용어 정리

| 용어 | 쉬운 뜻 |
|---|---|
| 자료형(데이터 타입) | 변수에 담을 값의 종류를 정하는 이름표 |
| 기본 자료형 | int, double, char, boolean 등 자바에 기본으로 있는 가장 단순한 자료형 |
| 참조 자료형 | 클래스라고도 함. String 등. 나중에 자세히 배움 |
| 클래스 | 자바 프로그램을 이루는 단위. 참조 자료형을 만드는 틀 |
| 바이트(byte) | 메모리 크기 단위. 자료형 이름 byte와는 구분 |
| 정수 | 소수점이 없는 수 |
| 실수 | 소수점이 있는 수 |
| 문자 | 글자 하나 (char) |
| 문자열 | 글자 여러 개의 묶음 (String) |
| 논리값 | 참(true) 또는 거짓(false) |
| 선언 | 변수를 새로 만드는 것 (`int a;`) |
