# 07. 제어문 - for 반복문

## 이 강의에서 배우는 것

- 같은 문장을 정해진 횟수만큼 되풀이하는 **for 반복문**의 형식과 실행 순서(①→②→④→③→②...)를 익혀요.
- 반복 변수를 **증가**시키면서, 또 **감소**시키면서 반복하는 방법을 배워요.
- 변수가 살아 있는 범위인 **유효범위(scope)** 를 이해해요. for 괄호 안에서 만든 변수는 for 밖에서 못 써요.
- 반복문 안에 반복문을 넣는 **이중 반복문**을 배우고, 이를 이용해 **구구단(2단~9단)** 을 출력해요.
- 흐름이 헷갈릴 때 쓰는 **회전 추적표**(변수 값을 한 줄씩 적어 보는 방법)를 익혀요.

---

## 1. 반복문이 왜 필요할까요?

"JAVA"를 100번 출력해야 한다고 해 볼게요. `System.out.println("JAVA");`를 100줄 복사해 붙이면 될까요? 되긴 하지만 그건 프로그래밍이라기보다 워드 작업에 가까워요. 프로그래밍을 하는 큰 이유 중 하나가 컴퓨터에게 **"이걸 100번 해"** 라고 한 줄로 시킬 수 있다는 점이에요.

비유하자면, 운동장을 10바퀴 뛰라고 할 때 "한 바퀴 뛰어, 한 바퀴 뛰어..."를 10번 말하는 대신 "10바퀴 뛰어"라고 말하고, 뛰는 사람이 손가락으로 바퀴 수를 세는 것과 같아요. 이 "손가락으로 세는 숫자"가 바로 **반복 변수**예요.

- **반복문**: 어떤 문장을 여러 번 되풀이하게 만드는 문법이에요.
- **반복 변수**: 지금 몇 번째 도는 중인지 세는 데 쓰는 변수예요. (변수 = 값을 담는 이름 붙은 상자, 03강 복습)

---

## 2. for 문의 형식

```java
for (①반복변수 시작값; ②조건식; ③반복변수 증감) {
    ④실행문
}
```

괄호 안은 세미콜론(`;`) 두 개로 세 칸이 나뉘어요.

| 번호 | 이름 | 하는 일 |
|---|---|---|
| ① | 시작값(초기식) | 반복 변수를 만들고 처음 값을 넣어요. **맨 처음 딱 한 번만** 실행돼요. |
| ② | 조건식 | `true`면 ④를 실행하고, `false`면 for문을 빠져나가요. |
| ③ | 증감식 | ④를 다 실행한 뒤 반복 변수 값을 늘리거나 줄여요. 그다음 ②로 가요. |
| ④ | 실행문 | 반복해서 실행할 내용이에요. 중괄호 `{ }` 안에 써요. |

실행 순서는 이렇게 돌아요.

```
① → ② → ④ → ③ → ② → ④ → ③ → ② ... → ②가 false가 되면 끝
```

핵심은 **①은 한 번만**, 그 뒤로는 **② → ④ → ③** 을 계속 빙글빙글 도는 거예요. 몇 번 돌지는 시작값, 조건, 증감을 어떻게 쓰느냐로 여러분이 정해요.

- **조건식**: 결과가 `true`(참) 또는 `false`(거짓)로 나오는 식이에요. 06강의 if에서 쓴 것과 같아요.

## 3. 증가하면서 반복하기

```java
for (int a = 1; a <= 3; a = a + 1) {
    System.out.println("JAVA");
}
```

- `int a = 1` : 정수 변수 a를 만들고 1을 넣어요. (①, 한 번만)
- `a <= 3` : a가 3 이하인지 물어봐요. (②)
- `a = a + 1` : 지금 a 값에 1을 더해서 다시 a에 넣어요. 즉 a를 1 늘려요. (③)
- `System.out.println("JAVA");` : JAVA를 출력하고 줄을 바꿔요. (④)

### 회전 추적표로 따라가 보기

반복문이 처음엔 눈에 잘 안 들어와요. 그럴 땐 변수 값을 아래처럼 직접 적어 보세요. 강사도 이 방법을 강력 추천해요.

| a 값 | 조건 `a <= 3` | 출력 | 증감 후 a |
|---|---|---|---|
| 1 | 1<=3 → true | JAVA | 2 |
| 2 | 2<=3 → true | JAVA | 3 |
| 3 | 3<=3 → true | JAVA | 4 |
| 4 | 4<=3 → **false** | (for문 끝) | |

실행 결과:

```
JAVA
JAVA
JAVA
```

왜 `<`가 아니라 `<=`일까요? `a < 3`으로 쓰면 a가 3일 때 false가 되어 2번만 돌아요. "1부터 3까지 세 번"을 원하니 3도 포함하는 `<=`를 써요.

> 참고: `a = a + 1`은 줄여서 `a++` 라고도 써요. 뜻은 같아요. 강의 후반 구구단에서는 `a++`를 써요.

## 4. 감소하면서 반복하기

반복 변수를 꼭 늘릴 필요는 없어요. 줄이면서도 반복할 수 있어요.

```java
for (int b = 3; b >= 1; b = b - 1) {
    System.out.println("Python");
}
```

- `int b = 3` : 3부터 시작해요.
- `b >= 1` : b가 1 이상인 동안 반복해요.
- `b = b - 1` : 한 바퀴 돌 때마다 1씩 줄여요.

| b 값 | 조건 `b >= 1` | 출력 | 증감 후 b |
|---|---|---|---|
| 3 | true | Python | 2 |
| 2 | true | Python | 1 |
| 1 | true | Python | 0 |
| 0 | **false** | (for문 끝) | |

실행 결과:

```
Python
Python
Python
```

카운트다운(3, 2, 1)처럼 거꾸로 세야 할 때 이렇게 써요.

## 5. 유효범위(scope) - 변수는 어디까지 살아 있을까?

**유효범위(scope)** 는 어떤 변수가 살아 있어서 쓸 수 있는 범위를 말해요. 비유하면, 놀이공원 손목밴드 같은 거예요. 놀이공원 안(for문 안)에서는 유효하지만, 정문을 나서면(for문이 끝나면) 효력이 없어지죠.

### for 괄호 안에서 만든 변수

```java
for (int c = 1; c <= 5; c = c + 1) {
    System.out.println("KOREA");
}
// System.out.println(c);   // 에러!
```

- c는 for의 괄호 안에서 태어났어요. 그래서 **for문 안에서만** 쓸 수 있고, for문을 빠져나가는 순간 메모리에서 사라져요.
- 그래서 for문 아래에서 `c`를 쓰면 "그런 변수 없어요" 에러가 나요.

### for 바깥에서 만든 변수

```java
int d = 0;                       // for보다 먼저, 바깥에서 선언
for (d = 1; d <= 5; d = d + 1) { // 여기서는 int 없이 값만 넣어요
    System.out.println("SEOUL");
}
System.out.println(d);           // 6
```

- d는 for와 상관없이 위에서 선언했어요. 변수는 **선언된 줄부터 그 아래(자기가 속한 중괄호 끝까지)** 어디서든 쓸 수 있어요.
- 마지막에 d가 6인 이유: d가 5일 때 SEOUL을 찍고 6으로 늘어난 뒤, `6 <= 5`가 false라서 끝났기 때문이에요.

실행 결과:

```
KOREA
KOREA
KOREA
KOREA
KOREA
SEOUL
SEOUL
SEOUL
SEOUL
SEOUL
6
```

**왜 중요할까요?** 반복이 끝난 뒤에도 그 값을 써야 한다면(예: 몇 번 돌았는지, 합계가 얼마인지) 변수를 for 바깥에서 미리 선언해야 해요. 반대로 반복 안에서만 잠깐 쓸 변수는 for 괄호 안에서 만드는 게 깔끔해요.

## 6. 이중 반복문

반복문 안에 또 반복문을 넣을 수 있어요. 2중, 3중도 가능해요. (for 안에 if를 넣는 것처럼 지금까지 배운 문법은 다 서로 겹쳐 쓸 수 있어요.)

비유: 시계를 떠올려 보세요. 분침(안쪽 반복)이 한 바퀴(60분)를 다 돌아야 시침(바깥 반복)이 한 칸 움직이죠.

```java
for (int a = 1; a <= 2; a = a + 1) {        // 바깥: 2번
    System.out.println("JAVA");

    for (int b = 1; b <= 3; b = b + 1) {    // 안쪽: 바깥 한 번당 3번
        System.out.println("Python");
    }
}
```

### 회전 추적표

```
a=1  1<=2 true  -> JAVA
        b=1  1<=3 -> Python
        b=2  2<=3 -> Python
        b=3  3<=3 -> Python
        b=4  4<=3 false -> 안쪽 for 끝
a=2  2<=2 true  -> JAVA
        b=1 (다시 1부터!) -> Python, Python, Python
a=3  3<=2 false -> 바깥 for 끝
```

실행 결과:

```
JAVA
Python
Python
Python
JAVA
Python
Python
Python
```

포인트:
- 바깥이 **한 번** 돌 때 안쪽은 **처음부터 끝까지 전부** 돌아요.
- 안쪽 for의 ①(`int b = 1`)은 바깥이 돌 때마다 **새로** 실행돼요. 그래서 b는 매번 1부터 다시 시작해요.
- 전체 횟수 = 바깥 횟수 x 안쪽 횟수 (여기서는 Python이 2 x 3 = 6번).
- 유효범위도 그대로 적용돼요. for가 끝난 뒤 `a`나 `b`를 출력하려 하면 둘 다 에러예요.

## 7. 실전: 구구단 2단 ~ 9단

구구단은 이중 반복문의 대표 예제예요. "단"이 2부터 9까지 바뀌고, 각 단 안에서 곱하는 수가 1부터 9까지 바뀌니까 반복이 두 겹 필요해요.

생각하는 순서:
1. 먼저 바깥 반복으로 "2단, 3단, ... 9단" 제목만 찍어 봐요.
2. 그다음 각 단 안에 9줄이 나오도록 안쪽 반복을 넣어요.
3. 마지막으로 그 9줄을 `2*1=2` 모양으로 바꿔요.

```java
for (int dan = 2; dan <= 9; dan++) {
    System.out.println(dan + "단");

    for (int a = 1; a <= 9; a++) {
        System.out.println(dan + "*" + a + "=" + (dan * a));
    }
}
```

- `dan++` : `dan = dan + 1`의 줄임말이에요.
- `dan + "단"` : 숫자와 문자열을 `+`로 붙이면 이어 붙인 글자가 돼요. 2 + "단" → `2단`.
- `dan + "*" + a + "=" + (dan * a)` : 글자를 이어 붙이다가, 마지막에 괄호 안에서 곱셈 결과를 계산해 붙여요.

실행 결과(앞부분과 끝부분):

```
2단
2*1=2
2*2=4
2*3=6
2*4=8
2*5=10
2*6=12
2*7=14
2*8=16
2*9=18
3단
3*1=3
...
9*7=63
9*8=72
9*9=81
```

**왜 `(dan * a)`에 괄호를 칠까요?** 곱셈은 원래 덧셈보다 먼저 계산되니 이 경우엔 괄호가 없어도 결과는 같아요. 하지만 "여기는 계산 결과를 붙인다"는 뜻을 분명히 해 주고, 만약 덧셈이었다면 결과가 완전히 달라져요. 예를 들어 `x`가 2일 때 `"x+1=" + x + 1`은 `x+1=21`이 돼요(문자열 뒤에 2와 1을 차례로 이어 붙임). `"x+1=" + (x + 1)`이라고 써야 `x+1=3`이 나와요. 계산하고 싶은 부분은 괄호로 묶는 습관을 들이세요.

## 자주 하는 실수

### 1) for문 밖에서 반복 변수 쓰기

```java
for (int c = 1; c <= 5; c++) { ... }
System.out.println(c);
```

- Eclipse: 빨간 밑줄과 함께 `c cannot be resolved to a variable`
- javac(명령창): `error: cannot find symbol` / `symbol: variable c`
- 원인: c는 for 괄호 안에서 선언되어 for가 끝나면 사라져요.
- 해결: for가 끝난 뒤에도 쓸 거라면 `int c = 0;`처럼 for **위에서** 선언하고, for 괄호에서는 `c = 1`로 값만 넣으세요.

### 2) 같은 이름 변수를 두 번 선언하기

```java
int d = 0;
for (int d = 1; d <= 5; d++) { ... }
```

- 에러: `variable d is already defined in method main(String[])`
- 원인: 바깥에 이미 d가 있는데 for 괄호에서 `int d`로 또 만들었어요.
- 해결: 바깥 변수를 쓸 거면 for 괄호에서 `int`를 빼고 `d = 1`로 쓰세요.

### 3) 세미콜론 대신 쉼표, 또는 칸 수 틀리기

```java
for (int a = 1, a <= 3, a++) { ... }   // 잘못
```

- 에러: `';' expected` 같은 문법 에러
- 해결: 괄호 안 세 칸은 반드시 **세미콜론 두 개**로 나눠요. `for (int a = 1; a <= 3; a++)`

### 4) 조건을 잘못 써서 한 번도 안 돌거나 끝나지 않는 경우

- `for (int b = 3; b <= 1; b--)` : 시작부터 `3 <= 1`이 false라서 **한 번도 실행되지 않아요.** 감소 반복은 보통 `>=`를 써요.
- `for (int a = 1; a <= 3; a--)` : a가 계속 줄어서 `a <= 3`이 영원히 true예요. **무한 반복**에 빠져 프로그램이 안 끝나요. Eclipse에서는 콘솔의 빨간 정지 버튼으로 멈추세요. 증감 방향이 조건과 맞는지 확인하세요.

### 5) 횟수가 하나 모자라거나 하나 많은 경우

- `a < 3`과 `a <= 3`은 한 번 차이가 나요. 헷갈리면 회전 추적표를 적어 마지막 값에서 조건이 어떻게 되는지 확인하세요.

### 6) for 괄호 뒤에 세미콜론 붙이기

```java
for (int a = 1; a <= 3; a++); {
    System.out.println("JAVA");
}
```

- 에러는 안 나지만 JAVA가 **1번만** 찍혀요. `;` 때문에 "아무것도 안 하는 문장"을 3번 반복하고, 그 뒤 중괄호는 그냥 한 번 실행돼요.
- 해결: `)` 바로 뒤에 `;`를 쓰지 마세요.

| 반복문 | 같은 문장을 여러 번 되풀이하게 하는 문법 |
| for 문 | 정해진 횟수만큼 반복할 때 주로 쓰는 반복문 |
| 반복 변수 | 지금 몇 번째 도는지 세는 변수 (예: a, b, dan) |
| 시작값(초기식) | for 괄호 첫 칸. 반복 변수의 처음 값. 한 번만 실행 |
| 조건식 | for 괄호 둘째 칸. true면 계속, false면 끝 |
| 증감식 | for 괄호 셋째 칸. 반복 변수를 늘리거나 줄임 |
| 실행문 | 중괄호 안에서 반복되는 문장 |
| 회전(수) | 반복이 한 바퀴 도는 것 / 몇 바퀴 도는지 |
| 회전 추적표 | 변수 값과 조건 결과를 한 줄씩 적어 흐름을 확인하는 표 |
| 유효범위(scope) | 변수가 살아 있어서 쓸 수 있는 범위 |
| 이중 반복문 | 반복문 안에 또 반복문이 들어 있는 구조 |
| `a++` | `a = a + 1`의 줄임말 (1 증가) |
| `a--` | `a = a - 1`의 줄임말 (1 감소) |
| 무한 반복 | 조건이 계속 true라서 끝나지 않는 반복 |
