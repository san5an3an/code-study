# 08. 제어문 - while문, do-while문, continue문

## 이 강의에서 배우는 것

- `while`문: 조건이 참(true)인 동안 같은 일을 계속 반복하는 방법
- `do-while`문: 일단 한 번 실행하고 나서 조건을 묻는 반복문, 그리고 `while`과의 결정적 차이
- `break`문과 `continue`문: 반복 도중에 "완전히 나가기"와 "이번만 건너뛰기"
- 무한루프(`while(true)`)와 `break`를 짝으로 쓰는 패턴

> 복습: 지난 강의에서 `for`문으로 반복하는 법을 배웠어요. 이번엔 반복을 만드는 다른 방법 두 가지와, 반복의 흐름을 바꾸는 명령 두 가지를 배워요.

---

## 1. 프로그램의 흐름과 반복문

프로그램은 기본적으로 **위에서 아래로 한 줄씩** 실행돼요. 그런데 반복문을 만나면, 특정 구간을 여러 번 빙글빙글 돈 다음 다시 아래로 내려가요. 이렇게 "어디를 몇 번 실행할지"를 정하는 걸 **흐름 제어**라고 하고, 그걸 하는 문장을 **제어문**이라고 불러요.

비유하자면 운동장 트랙이에요. 한 바퀴 돌 때마다 코치(조건식)가 "한 바퀴 더?"라고 묻고, "응(true)"이면 또 돌고, "아니(false)"면 트랙을 빠져나와요.

---

## 2. while문

### 형식

```java
while (조건식) {
    조건식이 true인 동안 반복할 내용
}
```

- **조건식**: 결과가 `true` 또는 `false`로 나오는 식이에요. 예: `a <= 3`
- 조건식이 `true`면 중괄호 `{ }` 안을 실행하고, 다시 위로 올라가 조건을 또 물어요.
- 조건식이 `false`가 되는 순간 `while`문 전체를 빠져나와 아래 코드로 가요.

즉 "물어보고 실행하고, 물어보고 실행하고..."를 반복하는 구조예요.

### 예제 (code/WhileBasic.java)

```java
int a = 1;                       // 1부터 시작
while (a <= 3) {                 // a가 3 이하인 동안 반복
    System.out.println("JAVA");  // JAVA 출력
    a = a + 1;                   // a를 1 늘림
}
System.out.println("반복이 끝난 뒤 a = " + a);
```

한 바퀴씩 따라가 보면 이래요. (강사님도 이렇게 직접 손으로 써 보라고 강조해요. 몇 번 써 보면 패턴이 보여요.)

| 바퀴 | 조건 확인 | 결과 | 실행 후 a |
|---|---|---|---|
| 1 | 1 <= 3 | true | JAVA 출력, a = 2 |
| 2 | 2 <= 3 | true | JAVA 출력, a = 3 |
| 3 | 3 <= 3 | true | JAVA 출력, a = 4 |
| 4 | 4 <= 3 | false | 반복 끝 |

실행 결과:

```
JAVA
JAVA
JAVA
반복이 끝난 뒤 a = 4
```

**왜 `a = a + 1;`이 필요할까요?** 이 줄이 없으면 a는 영원히 1이라서 조건 `1 <= 3`이 계속 true예요. 그러면 반복이 끝나지 않아요. while문을 쓸 땐 **반복 안에서 조건이 언젠가 false가 되도록** 값을 바꿔 줘야 해요.

> 참고: `for`문은 초기값, 조건식, 증감식을 한 줄에 다 쓰지만, `while`문은 초기값은 위에, 증감은 중괄호 안에 따로 써요. 몇 번 돌지 정확히 알 땐 `for`, "어떤 상태가 될 때까지" 돌릴 땐 `while`이 읽기 편한 경우가 많아요.

## 3. do-while문

### 형식

```java
do {
    반복할 내용
} while (조건식);   // 끝에 세미콜론(;)을 꼭 붙여요!
```

- `do`는 "일단 해라"라는 뜻이에요. 조건을 묻지 않고 바로 중괄호 안으로 들어가요.
- 중괄호를 다 실행한 다음에 `while (조건식)`으로 조건을 물어요. true면 다시 `do`로 올라가요.
- **맨 끝의 세미콜론 `;`을 빠뜨리면 에러**가 나요. 일반 while문에는 없는 부분이라 자주 틀려요.

### 예제 (code/DoWhileBasic.java)

```java
int c = 1;
do {
    System.out.println("Python");  // 먼저 실행
    c = c + 1;
} while (c <= 3);                  // 나중에 조건 확인
```

| 바퀴 | 실행 | 조건 확인 |
|---|---|---|
| 1 | Python, c = 2 | 2 <= 3 true, 다시 |
| 2 | Python, c = 3 | 3 <= 3 true, 다시 |
| 3 | Python, c = 4 | 4 <= 3 false, 끝 |

실행 결과:

```
Python
Python
Python
```

이 경우엔 while문과 결과가 똑같아요. 차이는 **조건이 처음부터 틀렸을 때** 드러나요.

## 4. while문과 do-while문의 차이

| | while문 | do-while문 |
|---|---|---|
| 조건을 묻는 시점 | 실행하기 **전** | 실행한 **후** |
| 조건이 처음부터 false라면 | **0번** 실행 | **최소 1번** 실행 |

강의에서는 차이를 보려고 조건을 **일부러 틀리게** 줬어요.

### 예제 (code/WhileVsDoWhile.java)

```java
int a = 3;
while (a <= 0) {                  // 3 <= 0 은 false
    System.out.println("SEOUL");  // 한 번도 실행 안 됨
    a = a + 1;
}
System.out.println(a);            // 3

int b = 3;
do {
    System.out.println("BUSAN");  // 일단 실행됨
    b = b + 1;                    // b = 4
} while (b <= 0);                 // 4 <= 0 은 false, 끝
System.out.println(b);            // 4
```

실행 결과:

```
3
BUSAN
4
```

- while 쪽: 입구에서 "3이 0 이하야?"라고 묻자마자 아니라서 들어가지도 못했어요. 그래서 SEOUL은 안 찍히고 a도 그대로 3이에요.
- do-while 쪽: 묻지도 않고 일단 들어가서 BUSAN을 찍고 b를 4로 만든 뒤, 나가면서 "4가 0 이하야?"를 물어요. 아니니까 거기서 끝. 그래서 b는 4예요.

비유: while문은 **입구에서 표 검사**하는 놀이공원, do-while문은 **일단 한 번 타고 나서 출구에서 표 검사**하는 놀이기구예요.

**언제 do-while을 쓸까요?** "최소 한 번은 반드시 실행돼야 하는" 경우예요. 예를 들어 메뉴를 먼저 보여 주고, 사용자가 "종료"를 고를 때까지 다시 보여 주는 프로그램이 딱 그래요.

## 5. 무한루프

```java
while (true) {
    ...
}
```

조건 자리에 `true`를 직접 쓰면 조건이 **항상 참**이라서 끝없이 반복돼요. 이걸 **무한루프**라고 해요.

무한루프는 "잘못된 코드"라는 뜻이 아니에요. 일부러 끝없이 돌려 놓고, 안에서 **원하는 순간에 `break`로 빠져나오는** 방식으로 아주 많이 써요. 강사님 표현대로 무한루프와 `break`는 "커플"이에요.

---

## 6. break문: 반복을 완전히 빠져나오기

`break`는 `switch-case`에서 이미 봤죠. 반복문 안에서 `break`를 만나면 **남은 바퀴가 있어도 반복문 전체를 즉시 빠져나가요**.

### 예제 (code/BreakContinue.java 앞부분)

```java
for (int a = 1; a < 10; a = a + 1) {
    if (a == 5) {
        break;                    // a가 5면 for문 탈출
    }
    System.out.printf("%d", a);   // %d = 정수 자리 (05강 printf 복습)
}
System.out.println();             // 괄호가 비어 있으면 줄바꿈만 해요
```

실행 결과:

```
1234
```

a가 1, 2, 3, 4일 땐 `a == 5`가 false라서 숫자를 찍어요. a가 5가 되는 순간 `break`를 만나서, 아직 6~9가 남아 있어도 그냥 나가 버려요. 5는 출력 전에 나갔으니 안 찍혀요.

비유: 줄넘기 100번 하기로 했는데 4번 하다가 비가 와서 **그대로 집에 가는** 거예요.

---

## 7. continue문: 이번 바퀴만 건너뛰기 (U턴)

`continue`를 만나면 **그 아래 코드를 건너뛰고, 다음 바퀴로 바로 넘어가요**. 강의에서는 이걸 "U턴"이라고 불렀어요. 반복문을 나가는 게 아니라 위로 돌아가는 거예요.

어디로 U턴하는지가 반복문마다 달라요.

| 반복문 | continue를 만나면 가는 곳 |
|---|---|
| for문 | **증감식** (예: `a = a + 1`) |
| while문, do-while문 | **조건식** (예: `while (a < 10)`) |

### 예제 (code/BreakContinue.java 뒷부분)

```java
for (int a = 1; a < 10; a = a + 1) {
    if (a == 5) {
        continue;                 // a가 5면 아래 printf를 건너뛰고 증감식으로
    }
    System.out.printf("%d", a);
}
System.out.println();
```

실행 결과:

```
12346789
```

a가 5일 때만 출력을 건너뛰고, 증감식으로 U턴해서 a가 6이 된 뒤 계속 돌아요. 그래서 **5만 빠졌어요**.

비유: 줄넘기 9번 하는데 5번째에 줄이 발에 걸려서 **그 한 번은 안 센 셈 치고** 다음 번으로 넘어가는 거예요.

### break와 continue 한눈에 비교

| | break | continue |
|---|---|---|
| 뜻 | 반복 그만! | 이번만 건너뛰고 계속! |
| 결과(위 예제) | `1234` | `12346789` |
| 반복문 밖으로 나가나요? | 예 | 아니요 |

## 8. 무한루프 + break 활용 (code/InfiniteLoopBreak.java)

강사님이 "프로젝트 할 때 참고하라"며 보여 준 예제예요.

```java
int b = 1;
while (true) {                    // 무한루프
    System.out.println("KOREA");
    b = b + 1;
    if (b == 5) {
        break;                    // b가 5가 되면 빠져나옴
    }
}
```

실행 결과:

```
KOREA
KOREA
KOREA
KOREA
```

KOREA를 찍고 b를 늘리는 걸 반복하다가, b가 5가 되는 순간 `break`로 빠져나와요. 출력은 b가 1, 2, 3, 4일 때 찍힌 4번이에요.

### 덤: while문 안에서 continue 쓸 때 주의

while문의 continue는 **조건식**으로 U턴하기 때문에, 값을 늘리는 코드가 continue **아래**에 있으면 그 코드도 건너뛰어 버려요. 그래서 증가 코드는 continue **위**에 두는 게 안전해요.

```java
int n = 0;
while (n < 6) {
    n = n + 1;                    // 먼저 늘리기
    if (n == 3) {
        continue;                 // 3은 건너뛰기
    }
    System.out.print(n + " ");
}
System.out.println();
```

실행 결과:

```
1 2 4 5 6 
```

## 자주 하는 실수

### 1) do-while 끝에 세미콜론을 빠뜨림

```java
do {
    ...
} while (c <= 3)    // ; 없음
```

- 에러 메시지(javac): `error: ';' expected`
- Eclipse에서는 빨간 줄과 함께 `Syntax error, insert ";" to complete DoStatement` 같은 메시지가 떠요.
- 해결: `} while (c <= 3);`처럼 끝에 `;`을 붙여요.

### 2) 반복 안에서 값을 안 바꿔서 무한루프

```java
int a = 1;
while (a <= 3) {
    System.out.println("JAVA");   // a = a + 1; 을 깜빡함
}
```

- 에러는 안 나요. 대신 콘솔에 JAVA가 끝없이 찍히고 프로그램이 안 끝나요.
- 해결: Eclipse 콘솔 창의 빨간 네모(Terminate) 버튼으로 강제 종료한 뒤, 반복 안에 `a = a + 1;`을 넣어요.

### 3) while문에 `;`을 잘못 붙임

```java
while (a <= 3);     // 여기에 ; 를 붙이면
{
    ...
}
```

- `while (a <= 3);`은 "아무것도 안 하는 문장을 반복해라"라는 뜻이 돼요. a가 안 바뀌니 **아무것도 출력되지 않은 채 멈춘 것처럼** 무한루프에 빠져요.
- 해결: `;`은 **do-while의 끝에만** 붙여요. 일반 while문의 `)` 뒤에는 붙이지 않아요.

### 4) while문에서 증가 코드를 continue 아래에 둠

- 증가 코드가 건너뛰어져서 같은 값으로 계속 continue만 반복하는 무한루프가 돼요.
- 해결: 위 8번 "덤"처럼 증가 코드를 continue보다 위에 둬요.

### 5) 반복문 밖에서 break/continue 사용

```java
if (a == 5) {
    break;          // 반복문(또는 switch) 안이 아님
}
```

- 에러 메시지: `error: break outside switch or loop` / `error: continue outside of loop`
- 해결: break는 반복문이나 switch 안에서만, continue는 반복문 안에서만 써요.

### 6) `=`와 `==` 헷갈림

- `if (a = 5)`처럼 쓰면 `error: incompatible types: int cannot be converted to boolean`이 나요.
- `=`는 "넣어라(대입)", `==`는 "같으냐(비교)"예요. 조건에는 `==`를 써요.

## 용어 정리

| 용어 | 쉬운 뜻 |
|---|---|
| 제어문 | 프로그램이 실행되는 순서(흐름)를 바꾸는 문장 |
| 반복문 | 같은 코드를 여러 번 실행하게 하는 문장 (for, while, do-while) |
| 조건식 | 결과가 true(참) 또는 false(거짓)로 나오는 식. 예: `a <= 3` |
| while문 | 조건을 먼저 묻고, true인 동안 반복하는 문장 |
| do-while문 | 먼저 한 번 실행하고 나서 조건을 묻는 반복문. 최소 1번 실행 |
| 무한루프 | 끝없이 반복되는 상태. `while(true)`처럼 일부러 만들기도 함 |
| break | 반복문(또는 switch)을 즉시 완전히 빠져나오는 명령 |
| continue | 이번 바퀴의 나머지를 건너뛰고 다음 바퀴로 넘어가는 명령 (U턴) |
| 증감식 | for문에서 매 바퀴 끝에 변수를 늘리거나 줄이는 부분. 예: `a = a + 1` |
| 바퀴(회전수) | 반복문이 한 번 도는 것. 반복 횟수 |
